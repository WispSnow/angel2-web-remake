# 普通攻击、反击、生命、经验与累计成长

日期：2026-07-14

## 结论

模块 29 的普通攻击链已经从选定攻击者/目标一直追到地形防御、伤害、反击、状态写入、生命归零、死亡移除、经验累加和第三成长行后的外推规则。以下公式均为原生机器码直接确认；本轮未开始 Web 实现。

机器可读结果为 `reverse/parsed/native/combat-formulas.json`，重复导出命令：

```sh
node reverse/tools/angel2-combat-formulas.mjs --extract \
  reverse/unpacked/lzexe-modules/raw/0029-unpacked.bin \
  reverse/parsed/native/unit-descriptors.json \
  reverse/parsed/native/combat-formulas.json
```

导出器会验证 41 段关键代码签名、35 项击杀经验表、23 项第三行后成长表和完整回合状态链；任一地址不再匹配便失败。

## 战斗对象和属性

普通攻击入口 `0000:90D8` 使用：

- `77BFh`：攻击者棋盘格；
- `77C1h`：防守者棋盘格；
- `31BFh/31C1h`：装入状态与难度/状态修正后的有效攻击/防御；
- `31C7h`：当前 `DATA` 行等级；
- 单位状态 `+00h`：当前生命；
- 单位状态 `+02h`：累计经验；
- 单位状态 `+0Ch`：最高位在地图结算路径中阻止移动和逐点扣血。

攻击入口会先由 `0000:9123` 把攻击者棋盘单位槽字节 OR `80h`。所以攻击会消耗该格单位的行动标志，即使最终伤害为 0；伤害动画不是行动消耗的触发点。

## 随机数

`0000:95D2` 从 PIT 通道 0 的 I/O 端口 `40h` 读取一个字节，若结果大于调用者给定的 `DX` 就重读。普通攻击传 `DX=3`，随后加 4，因此每次调用的结果域严格是 `4..7`。

这证明值域，但不能仅凭机器码断言四个结果在现代统计意义上均匀。复刻原版体验时应先把它建模成独立的 `random4to7()`；若以后要求逐周期 DOS 硬件复现，再替换随机源。

## 地形防御

`0000:946A → 1000:41A1` 用棋盘地形字节和当前兵种 profile 取出一个百分数。攻击者与防守者分别计算：

```text
terrainDefense = floor(effectiveDefense * terrainPercent / 100)
```

因此地形值不是直接加到防御上的点数，而是当前有效防御的百分比加成。后续 `MAP` 轮次已确认它来自第二张 23 槽逻辑 profile；物理第 24 字是重叠字。token→瓦片→逻辑槽映射已闭合；对 DS:`2E7D` 的全部六个战斗读取点审计未发现原版名称路径，因此槽以数字 ID 记录，见 `movement-terrain-rules.md`。

## 最高难度敌方属性加成

通用单位装载链在应用职业/等级属性和场景专用覆盖后调用 `1000:8BD1`。该函数只在 GO 原符号 `LV_HARD==3` 且当前阵营为 side 2 时修改：

```text
baseAttack    += floor(baseAttack / 2)
currentAttack += floor(currentAttack / 2)
baseDefense   += floor(baseDefense / 2)
currentDefense+= floor(currentDefense / 2)
maxLife       += floor(maxLife / 2)
```

移动、等级、当前生命和经验不在此函数中修改。由于加成发生在场景 37 的 Boss 统一覆盖之后，其三部位会从攻 100、防 10、最大生命 10,000 变为攻 150、防 15、最大生命 15,000。`LV_HARD` 的四个原版可见名称依次为“過關斬將/勢均力敵/困難重重/無法無天”。

## 伤害公式

令 `r1,r2 ∈ {4,5,6,7}`，则先攻伤害为：

```text
primaryDamage =
  max(0, attacker.attack - defender.defense - defender.terrainDefense)
  + r1 + r2
```

随机总加成为 `8..14`。这是原版一个必须保留的细节：`0000:9490` 加第一次 `4..7`，紧随其后的 `0000:94E3` 又把第二次 `4..7` 加到 `77D3h` 的先攻伤害，而不是反击伤害。反击基础伤害为：

```text
counterDamage = floor(
  max(0, defender.attack - attacker.defense - attacker.terrainDefense) / 2
)
```

该反击基础值没有普通随机加成。完整普通攻击计算链没有命中/闪避或暴击分支；它总会产生一个非负伤害值。此结论只覆盖普通物理攻击，不外推到魔法或“技”。

## 反击条件和职业特例

先攻结算后，只有同时满足以下条件才进入反击：

1. 先攻后双方生命均不为 0；
2. 攻击者短码不是 `0G`，即巨斧战士；
3. 防守者的逐单位禁用字节为 0。

所以巨斧战士的普通攻击会压制反击。防守者禁用字节来自双方各 75 字节数组；它同时参与单位可选择性和 UI 状态，但业务名称尚未完全恢复，当前不把它擅自命名成眩晕、待机或已行动。

若防守者是短码 `2E` 的兽骨骑士，`0000:94E3` 直接读取一次 PIT 值；最低位为 1 时把反击伤害改成完整的 `primaryDamage`，并在地图动画路径设置专用表现标志。它是 50% 候选分支，但精确概率仍依赖 PIT 采样时序。

## 两种伤害呈现路径

`DS:1119` bit 0 选择两套表现：

| 路径 | 选择值 | 生命结算 | 原生边界 |
| --- | --- | --- | --- |
| 地图动画 | bit 0 = 0 | `0000:783D` 每动画一步扣 1 点，最低为 0 | 状态 `+0Ch` bit 15 会跳过每次扣血 |
| 全屏战斗动画 | bit 0 = 1 | `A096/A0C6/A0F6/A10C/A122` 对镜像生命一次饱和减法，再写回 `+00h` | 已恢复的直接减法不检查 `+0Ch` bit 15 |

第二行是原版代码真实存在的路径差异，不应在复刻时悄悄统一。后续实机测试要确认该状态是否只会出现在不会进入全屏战斗的对象上；在此之前应把差异作为兼容开关/原版行为测试保留。

两条路径的视听层现已另行闭合：地图受击 `UN/62 + E/38`、地图死亡 `MAGIC/12`、全屏职业 `M_00/Y_00` direct/+50 选择、五槽职业音效、先攻/反击与 `E/11` 死亡同步见 `ordinary-combat-presentations.md` 和 `combat-presentations.json`。数值公式仍以本文件为规范，两份清单通过 `77D3h/77D5h` 伤害输入连接，不重复计算。

普通伤害链的死亡扫描 `0000:96C2` 遍历 2,500 格，对当前生命为 0 的单位调用移除路径并清当前棋盘格。反击判断发生在先攻后的存活检查之后，所以被先攻击破的单位不会反击。完整回合毒伤链不调用这个扫描器；被毒减至 0 的单位仍留在棋盘并可被选择/休息，详见 `status-lifecycle.md`。

## 普通攻击附加状态

普通攻击附加的四种状态均直接覆盖为 `8003h`。每个完整玩家+自动+敌方回合结束后，原生倒计时执行 `8003h → 8002h → 8001h → 0000h`；重复施加会刷新为 `8003h`。

| 攻击者 | 短码 | 防守者状态偏移 | 已确认效果 |
| --- | --- | ---: | --- |
| 魔剑战士 | `1G` | `+12h` | 该位生效时有效防御 -20 |
| 兽骑士 | `1E` | `+10h` | 该位生效时有效攻击 -20 |
| 邪剑战士 | `2G` | `+0Eh` | 写入与技术 `LA/混亂` 相同的状态槽；进入 AI 装载时把行为强制覆写为 `FFh` 并走职业相关的移动后结束动作 |
| 丛林战士 | `0H` | `+14h` | 写入与技术 `IP/施毒` 相同的状态槽；每次完整回合边界使当前生命变为 `floor(当前生命/2)` |

另外，状态 `+08h/+0Ah` 的 bit 15 分别使有效攻击/防御 +20；`+10h/+12h` 分别使有效攻击/防御 -20。加减是固定 20 点，不是百分比。

## 经验奖励

`1000:8CDD` 明确执行 `unitState[+02h] += award`。先攻者和反击者的奖励根据目标是否已被死亡扫描移除而分支：

| 情况 | 经验奖励 |
| --- | --- |
| 先攻命中，目标存活 | `目标等级 + random4to7()` |
| 先攻击破目标 | `击杀表[目标短码] + random4to7()` |
| 反击命中，目标存活 | `floor((目标等级 + random4to7()) / 2)` |
| 反击击破目标 | `击杀表[目标短码] + random4to7()` |

因此反击只有在未击杀时经验减半；反击击杀仍取完整职业击杀值。

## 累计经验与第三行后成长

普通战斗奖励只做加法，不扣减经验。`0000:5256` 总是先装 `DATA` 第一行，再在累计经验达到第二、第三行 `field0` 时依次替换，因此这些是累计阈值。

达到第三行后，`1000:8E85/8E62` 不读取 `DATA` 第四、第五行，而是从第三行阈值开始循环：

```text
nextThreshold = thirdRowThreshold
repeat:
  nextThreshold += thresholdIncrement
  if currentExperience < nextThreshold: stop
  effectiveAttack += attackIncrement
  baseAttack += attackIncrement
  maxLife += maxLifeIncrement
  growthRowCount += 1
```

该外推不增加防御。23 个职业有专属步长：
