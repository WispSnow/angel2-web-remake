# 主线结局链（内部 stage 49）

版本：Draft 0.1

状态：`[OF]/[SR]/[DD] 已闭合；M72 已指定，M73 已验证，等待用户复验`

## 1. 切片目的

本切片承接第 36 个可玩关卡“究極女神”的 `stage-49` 完成档，复现原版隐藏关之前的
完整主线结局：SAY/0070 战后道别、二十二名角色战绩卡、四段尾声（三段条件分支、
一段固定雕像），最后停在内部
stage 38 边界。它是非战斗演出，不建立地图、部署、回合、敌军或胜负条件。

## 2. 玩家体验摘要

- 剧情目标：观看妮雅一行告别异世界同伴并返回瓦爾克麗；
- 回顾目标：依原版顺序查看二十二名角色的最终职业、等级、属性与累计战绩；
- 条件尾声：依据前三槽族群、累计存档次数与全员战绩总和选择原版插画和文字；
- 路由边界：完整播放四段尾声后停在隐藏 stage 38，不提前播放制作人员表或 `The End`。

## 3. 证据入口

- 路由：内部 stage 37 的 999/1000 分支进入模块 25／stage 49，结局后模块 27 进入 stage 38；
- 剧情：SAY/0070，共 17 个 `KY` 等待检查点，音乐 `MAGIC/77`；
- 战绩卡：模块 33，二十二名角色固定顺序，背景 `A9/0`，装饰 `C/0..30`，音乐 `UN/6`；
- 条件尾声：模块 35，四段文字、`UN` 插画、`SAVE_NUM` 与 `KILL_ALL[0..74]` 分支；
- 制作人员表：模块 46，只在隐藏 stage 38 之后可达，不属于本切片；
- 机器登记：`reverse/parsed/native/ending-presentations.json`；

- [OF] 原版使用双独立对话窗；窗口可同时保留，当前 `KY` 只决定接受输入的活动窗；
- [OF] 原版模块 25 使用 `D/<角色>` 主图、眼睛 frame 1–3 与嘴部 frame 4–5：肖像按
  “睁眼→半闭→闭眼→半闭→睁眼”眨眼；每绘制一个 Big5 双字节字形就在闭嘴／小幅张嘴

## 6. 二十二名角色战绩卡

- [OF] 固定顺序为名册槽 0–21；不按出场、存活、职业或战绩重排；
- [OF] 每卡显示角色肖像／姓名、当前职业、职业等级、最大生命、攻击、防御与
  `KILL_ALL[slot]`；字段沿用原版内嵌标签 `姓名／兵種／等級／生命／攻擊／防禦`，
  战绩沿用 `戰績：00000 人` 的五位补零与量词；
- [OF] 画面并非只有肖像与文字：原版还直接读取当前 `ME_DATA` 职业记录的
  `M_00/<职业>/frame 0`，以 `(x=200, bottom=186)` 为锚点显示左侧普通全景战斗图形；
  这不是攻击动画，也不读取 `Y_00` 或 `+50` 记录；
- [OF] `A/9` 是 `8×349` 背景竖条，横向重复铺满 `640×350` 画面；角色 `D` 肖像位于
  `(16,50)`，`C/0..30` 装饰图位于 `(148,50)`，记录 28 被重映射为 29。职业图叠在装饰
  图上，七项文字的原版起点依次为姓名 `(32,220)`、兵种 `(176,220)`、等级 `(176,240)`、
  生命 `(296,220)`、攻击 `(296,240)`、防御 `(296,260)`、战绩 `(476,220)`；
- [DD] `stableRemake` 以固定、可复现的装饰序列替代原版表现随机，避免截图与异步加载
  抖动；它不消费模拟 PRNG，也不进入存档语义；
- [SR] 战绩含义严格采用原版生产者：side 1 槽发起一次合法普通攻击并进入主要经验路径时
  加一；反击、击杀、射击、技术与敌方攻击均不加一。

## 7. 四段尾声（三段条件分支、一段固定）

这里的“四段”是同一条尾声连续播放的四个段落，不是四个互斥结局。实际共有三个条件轴，
再加一个无条件段；调试中心 `STAGE-49` 的八个直达入口覆盖全部 `3 + 1 + 2 + 2` 结果：

| 段落 | 条件 | 可见结果 |
| --- | --- | --- |
| 1. 主力职业族 | 槽 0–22 最终职业的三族计数；骑兵并列优先，其次战士，法师须严格最大 | 骑兵／战士／法师三种原文与插画 |
| 2. 战士雕像 | 无条件 | 固定显示战士雕像原文与 `UN/11–12` |
| 3. 存档次数 | `SAVE_NUM > 100`／`<= 100` | 女帝重新登基／妮雅成为“神將官” |
| 4. 全员战绩 | `sum(KILL_ALL[0..74]) <= 100`／`> 100` | 王朝长久繁荣／女帝与妮雅死后王朝衰亡 |

### 职业族群

只统计名册槽 0–22 的最终职业原版记录：

| 族群 | 记录号 | 插画 |
| --- | --- | --- |
| 骑兵 | `13–19,22,23` | `UN/4–5` |
| 战士 | `1,2,7,9,27,28,29,33` | `UN/13–14` |
| 法师 | `3–6,10,11,24,25,30,31,32` | `UN/0–1` |

[OF] 平手优先级为骑兵，其次战士；法师只有严格大于两族时胜出。未列记录不计入任何族群。

### 固定雕像

[OF] 无条件显示 `UN/11–12` 与战士雕像原文；原版等待参数为 0（`0000:04C4`），
其等待循环是无号 `counter < limit`，因此绘制后立即进入下一段。

[DD] 该段有完整原文与专属插画对，缺等待参数更像原版漏填。原版仍会先把两张图与文字
同步写入显存，玩家能在下一段读碟时看到一瞬；浏览器的插画是异步 `<img>`，0 ms 会连
这一瞬都没有，等于比原版少画一屏。因此 `stableRemake` 取三个兄弟段实际使用的最小
上限 `0x08C3 = 2243` ticks 作为可见下限，而不是自拟数值；该段仍可被任一语义动作跳过。
这只影响等待，不消费模拟 PRNG，也不改变分支、名册或存档语义。

### 累计存档次数

- [OF] `SAVE_NUM > 100`：女帝重新登基，插画 `UN/17–18`；
- [OF] `SAVE_NUM <= 100`：妮雅成为“神將官”，插画 `UN/19–20`；
- [SR] Web 的 `saveCount` 改为当前战役累计写档次数；跨槽写入不再各自独立计数。

### 全员战绩总和

- [OF] `sum(KILL_ALL[0..74]) <= 100`：王朝长久繁荣，`UN/15–16`、`MUSIC/40`；
- [OF] 总和 `> 100`：王朝后来衰亡，`UN/2–3`、`UN/49`；
- [OF] 该曲由本段选择子决定，但在模块 35 入口（`0000:0457` 选、`0000:045A` 播）就已
  开始，四段尾声全程共用；不得实现为第四段才换曲；
- [SR] 比较使用全部 75 个名册槽，不只统计二十二张卡或最终出场单位。

## 8. 保存与兼容

- [SR] 保存身份为 v73／`stage-49-ending-records-1`，战中档、入关快照与完成档均保存
  75 个非负整数战绩计数；读取严格校验长度与整数边界；
- [SR] v72 及更早存档没有该原生内存状态，无法从现有字段重建；迁移采用 75 个零作为
  明示兼容基线，之后的普通攻击继续累计；
- [SR] `saveCount` 在当前战役内累计；读档恢复该累计值，写入任意槽都从当前值加一；
- [DD] 结局链本身不新增自动存档，也不覆盖已写入的 `stage-49` 完成档；
- [DD] 隐藏 stage 38 未实现，因此结局结束只显示可见冻结边界，不产生伪造 stage 38 存档。

## 9. UI 与输入

- 玩家可从第 37 关完成卡的“观看主线结局”进入；读入合法 `stage-49` 完成档也显示同一入口；
- 鼠标点击、Enter 与 Space 都映射到同一语义推进动作；边界页为终止态，鼠标与键盘都不再推进；
- 战绩卡和尾声支持原版等待上限自动推进；任何表现设置只改变等待；
- 调试中心以独立 `STAGE-49` 分组提供八个确定性直达夹具：职业族群三支、固定战士雕像、
  存档次数 100／101 与战绩总和 100／101；夹具仍建立正式结局会话，不复制分支规则；
- 音乐顺序为 `MAGIC/77`（模块 25）→ `UN/6`（模块 33）→ 模块 35 入口即切到最终分支
  `MUSIC/40` 或 `UN/49` 并覆盖全部四段尾声；隐藏关边界停乐；
- 像素插画使用原始尺寸／调色板和最近邻显示，不平滑缩放；`A/9` 为 `8×349` 竖条，
  按双向平铺填满 350 行，不做缩放；结局逻辑画面在 Web 页面中与常规关卡一样水平居中。

## 10. 规则集差异

| 项目 | `stableRemake` | `legacyStrict` | Mod |
| --- | --- | --- | --- |
| 装饰选择 | 固定表现序列，不消费模拟 PRNG | 原版 PIT 表现随机 | 改变不得影响存档／模拟 |
| 战士雕像等待 | 取兄弟段最小上限 2243 ticks 作可见下限 | 原版 0，实际不可读 | 改动只能停留在等待层 |
| 尾声音乐时点 | 模块 35 入口即切，覆盖四段 | 同左 | 不得改成逐段换曲 |
| 旧档战绩 | 明示零基线后继续累计 | 原版完整内存状态不可恢复 | 须声明迁移政策 |
| 存档计数 | 当前战役跨槽累计 | 原版 `SAVE_NUM` 累计 | 改阈值须改变规则身份 |
| 结束路由 | 停在 stage 38 可见边界 | 进入隐藏关 | 隐藏关须另立合同 |
| 制作人员表 | 不提前播放 | 隐藏关后播放 | 不得移到主线结局前 |
