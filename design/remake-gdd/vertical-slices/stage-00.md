# 第 0 关纸面垂直切片：瓦爾克麗宮

版本：Draft 0.7

内部场景：`stage 0`

原版标题记录：`SAY/0119`

状态：规则、剧情、阵容与 UI 合同已实现；自动验收通过，等待用户手动试玩

## 1. 切片目的

本关用于验证一条最小但完整的产品链：新游戏 → 关前剧情 → 无部署直接开战 → 固定编队战斗 → 回合内剧情 → 全灭胜利/妮雅战败 → 战后对白 → 保存 → 下一关。

它覆盖原版的核心战术显示与剧情节奏，但暂不覆盖交互部署、转职、射击、玩家技术或状态异常。

## 2. 玩家体验摘要

- `[OF]` 地点：瓦爾克麗宮。标题原文见 [`dialogue/0119.json`](../../../reverse/parsed/dialogue/0119.json)。
- `[OF]` 剧情前提：骑士团部队突入宫殿并掳走女帝；负伤士兵向妮雅报告。
- `[OF]` 玩家指挥六名固定我方单位清除宫内十名敌人。
- `[OF]` 妮雅必须存活；全部敌方因被击倒或抵达出口撤离而从棋盘消失时即胜利。
- `[OF]` 敌军不按普通职业攻击，而是沿宫殿专用路线朝中心锚点 `(25,47)` 移动；地图下方楼梯的 `(24,47)/(25,47)/(26,47)` 均为出口，进入任一格便立即离场，形成追击/截断压力。
- `[DD]` 关卡介绍应让玩家理解“保护妮雅并阻止敌人撤离”，但不得把“敌人到达终点”写成失败条件，因为原版目标表没有该条件。

## 7. 战斗时间轴

### 进入第 1 回合

1. `[OF]` 战斗从新生成的准备状态进入第 1 回合；
2. `[OF]` 在玩家获得控制前，side 1 槽 0（妮雅）从 `(10,23)` 脚本移动到 `(29,26)`；
3. `[OF]` 移动使用剧情专用 `FM` 范围、预算 50，并逐格表现；
4. `[OF]` 播放战场剧情 `SAY/0001`。

`[OF]` 脚本移动每格重画并重新居中。终点 `(29,26)` 对应视口原点 `(25,23)`，可见范围 X=`25..34`、Y=`23..29`；`SAY/0001` 继承此焦点，剧情结束后玩家从相同镜头取得控制。

`SAY/0001` 的玩家向内容：宫殿卫士与骑士团骑兵正在交战；希蜜呼叫妮雅，说明女帝已被带走，并让妮雅先追赶，自己处理此处战况。原文见 [`dialogue/0001.json`](../../../reverse/parsed/dialogue/0001.json)。

`[DD]` 剧情结束后，妮雅位于新坐标，玩家从此规范化棋盘状态开始第 1 回合；跳过剧情不能跳过脚本移动。

### 玩家第 1 回合

- `[OF]` 玩家可依常规规则选择六名未行动单位；
- `[OF]` 玩家可呼出“全部休息／跟随主将／自由行动／全面撤退”。本关六名 side 1 初始均为手动单位；全部休息会批量恢复并提交尚未行动者，另外两种 AI 接管会在敌方阶段前完整执行剩余我方行动；
- `[OF]` 全面撤退确认后返回本关准备；第 0 关没有部署页，因此重新建立固定 6 对 10 初态并再次执行妮雅入场移动。取消确认不得改变棋盘、回合或随机状态；
- `[OF]` 敌方阶段中，十名敌人按行为 12 尝试向楼梯出口移动，不使用普通职业攻击；进入三个出口格之一者在当前路径表现抵达后立即离场；
- `[OF]` 每次敌方阶段先行动的是具名骑兵哈釘，其后九名士兵按当前格号的行优先顺序行动；单位死亡或先行撤离会自然从后续扫描中消失；
- `[DD]` 玩家、剧情与 AI 移动表现必须消费模拟层给出的完整逐格路径，每段只连接正交相邻格；整条路径因此按实际通路形成折线，不得直接对起点和终点做穿墙直线补间。玩家“返悔”沿已走路径反向播放。选择移动候选时，黄色候选框随鼠标格即时更新、悬浮不提交；确认后候选框固定在最终目的地，不随路径逐格跳动。
- `[DD]` 本关不增加教程强制步骤。`stableRemake` 第一次进入本关时默认显示一次“查看勝利條件：保護妮雅，清除宮內敵人。”的非阻断提示；它不夺取焦点，并在首次查看目标或完成一个玩家动作后消失。`legacyStrict` 不显示该提示。

## 8. 胜负与结算

### 失败

- `[OF]` 若棋盘上找不到 side 1 槽 0，立即满足失败条件；
- `[OF]` 显示失败反馈，确认后回到同一场景的战前准备；本关没有部署，所以将重新建立固定初态后开战；
- `[DD]` 失败窗口显示“妮雅战败”，不能只写泛化失败。

### 胜利

- `[OF]` 棋盘上不再存在任何 side 2 单位时，写入现场胜利 999；被击倒与进入任一楼梯出口后撤离的单位均已从棋盘移除；
- `[OF]` 先按妮雅肖像资源 46 聚焦，再播放 `SAY/0003`；
- `[OF]` 剧情内容：敌军称任务完成并撤离；妮雅未能拦住；希蜜为未保护女帝道歉；妮雅决定先营救女帝，并命希蜜召集高级指挥官召开紧急会议；
- `[OF]` 原文见 [`dialogue/0003.json`](../../../reverse/parsed/dialogue/0003.json)。
- `[OF]` 随后进入普通胜利反馈与存档提示；本关不在跳过保存提示的特殊场景列表中；
- `[OF]` 继续时默认进入 `stage 1` 的关前流程。

### 保存提示

- `[OF]` 原版普通胜利询问是否记录本次战役，可选择五个存档槽；
- `[OF]` 选择已有槽会直接覆盖，不再弹出二次确认；
- `[SR]` Web 存档同时保存规则身份和 PRNG 状态；
- `[DD]` 战中“儲存記錄”保存当前回合、双方单位、视口、焦点与 PRNG；“讀取記錄”恢复该玩家阶段快照，不额外开始新回合。胜利后的完成存档则直接路由到下一关。

## 10. 可执行验收场景

### S00-A：正常开局

- 从新游戏进入场景 0；
- 播放/跳过关前剧情；
- 不出现部署选择；
- 棋盘建立为 6 对 10；
- 妮雅先移动到 `(29,26)`，再播放 `SAY/0001`；
- 玩家取得控制时棋盘、回合和目标一致。

### BOOT-A：原版启动闭环

- 普通地址先显示 `BK/41` 开场背景和三槽滚动原文，背景按 `41→43→44→45→46→47→48` 切换；
- 动画自然完成或任一键跳过后，组合 `BK/51+52+53` 标题画面，默认选择“遊戲開始”；
- 确认后在同一画面显示四个原版难度，方向键循环、副操作返回标题；
- 确认难度后才创建第 0 关模拟，并把所选值写入运行状态与战后存档。

### S00-B：第二回合事件

- 完成玩家阶段与敌方路线阶段且双方均未达终局；
- 回合号变为 2；
- 状态 tick 在剧情事件前完成；
- 聚焦妮雅并播放 `SAY/0002`；
- 剧情结束后仍处于第 2 回合玩家阶段。

### S00-C：失败重试

- 令妮雅从棋盘移除；
- 触发“妮雅战败”；
- 确认后返回同关准备；
- 因本关无部署，重新建立六名固定单位并从第 1 回合脚本开始。

### S00-D：正常胜利与保存

- 清除最后一名 side 2；
- 触发 999，聚焦妮雅并播放 `SAY/0003`；
- 显示普通胜利与保存提示；
- 保存到指定槽后，继续路由到 `stage 1`；
- 读取该完成存档不重复现场 `SAY/0003`，但能恢复正确下一关路由。

### S00-E：表现独立性

- 分别使用地图/全屏战斗表现、正常/加速动画、开启/关闭逐字音；
- 在相同规则状态与操作序列下，最终单位、生命、经验、回合、PRNG 和胜负完全一致。

### S00-F：具名骑兵与撤离胜利

- 聚焦 side 2 槽 15 时，右栏显示“騎兵／哈釘”及 `D/0015` 肖像；
- 地图棋子与战斗动作仍使用骑兵职业资源；
- 正常敌方阶段首个行动者为哈釘，后续士兵使用稳定的棋盘扫描顺序；
- 将敌人移动到 `(24,47)/(25,47)/(26,47)` 中任一格后，该单位立即离场而非停留占格；
- 最后一名敌人通过撤离消失时，在同一次单位行动内进入现场胜利流程，回合号不增加。

### S00-J：地图普通攻击与死亡表现

- 非致死普通攻击按 `UN/62` 的九次绘制表现，生命按实际扣除点数逐点下降；防守者存活时再对攻击者播放完整反击链；
- 致死攻击保留目标影像直至 `MAGIC/12` 前六个描述符完成，并在第七个描述符开始前清除棋子；
- 后九个描述符只保留死亡特效，完成后才进入本关终局剧情；表现过程不改变已经确定的伤害、经验、PRNG 或胜负。

### S00-M：战中记录、退出与音效同步

- `Esc` 根菜单按原文显示“遊戲功能／勝利條件／讀取記錄／儲存記錄／離開遊戲”；
- 战中保存后改变单位、焦点与视口，再读取同一槽，必须精确恢复回合、单位、焦点、视口和 PRNG；
- 离开游戏使用妮雅反馈肖像与原文，第一次主操作补全逐字文本，第二次才确认当前选择；
- 第 0 关脚本移动使用 `E/14`；地图普通攻击每次先攻/反击各在第一、第五帧请求 `E/38`；
- 全屏士兵起手只请求一次 `E/38`、冲刺只请求一次 `E/14`，骑兵投枪请求 `E/51` 且不附加士兵起手声；
- 全屏伤害 `<=10` 使用 `frame 3 + E/0` 格挡，伤害 `>10` 使用 `frame 1 + E/2` 常规受击；若生命归零，仍先完成对应阈值受击段，再进入 `frame 2 + E/11` 死亡段。

### S00-P：关前与战场背景音乐

- 首次用户输入解锁音频后，关前剧情循环播放 `MAGIC/73`；
- 完成或跳过关前剧情、进入妮雅脚本移动时，立即停止并复位 `MAGIC/73`，从头播放非循环的 `MUSIC/7`；其自然结束后自动切换并循环 `MUSIC/6`，游戏阶段不得因此推进；
- `[RI]` 从标题难度菜单确认新游戏时，确认键或点击本身必须同时解锁浏览器音频并立即开始 `MAGIC/73`；不得要求玩家进入关前剧情后再额外点击一次；
- 玩家与我方自动阶段保持当前 `7→6` 曲对；进入敌方阶段时从头执行 `MUSIC/5→4`；下一完整回合开始时重新执行 `MUSIC/7→6`；
- `M` 或“音乐”开关只暂停/恢复当前曲目；进入 `nextStage` 或确认退出后停止战场音乐。

### S00-N：终局反馈

- 失败使用 `D/46` 与原文“啊！．．．竟然失敗了？｜我太低辜敵人的實力，再給我一次機會吧！”；

- 两者按原版节奏逐字播放；第一次主操作只补全，下一次才重试或进入保存询问；
- 保存询问使用“確 定／取 消”，五槽选择位于原版坐标，覆盖已有槽不二次确认。

### S00-O：无测试夹具完整通关

- 从普通 `/` 启动，URL 不带 `?test=1`，全程不存在 `window.__ANGEL2__` 调试接口；
- 只用玩家输入跳过片头、确认“遊戲開始”和默认难度，再进入第 0 关关前剧情；
- 只使用剧情按钮、游戏功能菜单和“全部休息”等玩家可见输入完成关卡；

- 六名初始我方：妮雅、希蜜与四个职业回退的通用士兵；六者职业均为士兵、经验均为 0；

- 新手提示：`stableRemake` 首次进入默认启用一次非阻断提示，`legacyStrict` 关闭；
- 敌方意图：默认最多显示高层“向宫殿出口撤离”，不显示内部目标格。

- 敌方离场：三格楼梯均为出口；进入即移除，死亡与撤离共同计入全清胜利。
