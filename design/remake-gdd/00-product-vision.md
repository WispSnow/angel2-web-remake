# 产品愿景与体验支柱

## 一句话愿景

以现代浏览器重新呈现《天使帝国 II》的完整战役：玩家率领妮雅与持续成长、分支转职的部队，在紧凑的回合制战场上处理位置、地形、攻击顺序和职业能力，同时以原版像素美术、剧情节奏和 UI 构图保持可辨认的作品气质。

## 玩家幻想

- `[OF]` 玩家扮演瓦爾克麗军的指挥者，以妮雅为贯穿战役的关键角色，推进营救女帝及后续战争剧情。
- `[OF]` 单位在战役中保留成长，并通过职业分支形成长期队伍构成。
- `[DD]` 玩家应感觉自己在“带领一支逐渐成形的军队”，而不是操纵每关一次性棋子。
- `[DD]` 每回合的核心满足感来自看懂局面、选择行动顺序、利用职业差异并承受可预测的后果。

## 五项设计支柱

### 1. 原版身份优先

- `[DD]` 默认战役保留原版关卡、角色、剧情顺序、数值基线、地图、音乐音效、像素素材和主要 UI 构图。
- `[DD]` 现代化不能让表现设置改变战斗结果，也不能用“更合理”替换尚未核实的原版规则。

### 2. 确定而可解释的战术

- `[SR]` 同一规则集、存档状态和语义操作序列应得到相同结果。
- `[DD]` 玩家无需理解隐藏内存或动画分支；伤害类型、合法范围、免疫、行动是否提交等必须由界面给出一致反馈。
- `[DD]` 原版整数公式和取整顺序是玩法的一部分，除已确认修复外不做无证据“平滑化”。

### 3. 职业成长构成长期选择

- `[OF]` 原版含 39 个职业记录和 31 条可达普通转职边。
- `[DD]` 职业价值通过移动、地形、攻击方式、技术、成长曲线与队伍搭配共同体现，而不是只比较面板总值。
- `[DD]` 在完成原版战役基线验收前，不启动全局再平衡；平衡 Mod 与默认复刻分离。

### 4. 原貌 UI，现代使用条件

- `[OF]` 原版主战斗画面为 `640×350`，战场视口为 `10×7` 格，右侧是单位状态与回合信息区。
- `[DD]` 默认视觉构图、像素边缘、调色板和信息密度尽量复现原版。
- `[DD]` 浏览器缩放、全屏、音量、文本速度、输入重映射等属于外层便利功能，不改规则。

### 5. 复刻基线与 Mod 同时可维护

- `[DD]` 原版事实、默认修复版、严格兼容版和 Mod 不能混成一套不可追踪的“当前配置”。
- `[DD]` 每个可修改参数都有稳定身份、默认来源和规则版本；存档必须能说明自己由哪套规则产生。

## 玩家主要动词

| 层级 | 玩家动词 | 预期反馈 |
| --- | --- | --- |
| 战役 | 开始、继续、选择难度、观看/推进剧情、保存 | 明确当前关卡、规则集与存档状态 |
| 战前 | 查看目标、查看单位、选择出场、放置、撤下、确认 | 显示固定单位、上限、非法原因与预计阵容 |
| 战场 | 浏览、聚焦、查看、选择、移动、攻击、射击、使用技术、休息、结束阶段 | 合法范围、目标、代价、提交结果和回合状态清晰可见 |
| 成长 | 获得经验、升级、转职、比较职业 | 显示变化来源；转职不暗中治疗 |
| 系统 | 调整表现、保存/读取、退出、切换可选辅助信息 | 与模拟规则隔离，不造成隐藏差异 |
| Mod | 选择配置、检查冲突、开始独立存档线 | 规则来源和兼容性可追溯 |

## 产品范围

### 第一版完整复刻范围

- 原版可达主线、结局链与追加战；
- 原版 39 个职业、转职、成长、射击、技术、状态、地形、AI 与四档难度；
- 原版剧情、肖像、地图、战斗素材、音乐、音效和关键时间轴；
- 原版部署、战斗 HUD、目标、胜负、战后保存与五槽继续体验；
- 默认 `stableRemake` 与可选 `legacyStrict`；
- 可追溯的 Mod 配置与独立存档身份。

### 明确不作为目标

- `[DD]` 不模拟 DOS、VGA、PIT、越界写内存或 LZEXE 运行环境本身；
- `[DD]` 不照搬原程序模块边界、全局变量布局或文件格式作为内部架构；
- `[DD]` 不在基线复刻完成前新增职业、重写剧情或全面重平衡；
- `[DD]` 不把自动战斗、撤销、回溯或中途自由存档默认为原版玩法。

## 初始体验指标

以下均为待试玩验证的假设，不是原版事实：

- `[H]` 新玩家在第 0 关开始后的 3 分钟内能完成一次移动或攻击，无需外部说明书。
- `[H]` 玩家在打开行动菜单前，能从画面辨认当前单位、阵营、生命和回合。
- `[H]` 玩家在第一次失败时能说清失败条件，并在两次输入内进入同关重试。
- `[H]` 一场普通战斗的思考与演出节奏应以原版为基线，动画速度选项只缩短等待，不改变结算时点或结果。

## 产品完成定义

复刻不是以“画面能跑起来”为完成，而是同时满足：规则可验证、剧情可完整推进、关卡可从战前走到战后、UI 能解释规则、存档可恢复同一规则状态、原版素材呈现正确、默认修复与严格兼容差异可被测试。
