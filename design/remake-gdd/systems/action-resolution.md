# 战场动作结算规格

状态：`accepted`

授权日期：2026-07-29

用户接受日期：2026-08-01

依赖：职业目录、确定性 PRNG、移动、普通攻击、转职扫描、战场表现

## 玩家目的

玩家从职业命令中选择普通攻击、射击或技术，在提交前看到与规则完全一致的合法范围和目标；提交后无论动画速度、声音或资源加载状态如何，得到相同的确定性结果。

## 证据与决策

- `[OF]` 原版把普通攻击、射击和技术分为独立入口；成功提交后才设置行动位，取消恢复移动前位置且不消耗行动。证据见 [`shooting-and-technique-system.md`](../../../reverse/notes/shooting-and-technique-system.md)。
- `[OF]` 同一 `50×50` 数值范围图同时控制范围明暗和主操作合法性；表现层不得另算近似范围。证据见 [`battle-range-and-target-presentations.md`](../../../reverse/notes/battle-range-and-target-presentations.md)。
- `[OF]` 射击和五个主技术家族完成全部固定表现后才修改生命、状态、位置或治疗。
- `[SR]` 所有玩法随机来自版本化、可序列化的模拟 PRNG；表现不得消费模拟随机。
- `[DD]` Web 使用“预览 → 准备 → 表现 → 原子提交”边界。准备阶段用 PRNG 副本产生不可变结果和后继 PRNG 状态，不修改战场；提交时一次应用补丁和 PRNG。
- `[DD]` 表现资源缺失或播放失败时显示可见降级反馈并继续提交既定结果，不能卡住回合。

## 触发与输入

- 进入条件：玩家阶段、单位尚未行动、无阻断覆盖层、当前命令属于该职业。
- 合法行动者：当前选择的 side 1 单位；自动阶段由同一规则入口调用。
- 合法目标：动作定义的范围图非零格，并通过动作专用阵营、占用和免疫验证。
- 取消边界：目标提交前可取消；若已移动则回到移动后命令菜单，再次取消/返悔才恢复行动前位置。
- 提交时点：确认合法目标时准备结果并锁定输入；表现到达动作定义的提交标记时原子应用。

## 有序规则

1. 从职业目录构建语义命令；浏览菜单、范围或目标不得消费 PRNG。
2. 使用唯一数值范围图生成合法格；DOM 和 Phaser 只投影该结果。
3. 确认目标后在 PRNG 副本上计算伤害、治疗、经验、死亡和后继 PRNG 状态，产生 `PreparedAction`。
4. 锁定战场输入并播放动作表现；速度、减少动态和声音设置只改变等待或播放。
5. 在动作提交标记一次应用全部规则补丁、行动位和 PRNG。
6. 完成死亡移除、转职扫描、胜负、逐关事件与自动换阶段，顺序沿用转职系统合同。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 正常提交 | 应用准备结果并结束行动 | 状态栏显示伤害、治疗或经验摘要 |
| 无合法目标 | 不准备、不消耗 PRNG、不结束行动 | 原版无目标反馈及现代说明 |
| 取消 | 不改变模拟或 PRNG | 返回上一层；移动后可继续返悔 |
| 表现失败 | 仍提交同一准备结果 | 显示“表现资源缺失，已完成结算” |
| 致死 | 在动作规定的表现末点移除单位 | 播放对应死亡表现，再扫描转职/胜负 |
| 保存/读取 | 只允许非 busy 的玩家阶段保存 | 不保存 DOM/Phaser 对象或未提交表现 |

## AI 使用

AI 与玩家使用相同的合法性、准备和提交入口，只替换命令与目标选择器。AI 不得调用专用伤害公式或绕过状态、行动和 PRNG 边界。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 使用已确认修复和确定性准备/提交 |
| `legacyStrict` | 可保留安全、确定的原版怪癖；仍不得让表现改变规则 |
| 可开放 Mod 字段 | 动作列表、范围、目标过滤、效果参数、表现 ID；必须通过 schema 与确定性测试 |

## 表现与可访问性

密集菜单继续使用 DOM，范围、单位和地图特效由 Phaser 投影。当前菜单项、技术项和目标必须有可见焦点与完整可访问名称。减少动态可缩短等待或减少非必要中间帧，但必须保留目标、结果和提交反馈。

## 验收场景

1. Given 相同战场和 PRNG，When 分别以普通、加速、静音或减少动态提交同一动作，Then 最终单位、经验、行动位、死亡、转职队列和 PRNG 完全相同；
2. Given 已移动但未提交目标，When 取消目标并返悔，Then 单位回到原格且 PRNG、生命、经验和行动位不变；
3. Given 动作表现资源加载失败，When 提交合法动作，Then 显示降级反馈且规则结果与资源正常时相同。
