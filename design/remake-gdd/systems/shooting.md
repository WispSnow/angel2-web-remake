# 射击系统规格

状态：`accepted`

授权日期：2026-07-29

用户接受日期：2026-08-01

全职业数值复核日期：2026-08-08

依赖：战场动作结算、数值范围图、职业目录、地图特效、确定性 PRNG

## 玩家目的

弓兵、弩兵和魔弓兵可以在普通攻击之外从安全距离射击敌人。三种射击使用独立固定伤害，
不读取面板攻击、防御或地形防御；弩兵偏长程单体，魔弓兵偏线形多目标。

## 证据与决策

- `[OF]` 三种射击使用范围传播模式 2，清除射手格及四邻，最小曼哈顿距离均为 2；
  弓兵／弩兵／魔弓兵的 seed 为 `5／8／6`，实际最大距离为 `4／7／5`，并受不可传播地形阻断。
- `[OF]` 玩家只能确认范围内敌军格。射击不读取普通攻防或地形防御，也不触发反击。
- `[OF]` 弓兵固定伤害 `30..49`、经验 `8..11`；弩兵伤害 `70..89`；魔弓先取
  `50..69`，选中目标受两次半伤 `50..68`，其他合资格线格受一次半伤 `25..34`。
  弩兵／魔弓经验均为 `13..17`；三者击杀时另加目标职业基础奖励。
- `[OF]` 弓/弩通用表现为 `UN/60`：空白、八帧扩张圈、空白，每阶段 6 native ticks；处理器内没有直接音效。固定画面完成后才逐点扣除生命，每成功扣 1 点重画一次并等待 1 native tick。
- `[OF]` 射击不读取“戰鬥動畫”开关，始终在棋盘表现。
- `[SR]` 迅龍騎士的 PIT 低位完全闪避分支以确定性模拟 PRNG 复现为约 50% 候选，作用于
  弓、弩、魔弓三种射击。
- `[SR]` 依 `REMAKE-009`，同一射击 action definition 不因阵营或人工／AI 控制改变。
  原版 AI 弩兵 `50..89`、AI 魔弓基础值 `50..59` 只保留在 `originalFacts/legacyStrict`；
  `stableRemake` 敌我均使用上述玩家值域。
- `[SR]` 依 `REMAKE-006` 保留魔弓的两次半伤结构和逐段防魔时序，不合并为一次总伤。

## 触发与输入

- 进入条件：射击职业尚未行动，在初始或移动后命令菜单选择“射擊”。
- 合法行动者：职业 `archer`、`crossbow` 或 `magic-archer`，动作 ID 分别为
  `archer-shot`、`crossbow-shot`、`magic-archer-shot`。
- 合法目标：模式 2 范围图非零且格上为敌军。
- 取消边界：取消目标不结束行动；移动后取消回到移动后菜单。
- 提交时点：确认目标后准备伤害；对应固定图形阶段结束后先以只读显示生命逐点下降，走到终值才原子提交。

## 有序规则

1. 以射手格为原点、当前动作 seed 和模式 2 建立数值范围图。
2. 清除原点和四个正交邻格；过滤敌军目标。
3. 无目标则返回命令菜单；单目标可自动锁定，多目标进入手动选择。
4. 按 action definition 准备固定值域伤害、经验和迅龍闪避；魔弓另建立射手到目标的路径，
   对路径上的合资格敌军分别准备一次／两次半伤与防魔消费。
5. 弓／弩播放完整 `UN/60`，魔弓播放 `UN/60 + MAGIC/83` 线形时间轴。
6. 显示生命按已准备结果逐点下降；期间模拟生命、经验、行动位与 PRNG 后态尚未提交。
7. 时间轴完成后原子写入全部受影响单位生命、状态、经验、死亡移除和射手行动位，再进入转职和胜负顺序。

## 状态变化与边界

| 情况 | 结果 | 反馈／结算记录 |
| --- | --- | --- |
| 弓兵命中 | 目标损失 `30..49`，无反击 | 扩张命中圈结束后，棋子生命数字逐点降至结果值 |
| 弩兵命中 | 目标损失 `70..89`，无反击 | 与弓兵共用命中圈，结算读取弩兵动作值域 |
| 魔弓命中 | 目标 `50..68`，其他合资格线格 `25..34` | 结算数据区分目标、沿线单位及总伤害 |
| 迅龍闪避 | 本次射击伤害为 0 | 显示闪避结果，不公开未来随机值 |
| 魔弓遇防魔 | 目标挡第一段、受第二段；其他带盾线格为 0，盾被消费 | 分段反馈，不能显示为整次免疫 |
| 地形阻断 | 格不进入范围图 | 原生网点压暗，点击无提交 |
| 无目标 | 不消耗行动或 PRNG | “射擊範圍內沒有敵人” |
| 致死 | 追加击杀奖励并在表现后移除 | 地图死亡表现 |
| 保存/读取 | 职业派生出相同射击能力 | 不保存临时范围图或表现帧 |

## AI 使用

我方自动和敌方 AI 使用原版射手目标／落点意图，并应用 `REMAKE-002`：当前格就是最佳射击位
时直接原地射击。目标优先有效防御最低，同值取当前生命最低；结算调用与玩家相同的 action
definition。`stableRemake` 不保留原版 AI 弩兵／魔弓的较弱随机值域。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 修复原地最佳却跳过射击；三种射击敌我共用玩家 action definition |
| `legacyStrict` | 可保留原地最佳时跳过射击，并恢复 AI 弩兵 `50..89`、AI 魔弓基础值 `50..59` |
| 可开放 Mod 字段 | seed、最小距离、伤害值域、线形倍率、经验值域、表现 ID |

## 表现与可访问性

合法格保持完整地形，非法格使用原生 25% 网点掩码。射击菜单和目标提示必须区分“攻擊”与“射擊”。动画加速只压缩固定画面和逐点扣血等待，不改变伤害、经验、死亡或 PRNG。

## 验收场景

1. Given 弓兵与敌军曼哈顿距离 4 且路径可传播，When 提交射击，Then 造成 `30..49`、无反击、获得 `8..11` 加可能的击杀奖励并结束行动；
2. Given 弩兵与魔弓兵的职业内 1 级面板攻击均为 52，When 分别射击同一普通目标，Then
   弩兵造成 `70..89`，魔弓目标造成 `50..68`，且结果不读取该 52 点攻击；
3. Given 相同 PRNG 状态和镜像敌我射手，When 在 `stableRemake` 分别提交弩射或魔弓射击，
   Then 两侧使用同一 action definition 并得到相同伤害；`legacyStrict` 才恢复原版 AI 值域；
4. Given 魔弓路径上还有其他敌人，When 射击，Then 目标受两次半伤、其他线格受一次半伤，
   结算记录分别保留目标、各沿线单位和合计伤害；
5. 同一射击在全景开／关、正常／加速、静音／有声下产生完全相同的模拟结果。
