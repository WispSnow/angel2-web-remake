# 射击系统规格

状态：`accepted`

授权日期：2026-07-29

用户接受日期：2026-08-01

依赖：战场动作结算、数值范围图、职业目录、地图特效、确定性 PRNG

## 玩家目的

弓兵可以在普通攻击之外从安全距离射击敌人，以固定职业伤害换取远程覆盖；射击与近战保持不同范围、结算、经验和表现身份。

## 证据与决策

- `[OF]` 弓兵 `3A` 使用范围传播模式 2、原生 seed 5；清除射手格及四邻后，实际可选曼哈顿距离为 `2..4`，并受不可传播地形阻断。
- `[OF]` 玩家只能确认范围内敌军格；伤害为 `30..49`，不读取普通攻防或地形防御。
- `[OF]` 固定经验为 `8..11`，击杀时另加目标职业基础奖励；射击不触发反击。
- `[OF]` 弓/弩通用表现为 `UN/60`：空白、八帧扩张圈、空白，每阶段 6 native ticks；处理器内没有直接音效。固定画面完成后才逐点扣除生命，每成功扣 1 点重画一次并等待 1 native tick。
- `[OF]` 射击不读取“戰鬥動畫”开关，始终在棋盘表现。
- `[SR]` 迅龍騎士闪避保留条件分支，但 M00.6 第 0 关没有该目标，不额外开放其职业内容。
- `[DD]` 本切片只实现弓兵射击；弩兵、魔弓兵只保留目录元数据，不开放运行时动作。

## 触发与输入

- 进入条件：弓兵尚未行动，在初始或移动后命令菜单选择“射擊”。
- 合法行动者：职业 `archer`。
- 合法目标：模式 2 范围图非零且格上为敌军。
- 取消边界：取消目标不结束行动；移动后取消回到移动后菜单。
- 提交时点：确认目标后准备伤害；`UN/60` 固定图形阶段结束后先以只读显示生命逐点下降，走到终值才原子提交。

## 有序规则

1. 以射手格为原点、seed 5 和模式 2建立数值范围图。
2. 清除原点和四个正交邻格；过滤敌军目标。
3. 无目标则返回命令菜单；单目标可自动锁定，多目标进入手动选择。
4. 准备 `damage=random(30..49)` 与 `experience=random(8..11)+击杀奖励`。
5. 播放完整 `UN/60` 固定图形时间轴。
6. 目标棋子下方的显示生命按实际伤害逐点下降，每点保持 1 native tick；期间模拟生命、经验、行动位与 PRNG 后态尚未提交。
7. 显示生命到达终值后，原子写入生命、经验、死亡移除和射手行动位，再进入转职和胜负顺序。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 命中 | 目标损失 `30..49`，无反击 | 扩张命中圈结束后，棋子生命数字逐点降至结果值 |
| 地形阻断 | 格不进入范围图 | 原生网点压暗，点击无提交 |
| 无目标 | 不消耗行动或 PRNG | “射擊範圍內沒有敵人” |
| 致死 | 追加击杀奖励并在表现后移除 | 地图死亡表现 |
| 保存/读取 | 职业派生出相同射击能力 | 不保存临时范围图或表现帧 |

## AI 使用

我方自动弓兵使用原版射手目标/落点意图，并应用 `REMAKE-002`：当前格就是最佳射击位时直接原地射击。目标优先有效防御最低，同值取当前生命最低；结算仍调用同一射击入口。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 修复原地最佳却跳过射击，其他弓兵规则保持原版 |
| `legacyStrict` | 可保留原地最佳时跳过射击 |
| 可开放 Mod 字段 | seed、最小距离、伤害值域、经验值域、表现 ID |

## 表现与可访问性

合法格保持完整地形，非法格使用原生 25% 网点掩码。射击菜单和目标提示必须区分“攻擊”与“射擊”。动画加速只压缩固定画面和逐点扣血等待，不改变伤害、经验、死亡或 PRNG。

## 验收场景

1. Given 弓兵与敌军曼哈顿距离 4 且路径可传播，When 提交射击，Then 造成 `30..49`、无反击、获得 `8..11` 加可能的击杀奖励并结束行动；
2. Given 敌军距离 1、5 或被不可传播地形隔断，When 打开射击，Then 该目标不可提交且不消耗 PRNG；
3. 同一射击在全景开/关、正常/加速、静音/有声下产生完全相同的模拟结果。
