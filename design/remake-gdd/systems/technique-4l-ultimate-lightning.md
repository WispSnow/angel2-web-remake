## 玩家目的

第三层魔法師在七步内指定一名未冰封敌军。细雷从目标上方八行逐格下降，再在目标格形成
七行高的完整雷柱；五圈错相电波和全敌共同收尾完成后，按范围值对未冰封敌军造成
`30/50/70/90/110` 伤害。完整 304 native tick 后才原子结算；防魔只挡本单位本次伤害
并被消费，经验只来自实际击杀奖励。

## 证据与决策

- `[OF]` 魔法師 `1L` 第一／二／三层玩家菜单及 AI 池分别只有 `2L/3L/4L`；`4L` 只属于
  第三层。魔術士和魔祭師菜单里的 `1L` 是初級落雷，不能按名称混用。
- `[OF]` 玩家分发表的 `4L` 选择距离为 7，AI 动作表为 6。依 `REMAKE-009`，
  `stableRemake` 的玩家、我方自动与敌方 AI 统一使用玩家参数 7；`legacyStrict` 可保留 7/6。
- `[OF]` 以选中格为中心建立曼哈顿菱形，效果半径 5；范围值 `1/2/3/4/5` 分别造成
  `30/50/70/90/110` 伤害，即中心 110、最外圈 30。处理顺序为行优先线性格顺序，不读取
  攻击、防御或地形防御。
- `[OF]` 范围内每个敌军的防魔最高位阻挡本单位全部伤害，结算后清除；无防魔时按当前
  生命饱和扣除。经验没有固定或随机项，只累加实际击杀单位的职业奖励，动作不调用 PRNG。
- `[SR]` 依 `REMAKE-013`，冰封主目标非法；被其他合法中心覆盖的冰封敌军完整跳过，
  不受伤、不清防魔、不死亡、不提供击杀经验。冰壳持续投影在所有雷柱、电波和共同收尾
  之上；`legacyStrict` 可保留冰雪仅禁行动、仍受范围伤害的原版行为。
- `[OF]` 0 tick 请求一次 `E/43`。主体 A 使用 `MAGIC/39` 的两项 `1×7` 描述符循环九轮、
  每项 3 tick，共 18 draw／54 tick；锚点从目标行 `−8` 到 `0`，每行恰好两项。
- `[OF]` 第九轮后绘制锚点已位于目标行 `+1`，后续不重置：主体 B 使用 `MAGIC/39`
  四项×10 tick，主体 C 使用 `MAGIC/40` 三项循环两轮、六项×10 tick，主体 D 将 B 的
  四项逆序播放、四项×10 tick。三段描述符高 7 行且 `yOffset=−7`，所以底端精确落在
  目标行；主体共 `18+4+6+4=32` draw／194 tick。
- `[OF]` 公共电波 `MAGIC/26` 的 runtime tile code 为 `12/13`。半径最大值减一为 4，
  波宽 11，共 15 轮 A/B；每次 draw 都把范围阈值减一并等待 2 tick，共 30 draw／60 tick。
  随后 `MAGIC/6` 五阶段在效果范围内的敌方占用格绘制、每项 10 tick，共 50 tick。
- `[OF]` 电波是两层：扫描层对范围带内的每个效果格按该格 `范围值 − 当前阈值` 取
  `MAGIC/26` 帧 `0..10`，不分阵营与占用；标记层再对同一带内的敌方占用格交替叠加 tile code
  `12/13`（帧 `11/12` 的角色触电美术），按 `REMAKE-049` 恢复。
- `[OF]` 固定等待总计 `194+60+50=304` tick；全部画面结束后才逐单位执行一次饱和减法，
  不走炎暴的逐点扣血路径。共同收尾覆盖效果范围内的全部敌军，范围外既不受伤也不绘制。
- `[OF]` 第三层魔法師 AI 池只有 `4L`，使用组 11 原文“看我的雷電魔法.”，并按有效防御、
  当前生命、路径与线性格顺序选择单一主目标，不为扩大范围覆盖人数另选中心。
- `[OF]` 后期 Boss 双手和场景 42 脚本直接复用完整 `4L` 处理器／304 tick 表现；双手的
  随机候选、落雷／炎暴交替及场景 42 剧情清格仍属于冻结的后续战役内容。本动作实现只
  提供可复用定义，不提前建立这些关卡流程。

## 触发与输入

- 魔法師只在第三层显示“究級落雷”；第一／二层分别只使用 `2L/3L`，不得回退显示低阶。
- 行动者必须未行动、未冰封且未被禁咒；目标必须是统一距离 7 内的未冰封敌军。防魔
  敌军仍是合法目标。
- 取消目标回技术菜单，再取消回动作菜单；不提交行动位、生命、防魔、经验或 PRNG。
- 确认时冻结 `{效果中心, 五圈范围图, 行优先接收者, 每单位伤害／阻挡, 击杀经验}`；
  表现、声音、镜头、墙钟与资源载入顺序都不能重算准备结果。

## 有序规则

1. 验证第三层魔法師、行动位、冰封、禁咒、敌方目标与统一选择距离 7；
2. 以选中格建立半径 5 范围图，并按行优先扫描范围内敌军；
3. 冰封接收者完整跳过且保留防魔；其他接收者若有防魔则伤害为 0 并准备清盾；
4. 无防魔接收者按范围值取 `30/50/70/90/110`，再按当前生命饱和；只为实际归零者累加
   击杀奖励；
5. 保存完整准备结果；整个动作不调用模拟 PRNG；
6. 0 tick 请求 `E/43`，播放 `MAGIC/39` 九轮下降细雷，共 18×3 tick；
7. 沿用目标行 `+1` 锚点播放 `MAGIC/39` 四项、`MAGIC/40` 六项、`MAGIC/39` 逆序四项，
   共 140 tick；
8. 播放 `MAGIC/26` 15×2 draw×2 tick，再在所有敌方占用格播放 `MAGIC/6` 5×10 tick；
9. 304 tick 后原子提交生命、防魔、击杀经验与行动位，再执行死亡、胜负和阶段后置链。

## AI 使用

第三层魔法師原版池只有 `4L`。AI 从当前位置按 `stableRemake` 统一距离 7 查找未冰封敌军，
仍沿用原版单目标评分，不为覆盖更多单位改变主目标。成功时显示组 11 原文、对焦准备中心、
播放同一 304 tick 时间线并走共同原子提交；无候选时回退普通移动／攻击／休息。动画和
提示不消费模拟 PRNG。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 玩家与 AI 距离 7；冰封主目标非法、范围覆盖完整跳过；其余数值与表现保持原版 |
| `legacyStrict` | 玩家距离 7、AI 距离 6；冰封单位仍可受范围伤害；其余公式与时间线相同 |
| 可开放 Mod 字段 | 职业层级、选择／效果半径、五圈伤害、防魔语义、资源／描述符／锚点／声音／等待；修改后必须改变规则身份 |

## 表现与可访问性

正式地图与 technique-lab 必须共用 `MAGIC/39/40/26/6` 的原版描述符和逐档资源。前 18 项
必须以 `−8..0` 锚点逐行下降，后三段必须继承目标行 `+1`；不能把 32 项固定在目标格，
也不能复用或换色 `3L`。`MAGIC/26` 运行时 tile code 必须是 `12/13`；`MAGIC/6` 每阶段
在效果范围内的敌方占用格绘制后只等待一次。原始像素禁用平滑。加速、减少动态、静音和 AI 对话
开关只能改变墙钟、声音或提示，不能改变 32 次主体 draw、30 次电波、5 次收尾、304 tick、
准备结果或提交时点。

## 验收场景

1. 三层魔法師分别只显示／规划 `2L/3L/4L`；`4L` 仅第三层可用，玩家与双方 AI 的目标
   距离均为 7；
2. 中心至最外圈五名无盾目标分别承受 `110/90/70/50/30`，第六圈不受影响；低生命按
   当前值饱和；
3. 防魔单位伤害 0 且提交后清盾；冰封单位生命、防魔、死亡与行动位不变，不提供经验；
4. 多个击杀只累加职业击杀奖励；有／无击杀均不改变模拟 PRNG 状态或调用数；
5. AI 使用组 11“看我的雷電魔法.”并按原版单目标评分，不按范围覆盖人数优化；
6. 正式玩家与 AI 在 0 tick 请求 `E/43`，播放 32 个主体、30 个错相电波和 5 个范围内收尾；
   304 tick 前生命、防魔、经验和行动位不提交；
7. 细雷九轮锚点严格为 `−8..0` 各两项；完整七行雷柱沿用 `+1` 锚点且底端命中目标格；
   电波只出现在扫描带敌军，共同收尾覆盖范围内外敌军，持续冰壳全程高于落雷效果；
8. technique-lab 与正式竞技场的主体、电波、收尾帧和规则读数一致，代表截图确认不是
   `3L` 换色、固定锚点或把共同收尾误判为范围外伤害。
