# 全局程序暂停

状态：功能增强 / 已实现并通过定向验收

负责人：Web 复刻实现

依赖：语义输入、宿主选单（`src/game/host-menu.ts`）、表现时钟、Phaser、Web Audio

## 玩家目的

玩家可像使用 DOSBox 的 Pause 一样临时冻结整个游戏，在不丢失当前演出时点、行动选择或音乐位置的情况下离开屏幕，回来后从同一拍继续。

## 证据与决策

- `[OF]` 原版游戏内没有已取证的全局暂停菜单；DOSBox Pause 属于模拟器宿主能力，不是《天使帝国 II》的战斗规则。
- `[DD]` Web 复刻新增独立于 `640×350` 原版构图的全局暂停。它是功能增强，不进入模拟状态、PRNG、规则身份或存档。
- `[DD]` 用户于 2026-11-22 决定拿掉画面下方的宿主工具列，改由逻辑画面右下角的小图标呼出宿主选单：
  打开选单就是暂停，选单直接画在暂停层上，原来的独立「暫停」按钮与「遊戲已暫停」对话框不再出现在
  正常游戏里（没有宿主选单的表面仍以那个对话框作为后备）。「復刻說明／圖鑑／RoadMap」改为只能从
  暂停中的选单打开，因此打开期间游戏一直保持暂停；这取代了此前「资料层不暂停游戏」的约定。

## 触发与输入

- 进入条件：标题、剧情、部署、战场、结局和制作人员表等已挂载游戏表面均可暂停；资源载入本身不因暂停取消。
- 合法行动者：当前浏览器玩家。
- 合法目标：整个游戏程序的语义与表现时间线。
- 进入方式：点逻辑画面右下角的选单入口，或按 `P`／`Pause`（可编辑栏位之外的任何地方）。
- 取消边界：暂停层打开后，`P`、`Pause`、选单的「繼續遊戲」、入口位置上的红宝石或点选单以外的暗处
  直接恢复；`Esc`（或右键、`Backspace`）逐层返回——先收起子选单，再关闭从选单打开的资料层并把焦点
  交还选单里的入口，最后才恢复。其余键盘、鼠标、触控和手柄游戏输入不得穿透到底层。
- 提交时点：触发暂停的同一输入事件立即建立冻结边界；恢复输入只撤销冻结，不提交底层动作。

## 有序规则

1. 捕获全局暂停输入并阻断同一输入继续传播；
2. 固定程序时钟，保留全部未完成等待的剩余时间；
3. 暂停 Phaser 更新／输入／绘制、DOM/CSS/Web Animation、对白逐字、肖像与结局时间线；
4. 挂起音乐和音效的 Web Audio 时钟，使正在播放的声音停在当前采样位置；
5. 显示暂停层与其中的宿主选单；只有选单和从选单打开的资料层（标记 `data-program-pause-exempt`）接收输入；
6. 恢复时按原剩余时间和原音频位置继续，不补跑暂停期间的帧、计时或输入。

浏览器的网络请求、图片／音频解码和持久缓存可以在后台完成；它们不属于游戏时间。完成结果可以进入就绪状态，但不得让受程序时钟约束的剧情、战斗、结局或片尾序列越过当前语义节点。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 正常暂停 | 模拟、PRNG、表现与声音均不推进 | 暗化的画面上显示宿主选单，焦点在「繼續遊戲」 |
| 动画／对白中暂停 | 保留当前帧、已显示文字和剩余等待 | 恢复后从同一帧／下一个字继续 |
| 敌方／自动行动中暂停 | 当前已提交节点保留，其后节点不执行 | 恢复后继续原行动链 |
| 暂停时输入 | 只有选单、资料层与恢复动作有效 | 其他输入被暂停层消费 |
| 资料层打开 | 游戏保持暂停；关闭后回到选单 | `P`／`Pause` 直接恢复并关闭资料层 |
| 保存／读取 | 暂停状态不写入存档，也不改变存档语义 | 恢复后仍是原存读档表面 |

## AI 使用

AI 不使用暂停动作。暂停期间 AI 规划与行动消费者不得推进；恢复后继续原确定性行动链，不重新规划、不增加 PRNG 调用。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 使用相同全局暂停合同 |
| `legacyStrict` | 使用相同全局暂停合同；这是宿主增强，不伪装成原版规则 |
| 可开放 Mod 字段 | 无；Mod 不得绕过全局冻结边界 |

## 表现与可访问性

入口是画在逻辑画面右下角 `(618,327)` 的 20×20 小图标（原版系统选单角落的蓝宝石），平时只显示 30%，
指针悬浮、键盘聚焦或选单打开时完整显示；它是 DOM 层，不画进 Canvas。暂停层是页面级的暗幕，宿主选单
在其中按画面倍率整组放大并居中，外框借用原版系统选单与勝利條件面板的素材，文字用现代字体。打开时底层
页面进入 `inert`，焦点移到「繼續遊戲」；恢复后焦点回到暂停前的控件。选单有「遊戲暫停」标题、当前项目
的说明框和按键提示，不依赖颜色表达状态。

## 验收场景

1. Given 敌方或表现时间线正在推进，When 按 `P`，Then 等待超过原节点时长后，模拟快照、当前帧和程序时钟仍不变；恢复后才继续；
2. Given 对白正在逐字且音乐／音效正在播放，When 暂停，Then 字数、肖像帧和 Web Audio 时钟不再前进；恢复后从原位置继续；
3. Given 暂停层打开，When 输入移动、确认、取消或手柄动作，Then 战场与菜单状态不变；`P`、`Pause`、`Esc` 或「繼續遊戲」只恢复、不提交底层动作；
4. Given 从选单打开了资料层，When 等待超过敌方阶段时长，Then 回合不推进；`Esc` 关闭资料层并回到选单，`P` 直接恢复；
5. 暂停与恢复不改变模拟状态、PRNG、存档内容、规则身份或相同操作序列的战果。
