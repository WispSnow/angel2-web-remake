# 全局程序暂停

状态：功能增强 / 已实现并通过定向验收

负责人：Web 复刻实现

依赖：语义输入、宿主工具列、表现时钟、Phaser、Web Audio

## 玩家目的

玩家可像使用 DOSBox 的 Pause 一样临时冻结整个游戏，在不丢失当前演出时点、行动选择或音乐位置的情况下离开屏幕，回来后从同一拍继续。

## 证据与决策

- `[OF]` 原版游戏内没有已取证的全局暂停菜单；DOSBox Pause 属于模拟器宿主能力，不是《天使帝国 II》的战斗规则。
- `[DD]` Web 复刻新增独立于 `640×350` 原版构图的全局暂停。它是功能增强，不进入模拟状态、PRNG、规则身份或存档。
- `[DD]` 暂停不等于「復刻說明／圖鑑／RoadMap」覆盖层：三个资料层继续保持不暂停游戏；只有明确的「暫停」动作建立冻结边界。

## 触发与输入

- 进入条件：标题、剧情、部署、战场、结局和制作人员表等已挂载游戏表面均可暂停；资源载入本身不因暂停取消。
- 合法行动者：当前浏览器玩家。
- 合法目标：整个游戏程序的语义与表现时间线。
- 取消边界：暂停层打开后，仅 `P`、`Pause`、`Esc` 或「繼續遊戲」恢复；其余键盘、鼠标、触控和手柄游戏输入不得穿透到底层。
- 提交时点：触发暂停的同一输入事件立即建立冻结边界；恢复输入只撤销冻结，不提交底层动作。

## 有序规则

1. 捕获全局暂停输入并阻断同一输入继续传播；
2. 固定程序时钟，保留全部未完成等待的剩余时间；
3. 暂停 Phaser 更新／输入／绘制、DOM/CSS/Web Animation、对白逐字、肖像与结局时间线；
4. 挂起音乐和音效的 Web Audio 时钟，使正在播放的声音停在当前采样位置；
5. 显示唯一仍可接收输入的现代暂停层；
6. 恢复时按原剩余时间和原音频位置继续，不补跑暂停期间的帧、计时或输入。

浏览器的网络请求、图片／音频解码和持久缓存可以在后台完成；它们不属于游戏时间。完成结果可以进入就绪状态，但不得让受程序时钟约束的剧情、战斗、结局或片尾序列越过当前语义节点。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 正常暂停 | 模拟、PRNG、表现与声音均不推进 | 页面级「遊戲已暫停」层与继续按钮 |
| 动画／对白中暂停 | 保留当前帧、已显示文字和剩余等待 | 恢复后从同一帧／下一个字继续 |
| 敌方／自动行动中暂停 | 当前已提交节点保留，其后节点不执行 | 恢复后继续原行动链 |
| 暂停时输入 | 仅恢复动作有效 | 其他输入被暂停层消费 |
| 保存／读取 | 暂停状态不写入存档，也不改变存档语义 | 恢复后仍是原存读档表面 |

## AI 使用

AI 不使用暂停动作。暂停期间 AI 规划与行动消费者不得推进；恢复后继续原确定性行动链，不重新规划、不增加 PRNG 调用。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 使用相同全局暂停合同 |
| `legacyStrict` | 使用相同全局暂停合同；这是宿主增强，不伪装成原版规则 |
| 可开放 Mod 字段 | 无；Mod 不得绕过全局冻结边界 |

## 表现与可访问性

暂停层使用现代字体和复刻版酒红／鎏金宿主风格，位于逻辑画布之外的页面层。打开时底层页面及已有资料覆盖层进入 `inert`，焦点移到「繼續遊戲」；恢复后焦点回到暂停前的控件。暂停层提供清晰标题、冻结范围说明和键盘恢复提示，不依赖颜色表达状态。

## 验收场景

1. Given 敌方或表现时间线正在推进，When 按 `P`，Then 等待超过原节点时长后，模拟快照、当前帧和程序时钟仍不变；恢复后才继续；
2. Given 对白正在逐字且音乐／音效正在播放，When 暂停，Then 字数、肖像帧和 Web Audio 时钟不再前进；恢复后从原位置继续；
3. Given 暂停层打开，When 输入移动、确认、取消或手柄动作，Then 战场与菜单状态不变；`P`、`Pause`、`Esc` 或继续按钮只恢复、不提交底层动作；
4. 暂停与恢复不改变模拟状态、PRNG、存档内容、规则身份或相同操作序列的战果。
