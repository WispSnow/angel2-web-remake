# 移动结界与外圈生命减半

状态：M05 纸面合同已闭合／实现冻结

负责人：Web 复刻实现

依赖：[`stage-04.md`](../vertical-slices/stage-04.md)、
[`force-ai-groups.md`](force-ai-groups.md)、`REMAKE-023`

## 玩家目的

玩家要让队伍跟随自动前进的葛蒂拉斯穿过强化力场。葛蒂拉斯周围的小范围结界是安全区；
她每次尝试前进后，安全区外的我方单位都会损失一半当前生命。玩家需要在部署时判断首轮
站位，并在后续回合持续跟进，而不是把它误解为普通敌方攻击或防魔可以抵消的法术。

## 证据与决策

- `[OF]` [`behavior12-stage-effects.md`](../../../reverse/notes/behavior12-stage-effects.md) 与
  [`behavior12-effects.json`](../../../reverse/parsed/native/behavior12-effects.json) 的 `stage4`
  闭合了行动者、路线、范围、取整、死亡与 `MAGIC/26` 表现。
- `[OF]` side 1 槽 24“葛蒂拉斯／魔術士”使用行为 `12`：目标格 `125`、本次移动值 `3`，
  只有寻路结果格号小于原格号时才实际移动；无论是否移动，随后都运行一次结界效果。
- `[OF]` 安全区由行动者尝试后的格为中心，以模式 `0`、seed `3` 构造；普通地形上等价于
  路径代价不超过 `2`。范围不按占用阻断，但当前职业移动规则值为 `99` 的地形仍不可达。
- `[OF]` 范围反转后只处理 side-map 字节恰为 `1` 的单位；目标当前生命变为
  `floor(currentLife / 2)`，不读取或消耗防魔，也不读取攻、防、地形防御、最大生命或经验。
  生命 `1` 会降至 `0` 并由公共收尾立即离场。
- `[OF]` 表现使用 `MAGIC/26`、格码 `12/13`，共 `11 × 2 × 2 = 44` native tick；
  处理器没有直接 VOC 请求。传入的 `CX=40` 没有消费者，不是伤害值。
- `[SR]` `REMAKE-023` 保留全部结算与合法部署格，但默认 UI 提前显示首轮／当前安全区和
  “区外当前生命减半”说明；危险格不被禁用，也不自动替玩家换位。
- `[DD]` 模拟层把该机制表达为参数化的“路线尝试后范围效果”，关卡内容绑定行动者、路线、
  范围、生命变换和表现键；控制器、Phaser 与 UI 不按关卡号或角色名重新实现结算。

## 触发与输入

- 进入条件：第 4 关 side 1 独立 AI 军团轮到槽 24 行动，且该单位仍在场并可行动。
- 合法行动者：关卡内容指定的唯一行动者 `side 1 / slot 24`；玩家不能直接控制或替它选路。
- 合法目标：结界效果不进入目标选择 UI；结算时选取当前安全区外且 side-map 为 `1` 的单位。
- 取消边界：玩家只能在自己的未提交行动中取消；独立 AI 路线一旦开始表现就不能取消。
- 提交时点：路线结果先提交到模拟；以提交后的行动者格准备完整效果结果；44-tick 表现完成后
  原子提交生命变化、离场与行动消耗。动画加速或跳过只能压缩等待。

## 内容字段合同

| 字段 | 第 4 关值 | 通用边界 |
| --- | --- | --- |
| `kind` | `route-pulse` | 有类型的特殊行动分派，不读取 `stageId` |
| `actor` | side 1 / slot 24 | 构造时验证单位存在、阵营与军团一致 |
| `route` | goal `125`、movement `3`、只接受更小格号 | 路线器只返回规范移动结果 |
| `safeArea` | mode `0`、seed `3`、效果取反区 | 范围服务负责地形与整数传播 |
| `effect` | side 1、当前生命 `1/2`、向下取整 | 生命变换不读取表现或角色身份 |
| `presentation` | `stage-04-force-field-pulse` | 动作目录再绑定 `MAGIC/26` 与 44 tick |

关卡生成内容是这些参数的唯一来源。模拟结果事件至少携带行动者起止格、安全格集合、受影响
单位及前后生命；表现层只消费事件，不重新扫描棋盘来决定目标。

## 有序规则

1. 验证行动者仍在场、未完成本回合行动，并记录原格；
2. 使用目标格 `125` 和临时移动值 `3` 计算一次行为 `12` 路线，不调用普通攻击、射击或技术；
3. 仅当结果格号小于原格号时提交移动，否则保持原地；两种结果都继续后续步骤；
4. 以行动者提交后的当前格为中心执行模式 `0`、seed `3` 的范围传播，再把安全／效果区反转；
5. 按稳定单位顺序收集效果区内 side-map 恰为 `1` 的单位，准备每个目标的
   `floor(currentLife / 2)`；本动作不消费 PRNG；
6. 发出带 `stage-04-force-field-pulse` 表现键的准备结果；44 native tick 表现可缩放或跳过；
7. 原子写入全部生命，运行公共死亡／离场收尾，再消耗葛蒂拉斯本次行动；
8. 由通用目标检查器按提交后的棋盘判断失败或胜利，表现层不得提前写 `999`。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 正常移动 | 葛蒂拉斯向更小格号移动，再结算外圈 | 先跟随移动，后绘制区外 `MAGIC/26` |
| 无法移动／结果不向上 | 葛蒂拉斯原地，效果仍触发 | 明确显示“結界未前進，力場仍發動” |
| 安全区内我方 | 生命不变 | 安全格保持绿色轮廓，不绘制命中特效 |
| 安全区外我方 | 当前生命向下减半 | 命中特效结束后一次更新生命 |
| 敌方单位 | 不属于 side 1，完全不受影响 | 不绘制命中特效 |
| 防魔或高防御 | 不读取、不消耗，不能减伤 | 详情说明“力場：防魔無效” |
| 生命为奇数／为 1 | 如 `9→4`；`1→0` 后离场 | 数值与离场在同一提交点投影 |
| 保存/读取 | 保存移动后位置、生命、回合与完整 PRNG；定义由内容版本重建 | 读取后下一次行动结果一致 |

## AI 使用

葛蒂拉斯属于独立友军军团，行为 `12` 只选择上述路线，不进入职业行动池；其路线尝试完成后
统一调用参数化范围效果结算器。两名敌军继续使用既有 `native` 职业 AI，不会主动调用或
抵抗该效果。玩家军团的集团命令不能接管葛蒂拉斯，也不能改变她的目标格或移动值。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 原版路线、范围和减半结算；提前显示安全区与风险说明 |
| `legacyStrict` | 同一机器结算；不提供现代安全区预览，只保留剧情警告与原版表现 |
| 可开放 Mod 字段 | 行动者、路线目标、移动值、接受方向、范围 mode/seed、目标阵营、生命比例、取整和表现键 |

改变任何结算字段、触发频率或目标顺序都必须改变规则／内容身份。Mod 字段仍须经过范围、阵营、
分母非零与表现资源验证；不能把任意脚本回调注入模拟层。

## 表现与可访问性

部署页选中六个部署格时显示首轮安全轮廓；`(23,40)` 与 `(27,40)` 显示“首輪力場區外：
目前生命減半”，但仍可合法放置。战斗中选择葛蒂拉斯、打开目标详情或聚焦本次独立 AI 行动时，
显示以其当前格计算的安全轮廓和同一文本；不公开内部路线目标格 `125`。

`MAGIC/26` 只画到实际受影响单位。减少动态可把 44 tick 压缩为一次低闪烁脉冲；动画速度、
跳过、音效开关和镜头跟随不能改变目标集合、生命、死亡、行动顺序或 PRNG。安全／危险信息同时
使用轮廓、文字和可访问名称，不只依赖颜色。

## 验收场景

1. Given 葛蒂拉斯位于 `(25,41)` 且六个部署格都有人，When 首次路线尝试后结算，Then
   `(23,40)`、`(27,40)` 的单位减半，另四个部署格与固定槽 `0/24` 保持生命；
2. Given 葛蒂拉斯的路线结果未向更小格号移动，When 行动完成，Then 仍以原格运行一次效果并消耗行动；
3. Given 安全区外 side 1 单位生命分别为 `9/2/1` 且带防魔，When 效果提交，Then 变为
   `4/1/0`，防魔不变，最后一名单位离场；敌方生命不变；
4. Given 同一战中档，When 分别使用正常、加速、减少动态和跳过表现继续一轮，Then 行动者格、
   目标集合、生命、胜负、PRNG 状态与调用序号完全一致；
5. Given 修改行动者槽、比例分母为零或引用不存在的表现键，When 构造关卡，Then 在战斗开始前
   拒绝内容，而不是进入控制器硬编码兜底。
