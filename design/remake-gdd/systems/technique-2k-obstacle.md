## 玩家目的

工兵用一次完整行动移动到附近空格，并把落点四周可修改的地面改成本关障礙。障礙作为
持续动态地形立即参与移动代价与地形防御；落点本身不改变，也没有额外技能动画或音效。

## 证据与决策

- `[OF]` 工兵 `5A/34` 的三个等级均按 `1K/鐵板、2K/障礙` 显示菜单，两项共用玩家
  构筑入口、seed `5`、模式 `M`、空格落点与普通移动表现。
- `[OF]` 到达后按下、上、右、左的线性顺序检查邻格；当前原始 token 映射为逻辑槽 `0`
  时跳过，否则写入本关 `(16,26)` 复制出的同一个障礙 source token，中心格不改。
- `[OF]` 与 `1K` 共用同一段 `772Dh`／`77CDh`，因此同样最多只改 4 个正交邻格：落点自身
  只被写占位图 DS:`0022h` 的“已行动”位，移动路径由只读范围图的共享行走器完成，两者
  都不写地形。详见 [`technique-1k-iron-plate.md`](technique-1k-iron-plate.md) 的同名条目。
- `[OF]` 已开放关卡 `0..4` 的障礙 token 分别为 `23/18/4/36/27`，对应逻辑槽
  `13/3/10/5/13`；视觉 tile 分别来自 `B/0,2,4,6,8` 的同号图块。第 2、4 关障礙
  与鐵板碰巧引用同一 token，不得据此把两个语义 kind 永久合并。
- `[OF]` 第 27 关（玩家口径第 26 关）源格 `(16,26)` 的 token 为 `57`，映射逻辑槽 `9`，
  视觉 tile 来自 `B/0054` 的同号图块；同关鐵板为 token `3`／逻辑槽 `21`，两者 tile 不同。
  逻辑槽 `9` 对普通地面职业移动代价为 `4`（工兵与水戰士 `2`，飞行职业 `1`），因此
  障礙在这一关是真正的减速带，而不是与鐵板同义的地形。
- `[OF]` 成功构筑消费行动，但不给技术经验，不造成伤害／治疗／状态，不读取或推进 PRNG。
- `[OF]` `2K` 的休眠通用分发表包装器会横向写五个递增 token，但发布版玩家入口在调用前
  已跳入四邻构筑路径；工兵属于 ordinary AI 且没有 `1K/2K` 技术池，正常 AI 不会构筑。
- `[OF]` 障礙没有图形归档记录、VOC、描述符或固定等待；普通移动完成后即时写地形，棋盘
  常规重绘就是全部可见反馈。
- `[SR]` 继续执行 `REMAKE-025`：四邻按几何边界处理，不复现 DOS 线性跨行／越界；
  `obstacle` 与 `iron-plate` 共用可序列化动态覆盖，全部地形消费者读取覆盖后的逻辑槽。

## 触发与输入

- 工兵任意等级、未行动、未冰封且未禁咒时，技术菜单按原版顺序显示“鐵板、障礙”。
- 目标范围固定 seed `5`；路径传播读取工兵移动表，规则 `98/99` 不可进入。同阵营占格可
  穿过但不能落脚，敌军占格阻断，最终目标必须为空。全代价 1 时最远四步。
- 取消目标回技术菜单，再取消回动作菜单；不移动、不改地形、不消费行动或随机。
- 确认时冻结行动者、目标、路径和四邻 mutation；普通移动表现结束前模拟位置、覆盖表、
  行动位和保存快照仍保持准备前状态。

## 有序规则

1. 验证工兵职业／任意等级、行动位、冰封、禁咒和本关 `obstacle` 内容映射；
2. 以当前动态地形、单位占格和 seed `5` 建立 mode `M` 路径并验证空格目标；
3. 以目标按下、上、右、左枚举邻格，几何越界或当前逻辑槽 `0` 记录为跳过；
4. 其余邻格准备为 `{position, kind: "obstacle"}`；覆盖单位脚下、已有障礙或鐵板均合法，
   后写入的障礙取代前一 kind，中心不改；
5. 播放冻结的普通移动路径；不请求技能音频、不插入描述符等待；
6. 路径完成后原子校验准备未陈旧，提交位置、四邻覆盖与 `acted=true`，经验和 PRNG 不变；
7. 重绘原始障礙 tile，并让移动、范围、地形防御、AI、地形检查和保存统一读取新逻辑槽。

## 动态地形与存档

动态覆盖记录为 `{position, kind: "iron-plate" | "obstacle"}`，按线性格严格升序保存；同一格
只有一个 kind。新增 `obstacle` 扩展了持久化语义，故当前存档升级到 v18；v17
`dynamic-terrain-1` 无损迁移到 v18，已有鐵板覆盖保持原值。读取拒绝越界、重复／乱序、未知
kind、静态槽 `0` 或本关未声明的 kind。第 2、4 关即使两种 kind 映射相同 token，也保留
语义 kind，保证未来内容身份、Mod 和跨关验证不依赖偶然的数值相等。

## 表现与可访问性

- 使用既有普通移动的方向、逐格节奏和音效；障礙本身零专用声音、零技能图形、零等待。
- 提交后把本关原始障礙 tile 绘制在静态地图之上、网格与单位之下，禁用像素平滑。
- 目标选择文字为“選擇工兵移動並設置障礙的空格。”，与鐵板的“……並鋪設鐵板……”分列；
  提交阶段使用“前往設置障礙／障礙設置完成”，报告覆盖格与新 kind 格数，不称为攻击目标。
- technique-lab 使用第 1 关 token `18`，提供“移动前／构筑完成”两个语义节点；完成节点显示
  四邻图块并明确零伤害、零经验、零 PRNG、零专用音画。

## AI 使用

原版双方工兵都没有构筑技术池，`stableRemake` 与当前 `legacyStrict` 均继续使用 ordinary
AI，不选择 `2K`。竞技场需要断言敌方工兵不会在可设置障礙时自行构筑；未来 Mod 若开放
构筑 AI，必须另行定义评分、路径与确定性平局，不能伪称原版行为。

## 验收场景

1. 三个等级工兵均按“鐵板、障礙”显示；`2K` 目标范围、同阵营穿越、敌军阻断和空格落点
   与原版 seed 5 一致；
2. 目标四邻含普通地形、槽 `0`、已有鐵板和单位脚下地形时，中心与槽 `0` 不变，其余格
   依序成为障礙，单位保持并立即读取新的逻辑槽；
3. 地图边界不会线性跨行；准备／移动期间状态不提交，完成时位置、覆盖和行动位原子提交，
   经验、生命、状态、PRNG state/calls 不变；
4. 关卡 `0..4` 分别映射 token `23/18/4/36/27` 与逻辑槽 `13/3/10/5/13`，正式画面使用
   对应原始 `B` 图块；第 2、4 关仍保留 `obstacle` 语义 kind；
5. v17 鐵板存档迁移到 v18 后不变，v18 障礙覆盖可往返；重复、乱序、未知 kind 与无内容
   映射安全拒绝；
6. technique-lab 完成节点显示第 1 关 token `18` 四邻 tile，自动断言零技能音频和零描述符；
   正式竞技场玩家可从技术菜单提交，敌方工兵 ordinary AI 不选择 `1K/2K`；
7. 人工截图确认障礙像素、四邻落点、单位／地形层级和中心保持，完整单元、构建、Chromium
   与证据校验通过后才进入下一项。
