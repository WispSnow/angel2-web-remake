## 玩家目的

巫師第一层用一次行动以自身为中心释放中級冰雪。范围比初級冰雪多一圈，范围内敌军
不受生命伤害，但会被沿“施法者→自己”的连线向外推一格（`REMAKE-095`，八向取最近者），
所有候选都不合法时才留在原位。依 `REMAKE-094`，只有推完之后仍留在效果范围内的目标
被冰封：被吹出范围的敌军照常位移但可以继续行动，也仍是合法攻击目标。斜向一步令曼哈顿
距离 `+2`，因此偏斜方向的目标更容易被吹出范围，冰封区收敛为施法者上下左右各两格的十字。

## 证据与决策

- `[OF]` 玩家职业菜单只在 `巫師/2L` 第一层列出 `2C`；第二、三层分别改列 `3C/4C`，
  不保留低阶动作。玩家入口 `0000:75FA..7620/76B0` 绕过普通目标选择并把效果中心固定
  为行动者当前格；动作表中的玩家选择字 `3` 不会被消费。
- `[OF]` 效果使用 mode `0`、seed／半径 `4` 的正交范围：中心值 4，距离 1/2/3 的圈值
  分别为 3/2/1；只处理敌对阵营单位，不造成生命伤害。
- `[OF]` 按规范线性格升序处理目标；未免疫目标按下、上、左、右尝试第一个空闲、可通行
  且范围值更低的邻格。前一个单位的位移立即影响后续占用检查。
- `[OF]` 已有冰封、防魔或职业为龍／頭／手的目标不位移；防魔在该目标结算后消费。
  其他目标即使无合法退格也写行动禁用位。至少一名单位成功位移才取一次
  `10 + randomBelow(2)`；无人位移时经验为 0 且不推进模拟 PRNG。
- `[SR]` 延续 `REMAKE-013` 的冰封门禁，并依 `REMAKE-036` 允许范围值 1 的最外圈目标
  移到合法值 0 格。冰封期间不可行动或被攻治，破邪可以解除。
- `[SR]` 依 `REMAKE-094`，冰封位改按结算后的落点判定：落点范围值仍大于 `0` 才写冰封位。
  范围值 1 的最外圈成功外推即离开范围、只位移不冰封，推不动时留在原格仍冰封。免疫链、
  防魔消费时点与经验口径均不变。
- `[SR]` 依 `REMAKE-095`，方向由原版固定四向改为“与施法者→目标连线夹角最小的八向之一”，
  用整数判据 `(ax + ay)² > 2 × max(ax, ay)²` 判斜向，不使用浮点；斜向另需两个正交中间格
  至少一格地形可通行。首选不合法时在本人其余邻格中按“离施法者更远 → 夹角更小 → 原版
  下上左右再四对角”回退。半径 4 下正交推 `+1`、斜推 `+2`，因此冰封区为四个正交方向各
  两格，合计 8/24 格；原版固定四向会把正左／正右目标纵向吹出，这条缺陷正是本决定的起因。
- `[OF]` AI 的巫師第一层池只有 `2C`；第二、三层分别只有 `3C/4C`。AI 先要求当前位置
  距离 3 内有合法敌军候选，但技能中心仍固定为行动者格；候选按有效防御最低、当前生命
  最低、线性格等原版顺序破平。无候选时回退普通移动／攻击／休息。
- `[OF]` 成功的我方自动／敌方 AI 使用对白组 12，原文“看我的冰魔法.”；side 1 上窗、
  side 2 下窗。对白候选只用于施放门禁和提示焦点，不成为技能效果中心。
- `[OF]` 表现复用 `MAGIC/10 + UN/50`：三轮扩散，每轮六帧、每帧 10 native ticks，
  依次只画距离中心 1/2/3 的范围值 3/2/1 圈；每轮开始请求一次 `UN/50`，总计 18 次
  绘制、3 次声音、180 native ticks。最后一帧保持后才清动画并提交规则。

## 触发与输入

- 进入条件：巫師第一层、未行动、未冰封且未被禁咒；动作菜单显示“技術”，技术菜单只列
  “中級冰雪”。第二、三层在 `3C/4C` 各自完成前不显示 `2C` 作为替代。
- 玩家确认技术即以行动者当前格准备并提交，不进入目标格选择；取消技术菜单只回动作菜单，
  不写状态、行动位、经验或 PRNG。
- 玩家、我方自动和敌方 AI 共用 `ice-2` action definition、准备器和原子提交器。AI 的
  targetId 只保留为决策／对白候选；送入自中心准备器时必须省略，不能把候选误作中心。
- 完整表现期间冻结行动者中心、受影响单位、位移结果和 PRNG 前后态；动画、相机、音频或
  失焦不能重算占格及位移。

## 有序规则

1. 验证行动者为巫師第一层、状态与行动位合法；玩家中心必须等于行动者格；AI 还需先
   通过距离 3 的敌方候选门；
2. 以行动者格建立半径 4 效果图，按线性格升序收集范围内敌军；
3. 对每个目标依次检查已冰封、防魔、龍／頭／手免疫；已冰封不消费防魔，其他防魔目标
   在准备结果中记录提交后清除；
4. 对未阻挡目标先取 `REMAKE-095` 的径向方向，再按回退顺序查找第一格在地图内、可通行、
   无人占用且范围值更低的目的地（斜向还需满足拐角规则）；值 0 合法，成功后立刻更新准备态
   占格；全部候选都不合法时留在原格；
5. 依 `REMAKE-094`，按第 4 步得到的落点判定冰封：落点范围值大于 `0` 的写冰封位，
   等于 `0`（已被推出效果范围）的只保留位移；留在原格者落点即原格，照常冰封。
   该判定与位移在同一次准备中完成，不引入第二轮扫描，也不读取 PRNG；
6. 若位移数大于 0，只调用一次版本化模拟 PRNG 得到 `10..11` 经验；否则经验与 PRNG
   调用均为 0；经验口径仍是“是否有人成功位移”，与本次冻住几人无关；生命、普通八槽
   状态和地形不变；
7. 播放三轮各六帧的离散扩散，并在每轮开始请求 `UN/50`；墙钟期间模拟仍保持准备前值；
8. 180 native ticks 及末帧保持结束后，原子提交位置、防魔消费、冰封、经验、PRNG 与
   行动位，再进入阶段、胜负和转职后置链。

## AI 使用

巫師第一层的原版池没有随机选技分支，只有 `2C`。规划器从当前位置以选择距离 3 搜索未冰封
敌军；有多个候选时按有效防御、当前生命、路径与格号的确定顺序选择提示对象，但准备结果的
`target` 必须仍是施法者格。成功后先把相机对焦语义效果中心，显示组 12 原文，播放与玩家相同
的 180 tick 表现，再提交同一结果。第二、三层不得回退到 `2C`；无候选或施术受禁时使用既有
ordinary AI，不消费冰雪经验随机。

依 `REMAKE-094`，专家 AI 的 `2C` 估值必须与结算共用同一个纯预测函数：先按同一顺序、同一
方向表推算每个目标的落点，只把“落点范围值仍大于 `0`”的目标计入 `control` 与 `REMAKE-036`
的巫師仇恨带。被吹出范围的巫師不构成有效敌对结果；全部候选都会被吹出时，该动作按既有规则
记为 `waste` 并让位给普通攻击、移动或休息。预测只读公开模拟状态，不读取或推进玩法 PRNG，
且不得复制第二份位移实现。

`REMAKE-034` 覆盖敌方排程：只有当前最高候选实际为 `2C` 的巫師才延后到所有非冰雪行动者
之后；改选击杀／普通行动时不延后。存活 side 2 全部具备冰雪技术时过滤 `2C`；该门禁按职业能力判断且对残军规模没有
下限，因此只剩一名巫師时同样过滤，它会改选普通攻击、移动或休息而永远不施放 `2C`。不记录或
降低近期冰封目标价值，玩家须自行避免长期停留在施法范围。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 固定施法者中心；AI 候选门 3；冰封不可攻治、不可叠加，最外圈可外推到值 0 但外推成功即不冰封（`REMAKE-094`），破邪可解除；实际冰雪动作延后且纯冰雪残军禁用冰雪 |
| `legacyStrict` | 固定施法者中心；最外圈同样可移到值 0 格且照常冰封，冰封仍可受攻治且破邪不解冰 |
| 可开放 Mod 字段 | 职业层级菜单、AI 候选距离、效果半径、位移顺序、冰封判定基准（命中格／落点）、经验、表现 ID；修改后必须改变规则身份 |

## 表现与可访问性

正式地图和 technique-lab 共用六帧 `MAGIC/10` 像素资源，但每一时刻只绘制当前距离圈；
不能同时留下前三圈或用缩放圆代替原版逐格对象。每轮 `UN/50` 受“戰鬥”音效开关控制。
演出完成后的冰壳是独立持久状态投影，不算作冰雪动画对象；直到自然解封或破邪提交才消失。
加速、减少动态和静音只能改变墙钟等待或声音输出，不能改变 18 次语义绘制、圈序、位移、
经验或 PRNG。

## 验收场景

1. Given 巫師第一层，When 打开技术菜单，Then 只显示 `2C`；第二／三层不显示 `2C`；
2. Given 距行动者 1/2/3 格各有敌军，When 准备 `2C`，Then 效果值分别为 3/2/1，生命
   均不变，按线性格顺序与 `REMAKE-095` 的径向方向准备位移和冰封；
3. Given 敌军位于施法者正左、正右、正上或正下，When 提交，Then 它沿同一轴线被推开而不是
   纵向偏移；位于 `(±2, ±1)` 一类偏斜格的敌军按 22.5° 判据走对角，一步跨两格曼哈顿距离；
4. Given 内圈目标有合法更低正值邻格且外圈目标有合法值 0 邻格，When `stableRemake` 提交，
   Then 两者都按径向方向外移，内圈目标冰封而外圈目标只位移不冰封（`REMAKE-094`），
   外圈目标提交后没有冰壳且仍是合法攻击目标；整次动作只取一次 `10..11` 经验随机；
5. Given 所有目标均被阻挡或无合法退格，When 提交，Then 未免疫目标留在原格并全部冰封，
   经验为 0，PRNG state/calls 不变；防魔目标不冰封且防魔消费，龍／頭／手保持不变；
6. Given 径向首选格被占，When 提交，Then 目标改用第一个合法的外向邻格（离施法者更远优先），
   而不是留在原格；斜向两个正交中间格都不可通行时不允许穿过墙角；
7. Given 范围内只有可被推出范围的最外圈目标，When 专家 AI 评估 `2C`，Then 估值不计入
   任何 `control` 或巫師仇恨，动作记为 `waste` 并改选普通攻击、移动或休息；
8. Given AI 巫師第一层距离 3 内有合法敌军，When 规划并执行，Then 选择 `2C`、显示组 12
   原文并以自身为效果中心；没有候选时不施术，第二／三层不回退到 `2C`；
9. Given 2C 演出进行，Then 第 1/2/3 轮只显示距中心 1/2/3 的圈，分别在每轮开始请求
   `UN/50`，总计 18 draw、3 sound、180 native ticks；完成前位置、冰封、经验与 PRNG 不变；
10. technique-lab 与正式竞技场都能 seek／捕获第三圈代表截图；自动断言像素资源、当前圈
   对象数、末帧保持、提交后的持久冰壳和玩家／AI 共用准备结果。
