# 第 0 关修女技术规格

状态：`accepted`

授权日期：2026-07-29

用户接受日期：2026-08-01

依赖：战场动作结算、最小状态底座、职业目录、地图特效、确定性 PRNG

## 玩家目的

修女可以在普通攻击之外选择“初級炎暴”打击单个敌军，或用“初級治療”恢复单个友军；两项技术没有 MP，但会消耗本回合行动。

## 证据与决策

- `[OF]` 修女 `4A` 三个成长阶段的菜单都固定为“初級炎暴、初級治療”，顺序不变。
- `[OF]` 两项动作原生 selection radius 都为 5；炎暴只接受敌军，治疗只接受同阵营单位。
- `[OF]` 初級炎暴伤害为 `min(currentLife,108,floor(maxLife*18/100))`，经验为击杀奖励加 `8+random(0..1)`。
- `[OF]` 初級治療实际值为 `min(maxLife-currentLife,floor(maxLife*24/100))`；`q=floor(actualHeal*10/maxLife)`，经验为 `random(0..1)+(q==0?0:q+10)`。
- `[OF]` 炎暴使用 `MAGIC/22` 七阶段、每阶段 10 native ticks，开始请求 `MAGIC/83`；治疗使用 `UN/61` 39 帧加空白、每阶段 5 ticks，再接 `MAGIC/0` 五帧、每帧 15 ticks，开始请求 `E/36`。
- `[OF]` 两项技术都在全部固定动画后才修改生命或治疗，且不进入普通攻击全屏链；炎暴随后按实际伤害逐点扣血，每点重画并等待 1 native tick。
- `[SR]` 依据 `REMAKE-005`，炎暴属于魔法伤害；防魔先阻挡本次伤害再被消耗。
- `[DD]` 依据 `REMAKE-009`，同一技术的范围、数值与效果不因玩家、我方自动或敌方 AI
  控制而改变；AI 差异只存在于动作和目标选择策略。
- `[DD]` M00.6 只开放 `fire-1` 与 `heal-1`；其他 34 项技术保持冻结。

## 触发与输入

- 进入条件：修女尚未行动且尚未移动，在初始命令菜单选择“技術”，再选择技术项；确认
  移动后进入“攻擊／結束／返悔”菜单，本回合不能再施展技术。
- 合法行动者：职业 `sister` 且未被禁咒；M00.6 不提供禁咒生产者。
- 合法目标：炎暴为选择范围内敌军；治疗为选择范围内同阵营单位，允许选择施法者。
- 取消边界：目标层取消回技术菜单，技术菜单取消回职业命令；均不消耗行动或 PRNG。
- 提交时点：固定图形结束后先完成炎暴的只读显示生命逐点下降；整个表现时间轴结束后原子提交。

## 有序规则

1. 按职业和成长阶段构建技术菜单；修女始终得到 `[fire-1, heal-1]`。
2. 按动作 selection radius 建图并过滤目标阵营。
3. 确认目标后在 PRNG 副本准备效果与经验。
4. 炎暴先检查防魔；存在时准备 0 伤害和防魔消费，否则准备公式伤害。
5. 治疗按目标当前/最大生命计算实际恢复和 `q`，即使实际治疗为 0 仍保留外层随机经验。
6. 播放完整固定棋盘图形；炎暴命中时再把目标显示生命按实际伤害逐点降到结果值，每点 1 native tick。
7. 显示时间轴结束后原子提交生命、状态、经验、死亡和行动位。
8. 进入转职扫描、胜负和阶段切换。

技术的选择范围只以行动者当前位置为原点。玩家、我方自动与敌方 AI 都不得先移动再
施术；若 AI 当前格没有合法技术目标，可以改选移动后普通攻击或只移动推进。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 炎暴命中 | 单体魔法伤害，可能致死 | `MAGIC/22` 结束后生命数字逐点下降，再显示伤害摘要 |
| 防魔阻挡 | 0 伤害并消耗防魔 | 显示阻挡反馈 |
| 治疗受伤友军 | 恢复至多最大生命 24% | `UN/61 + MAGIC/0` 与恢复量 |
| 治疗满血友军 | 恢复 0，仍可能获得 `0..1` 经验 | 显示“生命已满”但动作正常提交 |
| 无合法目标 | 不消耗行动或 PRNG | 返回技术菜单并说明原因 |
| 保存/读取 | 技术能力由职业派生，状态与 PRNG完整恢复 | 不保存菜单焦点或动画帧 |

## AI 使用

我方自动修女使用同一技术列表和结算。负面动作优先有效防御最低、同值生命最低的敌军；治疗优先真实缺血量最大的友军。没有有价值技术目标时回退普通攻击、移动、休息或等待。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 炎暴受防魔阻挡并消费；同一 action ID 对敌我双方使用同一范围与公式 |
| `legacyStrict` | 可保留原版炎暴不检查防魔但事后清除，以及玩家/AI 分表差异 |
| 可开放 Mod 字段 | 菜单项、选择距离、公式参数、目标阵营、表现 ID |

## 表现与可访问性

技术子菜单由 DOM 呈现原版名称；目标范围和地图特效由 Phaser 呈现。屏幕阅读器可读动作名称、目标类型与作用摘要。减少动态可缩短重复帧，但规则提交仍位于时间轴语义末点。
原版最后一次绘制后的等待仍属于表现时间线：初級炎暴末帧保持 10 native ticks，随后
进入每点 1 tick 的扣血数字动画；初級治疗公共收尾末帧保持 15 native ticks。Web 在这些
阶段只投影显示生命，完成后才提交规则结果。

## 验收场景

1. Given 目标最大生命 160、当前生命 100 且无防魔，When 修女使用初級炎暴，Then 造成 28 点伤害并获得 `8..9` 加可能的击杀奖励；
2. Given 友军最大生命 200、当前生命 130，When 使用初級治療，Then 恢复 48 点，`q=2`，获得 `12..13` 经验；
3. Given 目标带防魔，When 使用炎暴，Then 伤害为 0、防魔被消费；保存读取与表现设置不改变结果；
4. Given 修女完成移动，When 打开移动后菜单，Then 只有“攻擊／結束／返悔”，玩家和
   AI 都不能从新位置施展技术；射击职业的移动后“射擊”不受影响。
5. Given 炎暴准备 28 点伤害，When 七阶段固定图形完成，Then 目标显示生命以 1 点／
   native tick 连续下降 28 次；期间模拟生命与 PRNG 保持准备前值，最后一次显示后才原子提交。
