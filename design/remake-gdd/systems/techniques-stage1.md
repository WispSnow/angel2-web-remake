## 玩家目的

玩家选择葛蒂拉斯出场后，可用魔術士的初級炎暴、初級落雷和初級冰雪在单体伤害、
范围伤害与范围击退之间取舍。敌方两名修女则首次在正常可达敌方阶段使用初級炎暴／
初級治療，让同一技术规则在玩家、我方自动和敌方 AI 中保持一致。

- 合法行动者：未行动、未被禁咒且职业目录当前提供相应 action ID 的单位。

  `初級炎暴／初級落雷／初級冰雪`，保持原生顺序。
- `1L` 合法选中格：行动者四步选择范围内、通过敌方目标 validator 的占用格。
- `1C` 没有目标格选择。玩家在技术菜单确认后，系统直接以行动者当前格准备并播放；

- `1F/1H` 在任何阵营和控制方式下都使用既有语义定义的选择范围 `5`；敌方修女不读取
  原版 AI 表中 `1F=4` 的专属缩水值。
- 取消：可选目标技术在目标选择时取消回技术菜单，技术菜单取消回动作菜单；`1C` 在

- 提交：动作定义只有在原版证据标记逐点扣血时，才在固定图形后按每点 1 native tick

  施法者标为已行动。

## `1L / 初級落雷`

1. 以选中格建立半径 3 的曼哈顿菱形；中心范围值 3，向外依次为 2、1。
2. 按规范战场格号升序扫描范围内敌军。
3. 每个敌军按范围值承受 `1→20、2→35、3→50` 点伤害，伤害不低于 0 且不超过
   当前生命。
4. 若目标有 `magicGuard`，本次伤害为 0；无论是否阻挡，受范围处理的敌军随后消费
   防魔。
5. 生命归零的单位在同一原子提交中移除；经验只有既有击杀奖励，不增加施法固定经验。
6. 表现使用 `MAGIC/8 → MAGIC/31 → MAGIC/6`，固定 414 native ticks：云层从目标东南
   沿对角线飞入，目标中心完成四组雷云主体循环后继续向西北飞出；`MAGIC/31` 按
   `REMAKE-049` 分两层——扫描层对范围带内的每个效果格按该格 `范围值 − 当前阈值` 取
   帧 `0..8`，标记层再对同一带内的敌方占用格交替叠加帧 `4/5`；`MAGIC/6` 再对效果范围内的
   敌方占用格播放五阶段收尾。最后一阶段绘制后继续保持 10 native ticks，再清除效果并提交规则。第 80 tick
   请求 `E/43`。原版 `1000:7166` 按目标一次写入结果，不调用炎暴／公共射击的逐点重画
   函数；全部固定表现完成前不得扣血、消费防魔或移除单位。

## `1C / 初級冰雪`

1. 以施法者当前格建立半径 3 的曼哈顿菱形；冰雪不造成生命伤害，调用者提供其他
   中心必须被模拟层拒绝。
2. 按规范战场格号升序处理范围内敌军。
3. 已冰封、有 `magicGuard` 或职业为 `1P/2P/3P` Boss 部件的单位不移动；正常单位依
   `[SR]` `REMAKE-095` 先取“与施法者→自己连线夹角最小的八向”，首选不合法时再按
   “离施法者更远 → 夹角更小 → 原版下上左右再四对角”回退。斜向判据为整数比较
   `(ax + ay)² > 2 × max(ax, ay)²`，不使用浮点。再次命中已冰封单位不刷新持续时间，
   也不消费其防魔。
4. 目的格必须在地图内、可通行、无人占用，且范围值严格低于当前格；范围值 `0` 也合法；
   斜向另需两个正交中间格至少一格地形可通行。内圈单位可被推到最外圈，最外圈单位继续
   尝试推到效果范围外。第一个合法格立即成为新位置，前面单位的位移影响后续占用检查；
   全部候选都无合法更低值格时仍留格冰封。
5. 非冰封目标被防魔阻挡时在结算后消费防魔。至少一名单位成功移动时，经验为
   `8 + randomBelow(2)`；无人成功移动时经验为 0，且不消费该随机调用。
6. `[SR]` 依 `REMAKE-094`，冰封位按**结算后的落点**判定：未被防魔／Boss 部件免疫的目标中，
   只有落点范围值仍大于 `0` 的写入逐单位冰封位。被推到值 `0` 格、离开本次效果范围的目标
   只发生位移，不写冰封位，提交后也不显示冰壳；全部候选都没有合法退格而留在原格的目标，其
   范围值必然大于 `0`，因此照常冰封。半径 3 下正交外推每次令曼哈顿距离 `+1`、斜推 `+2`，
   故冰封区收敛为四个正交邻格，最外圈只在推不动时才冰封。写入冰封位的单位不能选择、移动、攻击、
   射击、施术、休息、参与 AI 调度或反击。玩家施放后
   目标跳过紧接着的敌方阶段，并在下一完整回合入口解除；反向施放时，side 1 目标跳过
   下一玩家／我方自动阶段，并在敌方阶段开始前解除。它不是八槽普通状态，重复施加
   不叠加、不刷新且不延长解除时点。
7. 冰封有效期间，目标不能成为普通攻击、射击、单体伤害技术或治疗的合法目标；被拒绝
   的选目标不消费行动或 PRNG。若其他单位为中心的范围伤害／治疗覆盖冰封格，本单位的
   伤害与治疗均为 0，防魔、生命、死亡、击杀／治疗经验均不变；持续伤害也必须跳过。
   AI 使用同一门禁，且不把冰封单位视为军团警戒触发源。
8. 表现使用 `MAGIC/10 + UN/50`，两轮扩散、每轮六帧，共 120 native ticks，
   第一轮只画距施法者中心 1 格的范围值 2 圈，完整六帧后第二轮才画距中心 2 格的
   范围值 1 圈；中心格和另一圈不同时绘制。每轮开始请求一次 `UN/50`；最后一帧绘制
   后保持 10 native ticks，再清除效果并提交规则。全部表现完成前不得移动单位或写经验。
9. 提交后，冰封单位持续显示原版 `MAGIC/10` 冰壳末帧投影，直至对应阵营阶段结束或
   破邪提交并清除冰封位；该持久图形不计入已经完成的技能动画对象，其他范围演出期间
   也不隐藏。

1. `[OF]` 原版 `TR` 选择距离为 7，只能选同阵营单位；使用 `UN/57` 五路动态图形，

2. `[OF]` 原版表现完成后清防御下降、攻击下降、混乱、施毒和禁咒；它不读取冰雪的

3. `[SR]` `REMAKE-013` 将破邪设为冰封目标门禁的唯一例外。其原版五项净化照常发生，
   并在同一原子提交中清除冰封；冰壳此时消失，若目标尚未行动，可立刻在当前本阵营
   阶段行动。
4. 当前战役第 1 关没有可达魔祭师，不改变正式出战表；模拟、原版地图表现、任意职业
   动画实验室和“冰封／破邪靶场”先行提供验收入口，不据此解冻后续关卡。

## AI 使用

- 玩家、我方自动和敌方 AI 都调用同一合法性、准备结果与原子提交函数。
- stage 1 两名敌方修女的可用池仍为 `1F/1H`，动作范围及结算读取 `REMAKE-009` 的双方
  统一 action definition：`1F/1H` 均为范围 `5`；不再随机先抽一个动作再因无目标失败。
- 依 `REMAKE-012`，修女在当前状态允许行动时对全部合法候选统一评分：能确定击杀的
  `1F` 优先，其次是生命低于 `40%` 的友军治疗，再次是有效 `1F`、其他实际治疗；
  平局使用固定格号、路径长度和地形顺序，不读取 PRNG 结果。
- 依 `REMAKE-013`，所有 AI 伤害和治疗候选与“本回合可造成伤害”的军团警戒判定排除
  冰封单位；不得把它误评为击杀、有效伤害、紧急治疗或警戒触发源。
- 依 `REMAKE-034`，敌方魔術士若实际选择 `1C`，只在所有当前选择非冰雪动作的敌军之后
  行动；若改选炎暴、落雷、普通攻击或移动，则仍按正常专家分数排程。存活 side 2 全部
  具备冰雪技术时禁用 `1C`。不增加近期冰封衰减或目标抗性。
- 所有技术候选都只从修女当前位置建立范围，路径必须只有原格；不得为了取得技术目标先
  移动。当前位置没有合法技术时，追击态仍可改选移动后普通攻击或只移动推进。
- 没有合法技术时按当前守卫／警戒／追击状态待命、休息或推进；不得由 UI 或动画改选。
- 葛蒂拉斯的 `1L/1C` 在本切片只提供玩家入口；不为未出现的敌方魔術士虚构 AI 用例。
- 自动技术执行顺序固定为“准备结果 → 对焦 `result.target` → 原版情境对白 → 固定图形 →
  动作定义要求的可选逐点扣血 → 原子提交”。第 1 关 `1F` 有逐点扣血、`1H` 没有；提示
  和只读扣血表现期间模拟生命、行动位与 PRNG 都不变。
  side 1 自动单位使用上窗，side 2 敌军使用下窗。

- 表现期间不能存档；只有原子提交前的玩家状态或提交完成后的玩家状态可进入记录入口。
- 读取后同一语义动作产生相同目标、伤害、位移、经验、胜负和 PRNG 后态。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | `1F` 使用统一防魔修正及双方范围 `5`；冰封不可行动／攻治、不可叠加，最外圈可外推到值 0，破邪可解除；敌方实际冰雪动作延后且纯冰雪残军禁用冰雪 |
| `legacyStrict` | 可保留炎暴不先检查防魔及玩家/AI 数值分表；冰雪禁用行动但仍可攻治，破邪不解冰 |
| 可开放 Mod 字段 | 菜单有序 action IDs、选择/效果半径、伤害表、位移顺序、冰封持续/叠加/目标门禁/净化规则、表现 ID；改变后必须改变规则/内容身份 |

## 表现与可访问性

范围预览使用与普通/射击共享的非零格全亮、零值格 25% 网点合同，并以颜色之外的
轮廓区别选择范围与效果范围。表现事件只携带语义 action ID、中心、受影响单位与原生
时间线 ID；DOM/Phaser 不读取或重算伤害。加速、减少动态、静音和失焦恢复只能缩短或
跳过等待，不能提前提交或改变 PRNG。

自动技术提示沿用原版阵营窗口（side 1 上方、side 2 下方）、行动者肖像和逐字音，原文
不改；说话者标签显示“单位名・技术名”，避免玩家只凭泛用台词猜动作。相机逐格移动到
语义效果中心并受关卡视口边界夹取；它不读取 DOM、动画帧或未来结算状态。关闭
“ＡＩ對話”只跳过提示窗，不关闭对焦，也不改变原版逐字音以外的声音分类。

## 验收场景

1. Given 魔術士选择 `1L`，中心/中层/外层各有一名 100 生命敌军，When 表现完成，
   Then 三者生命依次为 `50/65/80`，表现前均保持 100；
2. Given `1L` 范围内一名防魔敌军，When 提交，Then 生命不变、防魔归零，其他目标
   正常受伤；
3. Given `1C` 目标可向下移动，When 表现完成，Then 生命不变、单位向下移动一格并取得
   `8..9` 经验；若四向都非法，则单位不动且经验为 0；
4. Given 修女同时存在确定击杀、紧急治疗或普通有效目标，When 敌方阶段规划，Then 按
   `确定击杀 → 紧急治疗 → 有效伤害 → 一般治疗` 选择，且不为评分预消费 PRNG；
5. Given 某目标位于统一 `fire-1` 合法范围内、但原版 AI `1F=4` 表无法覆盖，When 敌方
   修女在 `stableRemake` 选择炎暴，Then 目标合法且范围图与同位置玩家施法完全一致；
6. Given 目标只在修女移动后的技术范围内、但不在其当前技术或移动后普通攻击范围内，
   When 敌方阶段规划，Then 不施术且不因此解除军团警戒；
7. Given 相同初态和动作，When 使用正常/加速、地图/全景、静音/有声，Then 单位、状态、
   经验、胜负与 PRNG 完全一致。
8. Given `1C` 范围内一名未免疫敌军，When 表现提交，Then 其地图冰壳可见且不进入紧接
   敌方行动队列；When 下一完整回合开始，Then 冰壳和冰封位同时清除。
9. Given 冰封单位同时带有防魔，When 玩家尝试普通攻击、射击、炎暴或治疗，Then 该格
   不在合法目标集合、动作与 PRNG 均不消费；When 以其他目标为中心的落雷覆盖该格，
   Then 本单位伤害为 0、生命和防魔不变、冰壳不中断。
10. Given 已冰封目标再次进入冰雪范围，When 技术提交，Then 目标不移动、不消费防魔、
    不增加冰封层数也不延长解除时点；When 原定下一本阵营阶段结束，Then 正常解封。
11. Given 魔祭师以破邪选中尚未行动的冰封友军，When 50 帧、250 tick 原版演出完成，
    Then 五种原版负面状态与冰封同一提交清除、冰壳消失，目标可在当前阶段行动。
12. Given 未免疫敌军位于 `1C` 最外圈范围值 `1` 且存在合法值 0 邻格，When 冰雪提交，
    Then 目标按下上左右首格移出效果范围并进入冰封；若四向均非法则留格。只要发生任一
    位移就按既有合同取一次经验随机。
13. Given 第 1 关敌方修女选择 `1F` 或 `1H`，When 技术表现开始，Then 相机先夹取到准备
    结果中心，再于下方窗口显示行动者肖像、明确技术名和对应原版原文；提示结束前生命、
    行动位与 PRNG 不变。关闭“ＡＩ對話”后只省略窗口，相机仍对焦且结算完全相同。
14. Given side 1 修女由集体命令进入自动阶段并选择 `1H`，When 技术表现开始，Then 相机
    对焦受术者，上方窗口显示行动者肖像、“单位名・初級治療”和“生命單.”；目录中的
    33 项短码均能解析到证据组，而 `SM/FM/OJ` 明确返回无对白。
15. Given `1F` 已准备非零伤害，When 固定图形结束，Then 目标棋子生命数字逐点下降，
    每点 1 native tick；模拟生命与 PRNG 到数字终值后才原子提交。`1L` 保留原版固定图形
    后一次进入结果的独立路径，不套用该动画。
