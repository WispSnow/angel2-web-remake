## 玩家目的

玩家选择葛蒂拉斯出场后，可用魔術士的初級炎暴、初級落雷和初級冰雪在单体伤害、
范围伤害与范围击退之间取舍。敌方两名修女则首次在正常可达敌方阶段使用初級炎暴／
初級治療，让同一技术规则在玩家、我方自动和敌方 AI 中保持一致。

## 范围边界

- M00.6 已实现并接受 `1F/fire-1`、`1H/heal-1` 的范围、数值、防魔、表现后提交和
  我方自动入口；M01 必须复用这些语义，不复制第二套 stage 1 公式。
- M01 新增的动作只有 `1L/lightning-1` 与 `1C/ice-1`，以及敌方修女调用既有
  `1F/1H` 的调度适配。
- 正式战役不实现中高阶技术、状态施放、通用状态倒计时、MP、道具消耗或 stage 2 内容。
  用户于 2026-08-03 另行授权 `2L/3L/4L` 的原版地图表现与独立实验室投影；该授权不
  建立可提交动作、伤害结算、AI、职业菜单或存档规则，边界见
  [`technique-lab.md`](technique-lab.md)。

## 触发与输入

- 合法行动者：未行动、未被禁咒且职业目录当前提供相应 action ID 的单位。
- 菜单：修女显示 `初級炎暴／初級治療`；魔術士显示
  `初級炎暴／初級落雷／初級冰雪`，保持原生顺序。
- `1L` 合法选中格：行动者四步选择范围内、通过敌方目标 validator 的占用格。
- `1C` 没有目标格选择。玩家在技术菜单确认后，系统直接以行动者当前格准备并播放；
  不进入地图选格模式，也不能把分发表第三字 `2` 解释成可选距离。
- `1F/1H` 在任何阵营和控制方式下都使用既有语义定义的选择范围 `5`；敌方修女不读取
  原版 AI 表中 `1F=4` 的专属缩水值。
- 取消：可选目标技术在目标选择时取消回技术菜单，技术菜单取消回动作菜单；`1C` 在
  技术菜单确认即提交演出，不存在额外可取消的地图目标层。
- 提交：表现时间线完整结束后一次性写入全部规则结果，并把施法者标为已行动。

## `1L / 初級落雷`

1. 以选中格建立半径 3 的曼哈顿菱形；中心范围值 3，向外依次为 2、1。
2. 按规范战场格号升序扫描范围内敌军。
3. 每个敌军按范围值承受 `1→20、2→35、3→50` 点伤害，伤害不低于 0 且不超过
   当前生命。
4. 若目标有 `magicGuard`，本次伤害为 0；无论是否阻挡，受范围处理的敌军随后消费
   防魔。
5. 生命归零的单位在同一原子提交中移除；经验只有既有击杀奖励，不增加施法固定经验。
6. 表现使用 `MAGIC/8 → MAGIC/31 → MAGIC/6`，固定 414 native ticks：云层从目标东南
   沿对角线飞入，目标中心完成四组雷云主体循环后继续向西北飞出；`MAGIC/31` 只在
   当前范围带内的敌方占用格形成双相波纹，`MAGIC/6` 再对敌方全部占用格播放五阶段
   收尾。最后一阶段绘制后继续保持 10 native ticks，再清除效果并提交规则。第 80 tick
   请求 `E/43`。全部表现完成前不得扣血、消费防魔或移除单位。

## `1C / 初級冰雪`

1. 以施法者当前格建立半径 3 的曼哈顿菱形；冰雪不造成生命伤害，调用者提供其他
   中心必须被模拟层拒绝。
2. 按规范战场格号升序处理范围内敌军。
3. 有 `magicGuard` 或职业为 `1P/2P/3P` Boss 部件的单位不移动；正常单位按
   `下、上、左、右` 尝试目的格。
4. 目的格必须在地图内、可通行、无人占用，且范围值严格低于当前格；第一个合法格
   立即成为该单位的新位置。前面单位的位移会影响后续单位的占用检查。
5. 受范围处理的敌军在结算后消费防魔。至少一名单位成功移动时，经验为
   `8 + randomBelow(2)`；无人成功移动时经验为 0，且不消费该随机调用。
6. 每个未被防魔／Boss 部件免疫的目标都写入逐单位行动禁用位，即使四向均无合法退格；
   该单位不能选择、移动、攻击、施术、休息、参与 AI 调度或反击。玩家施放后目标跳过
   紧接着的敌方阶段，并在下一完整回合入口解除；反向施放时，side 1 目标跳过下一玩家／
   我方自动阶段，并在敌方阶段开始前解除。它不是八槽普通状态。
7. 表现使用 `MAGIC/10 + UN/50`，两轮扩散、每轮六帧，共 120 native ticks，
   第一轮只画距施法者中心 1 格的范围值 2 圈，完整六帧后第二轮才画距中心 2 格的
   范围值 1 圈；中心格和另一圈不同时绘制。每轮开始请求一次 `UN/50`；最后一帧绘制
   后保持 10 native ticks，再清除效果并提交规则。全部表现完成前不得移动单位或写经验。
8. 提交后，冰封单位持续显示原版 `MAGIC/10` 冰壳末帧投影，直至对应阵营阶段结束并
   清除行动禁用位；该持久图形不计入已经完成的技能动画对象。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| `1L` 中心命中 | 50 伤害或被防魔阻挡 | 预览显示三级范围，不提前显示随机结果 |
| `1L` 多目标 | 各自按范围值结算 | 表现结束后同一提交更新生命/移除 |
| `1C` 有合法退格 | 按下上左右首个合法格移动 | 时间线结束后棋子一次进入结果位置 |
| `1C` 无合法退格 | 单位不动但仍冰封 | 仍完成表现；无人移动则经验 0 |
| 冰封目标的下一本阵营阶段 | 不进入选择／AI 队列且不能反击 | 地图持续显示冰壳；阶段结束后清除 |
| 防魔 | 阻挡本次伤害/位移并被消费 | HUD 在提交后更新，不在表现中提前消失 |
| 取消 | 无状态或 PRNG 变化 | 返回上一层菜单并保留行动资格 |
| 致死后触发胜负/转职 | 技术原子提交完成后进入既有后置链 | 不允许表现层自行判胜或打开转职 |

## AI 使用

- 玩家、我方自动和敌方 AI 都调用同一合法性、准备结果与原子提交函数。
- stage 1 两名敌方修女的可用池仍为 `1F/1H`，动作范围及结算读取 `REMAKE-009` 的双方
  统一 action definition：`1F/1H` 均为范围 `5`；不再随机先抽一个动作再因无目标失败。
- 依 `REMAKE-012`，修女在当前状态允许行动时对全部合法候选统一评分：能确定击杀的
  `1F` 优先，其次是生命低于 `40%` 的友军治疗，再次是有效 `1F`、其他实际治疗；
  平局使用固定格号、路径长度和地形顺序，不读取 PRNG 结果。
- 所有技术候选都只从修女当前位置建立范围，路径必须只有原格；不得为了取得技术目标先
  移动。当前位置没有合法技术时，追击态仍可改选移动后普通攻击或只移动推进。
- 没有合法技术时按当前守卫／警戒／追击状态待命、休息或推进；不得由 UI 或动画改选。
- 葛蒂拉斯的 `1L/1C` 在本切片只提供玩家入口；不为未出现的敌方魔術士虚构 AI 用例。

## 保存与恢复

- v9 战中档在 v8 军团 AI 快照基础上，逐单位保存行动禁用位；v8 及更早旧档迁移为
  未冰封，不能虚构存档时不存在的冰雪结算。v7 第 1 关旧档仍按可观察棋盘确定性迁移
  军团 AI，不能在读档后把已活动军团重置为警戒。
- 表现期间不能存档；只有原子提交前的玩家状态或提交完成后的玩家状态可进入记录入口。
- 读取后同一语义动作产生相同目标、伤害、位移、经验、胜负和 PRNG 后态。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | `1F` 使用统一防魔修正及双方范围 `5`；所有同名动作使用同一范围、数值、效果顺序和消费时点 |
| `legacyStrict` | 可保留炎暴不先检查防魔及玩家/AI 数值分表；冰雪与默认规则都固定施法者中心 |
| 可开放 Mod 字段 | 菜单有序 action IDs、可选目标动作的选择半径、冰雪效果半径、伤害表、位移顺序、表现 ID；改变后必须改变规则/内容身份 |

## 表现与可访问性

范围预览使用与普通/射击共享的非零格全亮、零值格 25% 网点合同，并以颜色之外的
轮廓区别选择范围与效果范围。表现事件只携带语义 action ID、中心、受影响单位与原生
时间线 ID；DOM/Phaser 不读取或重算伤害。加速、减少动态、静音和失焦恢复只能缩短或
跳过等待，不能提前提交或改变 PRNG。

## 验收场景

1. Given 魔術士选择 `1L`，中心/中层/外层各有一名 100 生命敌军，When 表现完成，
   Then 三者生命依次为 `50/65/80`，表现前均保持 100；
2. Given `1L` 范围内一名防魔敌军，When 提交，Then 生命不变、防魔归零，其他目标
   正常受伤；
3. Given `1C` 目标可向下移动，When 表现完成，Then 生命不变、单位向下移动一格并取得
   `8..9` 经验；若四向都非法，则单位不动且经验为 0；
4. Given 修女同时存在确定击杀、紧急治疗或普通有效目标，When 敌方阶段规划，Then 按
   `确定击杀 → 紧急治疗 → 有效伤害 → 一般治疗` 选择，且不为评分预消费 PRNG；
5. Given 某目标位于统一 `fire-1` 合法范围内、但原版 AI `1F=4` 表无法覆盖，When 敌方
   修女在 `stableRemake` 选择炎暴，Then 目标合法且范围图与同位置玩家施法完全一致；
6. Given 目标只在修女移动后的技术范围内、但不在其当前技术或移动后普通攻击范围内，
   When 敌方阶段规划，Then 不施术且不因此解除军团警戒；
7. Given 相同初态和动作，When 使用正常/加速、地图/全景、静音/有声，Then 单位、状态、
   经验、胜负与 PRNG 完全一致。
8. Given `1C` 范围内一名未免疫敌军，When 表现提交，Then 其地图冰壳可见且不进入紧接
   敌方行动队列；When 下一完整回合开始，Then 冰壳和行动禁用位同时清除。
