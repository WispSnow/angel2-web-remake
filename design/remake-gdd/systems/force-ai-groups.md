## 玩家目的

同一战场可以同时存在玩家军团、独立友军军团和多个敌军军团。玩家命令只能作用于明确
归属玩家的单位；每个 AI 军团按自己的策略与目标行动，不能因原版行为号相同或同属一个
阵营而串队。

## 证据与决策

- `[OF]` 原版逐槽行为号、职业分派和关卡模块仍保存在关卡 `originalFacts` 与逆向产物中；
  它们是原版行为输入，不天然等同于 Web 版控制权或现代军团身份。
- `[SR]` `REMAKE-012` 已允许语义 AI 状态替代逐槽运行时策略；`REMAKE-020/021` 明确第
  3 关独立友军、防御区策略、敌方双军团目标与玩家集团命令边界。
- `[DD]` `REMAKE-022` 将军团 ID、阵营、成员、控制权、主将、AI 策略和目标策略提升为
  通用模拟层内容合同。关卡只声明数据，不用槽位分支决定调度与目标。
- `[DD]` 第 4 关纸面合同声明玩家护送军团、独立结界引导者和敌方守卫三个军团；这里只
  复用既有 `player/independent-ai` 控制合同；路线脉冲作为关卡显式策略。
- `[DD]` `REMAKE-037` 将 `expert` 设为双方默认自动战斗教义；原版行为号继续作为警戒、
  移动许可等内容输入，但不再选择一套较弱的 side 1 动作规划器。
- `[OF]` 原版成对领队／跟随行为的近端判据是“领队已存在于跟随者的普通移动图中”，机器
  记录见 `../../../reverse/parsed/native/ai-rules.json` 的
  `rules.movement.pairedLeaderFollowerBehaviors`。该图的模式 `A` 把同阵营单位视为可穿越
  的通行格，不是墙。
- `[OF]` 该“普通移动图”的模式与种子已于 2026-08-16 逆向闭合（`1000:1C0E`，笔记见
  `../../../reverse/notes/ai-decision-system.md`）：模式取 `[cs:017F]`，即 `1000:2300`
  装载器比较 `Y`/`A` 的相位基础移动模式；种子取 DS:`0D47h`，即行动者的原始移动值，
  **没有**行为 2 门控图那种 `max(移动力, 8)` 下限。因此在高进入代价地形上，原版跟随者
  的普通移动图确实很小，领队容易判为远端而触发归队移动。
- `[DD]` `REMAKE-091` 把跟随移动收敛为“无事可做时才归队”：跟随者当前已有合法职业动作或
  正交相邻的合法敌方目标时先执行该动作，编队移动只在没有可执行动作时接管。上一条已确认
  原版不会让位，因此这是明确的复刻产品选择，不是原版行为的还原。

## 触发与输入

- 进入条件：关卡构造战斗单位后，使用同一关卡的军团定义建立注册表并立即验证。
- 合法行动者：`control: player` 的 side 1 单位接受玩家单体和集团命令；
  `control: independent-ai` 的单位只进入自己的 AI 阶段。
- 合法目标：军团可声明一个或多个优先敌对军团；只要其中仍有存活成员，进攻动作不得
  越组。优先组全灭后执行明确的 `all-opponents` 或 `wait` 兜底。
- 取消边界：玩家取消菜单不会改变军团归属或 AI 状态。
- 提交时点：军团策略只负责计划合法动作；移动、战斗、技术、经验与状态仍由既有模拟
  结算器提交。

## 有序规则

1. 已迁移关卡构造时验证每个单位恰好归属一个军团、军团 ID 唯一、成员存在且阵营一致；
2. 验证玩家军团只在 side 1、集团主将属于该玩家军团且全场最多一个集团命令主将；
3. 验证目标军团存在且属于敌对阵营，并验证策略参数范围；非法内容立即拒绝启动；
4. 玩家输入、全体休息和集团命令一律按 `control` 筛选，不读取原版行为号来推断控制权；
5. 独立友军在玩家军团完成后进入独立 AI 阶段，不继承临时跟随目标或自由行动命令；
6. AI 先按军团 `doctrine.strategy` 选择规划器，再把军团目标过滤器传入进攻技术、普通
   攻击和追击；治疗不套用敌军目标过滤器，其友军范围由策略声明；
7. `terrain-hold` 先处理进入指定地形、优先治疗、低血休息和编队，再在允许地形内使用
   专家战斗排序；`expert` 是双方默认教义，并在每次提交后重选当前队列的下一行动者；
7b. `REMAKE-111` 给 `terrain-hold` 增加可选的集结项 `rally = { unitId, meleeHoldsFire }`：
   `unitId` 必须是本军团成员，构造时验证；声明 `meleeHoldsFire` 后，近战职责成员**不再
   规划任何主动进攻**（普通攻击、追击与近战职业技术都不再参选），休息门槛由
   `restThresholdPercent` 改成「不满血即休息」，满血后只做集结移动；远程与治疗职责成员
   规则顺序不变，只是把原来的原地待命兜底换成集结移动。集结移动与 `7a` 的编队跟随共用
   同一套候选排序与防区、路径过滤器，因此两条规则不会互相拉扯；集结点阵亡时集结项失效，
   规划器退回原地待命。集结与编队跟随的**进展按防区内的真实路径代价判定**（以集结点／领队
   所在格为种子反向传播、限制在允许地形内、同阵营单位仍是通行格），直线距离只在完全没有
   防区内通路时兜底——否则防区里一处地形缺口就会把所有合法绕行读成「更远」而卡住整条侧翼；
   声明集结点后，进入防区的落点也先按「进区后离集结点还剩多少路程」排序。反击不受影响：
   交出的是主动进攻权，不是防御；
7a. `REMAKE-091` 编队跟随的两条边界：其一 `[OF]`，“领队是否已在近端”按原版模式 `A`／`Y`
   语义判定——用跟随者的普通移动图（种子为原始移动值、无 `8` 下限），同阵营单位是通行格
   而不是障碍，不再要求跟随者能实际落在领队所在格；其二 `[DD]`，跟随移动只在跟随者本回合
   没有合法职业动作、也没有正交相邻合法敌方目标时接管——原版在这种情况下仍会归队，本条
   是复刻的可玩性选择。两者都不放宽防区、路径或目标过滤器，跟随者仍不得离开允许地形；
8. 表现层只为玩家单位紧凑显示控制权和行动状态；独立友军以单行“友军・战术…”投影
   内容作者声明的高层意图，敌军只显示战术。基础单位卡不显示军团名称，不把军团标签、
   策略 ID 或目标组直接当作战术；表现层不拥有或改写上述状态。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 玩家军团 | 接受玩家操作与集团命令 | 紧凑显示“我方・玩家・可行动／已行动” |
| 独立友军 | 玩家不能选其行动；按独立 AI 排程 | 单行显示“友军・战术…” |
| 多个敌军军团 | 各自使用声明的策略与优先目标 | 只显示高层战术 |
| 默认专家教义 | 友军 NPC、“自由行动”和敌军共享候选、评分与动态重选 | 复用既有行动反馈 |
| 优先目标全灭 | 执行声明的全敌兜底或等待 | 不生成跨组隐式规则 |
| 非法定义 | 构造阶段抛出内容错误 | 调试／测试直接失败 |
| 保存/读取 | 归属与策略由关卡内容重建；可变激活态单独保存 | 读取后调度和目标不变 |

## AI 使用

军团策略只组合既有可达格、路径、动作合法性和结算 API。它不能绕过冰封、禁咒、射程、
目标阵营、行动位或 PRNG 边界。新增通用策略须扩展有类型的 `doctrine` 联合与对应规划器，
不得在控制器或关卡槽位条件中添加隐式分派。

## 规则集与 Mod

| 配置 | 行为 |
| --- | --- |
| `stableRemake` | 使用显式军团控制权、策略和目标合同 |
| `legacyStrict` | 可由关卡声明原版逐槽策略，但仍须显式声明 Web 控制权 |
| 可开放 Mod 字段 | 军团 ID、成员、主将、策略 ID、地形/回血参数、集结点与近战交权、优先目标与兜底 |

改变成员、控制权、主将、策略或目标会改变内容／规则身份。行为号不得作为缺省控制权写入
新关卡；旧关卡在迁移前可使用兼容回退。

## 表现与可访问性

阵营／控制／行动摘要和玩家向战术文本由 UI 投影并被屏幕阅读器读取；军团名称属于按需
战术详情，不占用基础属性列表。动画速度、镜头跟随和减少动态不改变排程。玩家不能通过
视觉设置或输入焦点取得独立友军控制权。

## 验收场景

1. Given 一个原版行为号为 `0`、但声明为 `independent-ai` 的 side 1 单位，When 玩家
   打开集团命令，Then 该单位不进入玩家队列，随后进入独立友军 AI 阶段；
2. Given 两个敌军军团分别优先两个不同友方军团，When 两组都存活，Then 各军团的进攻
   目标只来自自己的优先组；目标组全灭后才按声明兜底；
3. Given 成员重复、跨阵营、主将不在本军团或目标为友军的定义，When 构造战斗，Then
   在任何回合开始前拒绝内容；
4. Given 第 3 关现有四个军团，When 运行防御区、集团命令和双目标回归，Then 行为与
   `REMAKE-020/021` 一致，且关卡战斗类中不再存在按敌军槽集合选择目标的分支；
5. Given 一个魔術士属于玩家军团或独立友军军团，When 进入默认自动行动且技术合法，Then
   使用与敌军相同的完整专家候选，不退化为普通攻击；
6. Given 一个声明 `rally.meleeHoldsFire` 的防区军团，When 满血近战成员正交相邻就有合法
   敌方目标，Then 它仍不进攻，只在允许地形内向集结点靠拢；掉血后改为休息，同队远程成员
   则先射击／治疗，无合法动作时才靠拢；
7. 保存/读取与表现设置差异不会改变军团归属、策略选择或确定性结果。
7. Given 第 3 关第四军团的行为 4 跟随者是弓兵、领队不在其一格森林移动图内、但棋盘上
   存在合法射击目标，When 独立友军阶段规划，Then 提交射击而不是编队移动；Given 同一
   跟随者没有任何合法射击目标，Then 仍按编队移动靠近领队且不离开森林／山地；
8. Given 行为 4 跟随者与领队之间只隔一名同军团友军，When 判定领队是否在近端，Then 按
   模式 `A` 的通行语义视为可达，不因友军占格而误判为“领队在远端”。
