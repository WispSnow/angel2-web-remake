## 玩家目的

玩家可以选择让剧情对白由角色语音读出，每个角色的声线固定，旁白另有一个声音。剧情仍以画面文字为准：
语音是可选的表现增强，关掉后游戏与现在完全一样。

## 触发与输入

- **进入条件**：同时满足以下三条：
  - 语音音量不为「關」；
  - 剧情对白层开始一页的逐字，即窗体展开与肖像就绪之后，与逐字声、口型同一时点；
  - 该页的片段已下载并解码。
- **合法行动者**：当前浏览器玩家。语音不产生任何玩家行动。
- **合法目标**：当前页的活动窗口新打出的文字：
  - 追加文字的页面（`revealStart > 0`）只读新追加的部分；
  - 另一扇仍保留在画面上的窗口不重读；
  - 只有肖像、没有文字窗的页面（如 SAY/0043 的斥候）没有语音。
- **取消边界**：以下情况会切断当前语音，淡出约 0.1 秒：
  - 推进到下一页；
  - 确认跳过整段对话，或跳过演出序列；
  - 对白结束、离开剧情表面；
  - 把语音音量调到「關」。

  补完本页（逐字中的第一次主操作）**不**切断语音。
- **提交时点**：语音只读模拟与对白状态，不提交任何东西。自动翻页提交的是与玩家主操作完全相同的
  “推进到下一页”，不新增任何控制器入口。

## 有序规则

1. **片段键**：`(SAY 记录号, KY 序号)`，即 `DialoguePage.source.{record, wait}`。第 0 关手写的对白
   使用同一键。每个键最多一个片段；没有片段的页面就是无语音页。
2. **开页**：页面开始逐字时，若片段已解码，就从头播放该片段，并把这一页标为“有语音页”。若片段未就绪
   （未下载、下载失败或解码失败），这一页就是无语音页：照常播放逐字声，不在页中途补播语音，也不自动翻页。
   - 片段可以声明 `startGlyph`（默认 0）：逐字打到第几个发音字形时才开始播放。原以为 SAY/0164 `KY` 20 要用它跳过
     页首笑声；实现时核对运行时页面，笑声在独立的 `KY` 19，`KY` 20 以 `revealStart` 接在其后，`startGlyph` 为 0 即指向
     第一个说话人的词（`REMAKE-188`）。
3. **逐字声**：有语音页在整页逐字期间不提交「說話」逐字声请求。无语音页的逐字声规则不变。
4. **逐字与口型**：速度、补完与 SAY/0164 的页内换脸都照现有规则，由逐字驱动，不跟语音对齐。口型由用户 2026-11-17 改为跟随语音
   （[`REMAKE-192`](../../../reverse/gdd/web-remake-rule-decisions.md#remake-192可选高清肖像说话动画跟随语音)）：有语音的页面，语音此刻有声
   才说话，语音里的停顿闭嘴，片段说完才停，与逐字是否打完无关；原版肖像在有声期间每 80 ms 切换一次，高清肖像按说话节奏与过渡嘴形开合。
   无语音页仍照原版逐字切换；片段中途放弃时退回逐字驱动。
5. **推进**：玩家推进，或自动翻页触发推进时，当前片段约 0.1 秒淡出，下一页按第 2 条重新判定。
   全局同时最多一个语音片段在播放。
6. **自动翻页**（只在「自動翻頁」开启时生效）：有语音页在以下条件全部满足后，再等约 0.6 秒，提交一次推进：
   - 逐字已完成（自然打完或被补完）；
   - 页面已开始接受输入（`DL` 等待跑完）；
   - 片段已播完。

   以下情况不自动翻页，等待玩家输入：
   - 无语音页；
   - 跳过确认框打开时；
   - 暂停时；
   - 复刻资料层（「復刻說明」「圖鑑」「RoadMap」）打开时。

   玩家先按下的操作照常生效，并取消本页的自动翻页计时。
7. **暂停**：全局暂停挂起语音的音频时钟，片段停在当前采样位置；自动翻页计时同样冻结。恢复后从原位置继续。
8. **音量**：语音增益只在播放边界读取。调档即时作用于正在播放的片段，不重新开始。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 语音关闭（默认） | 不请求、不下载任何语音文件；逐字声与现在完全一样 | 无 |
| 正常有语音页 | 片段与逐字同时开始；本页没有逐字声 | 文字、肖像照常；口型跟随语音（`REMAKE-192`） |
| 逐字中第一次主操作 | 文字补完，语音继续 | 与现在相同 |
| 语音未播完就推进 | 片段约 0.1 秒淡出，下一页立即开始 | 与现在相同 |
| 跳过整段对话 | 跳过确认框打开期间语音继续；确认后淡出 | 与现在相同 |
| 片段缺失或失败 | 本页按无语音页处理，不抛异常，不阻塞对白 | 首次失败时状态列给一次现代文字提示 |
| 关卡中途开启语音 | 后台下载本关片段，下载完成前的页面都是无语音页 | 无 |
| 保存／读取 | 存档不含语音状态；读档后已消费的剧情不重播，之后的剧情按当前偏好判定是否有语音 | 无 |

## AI 使用

不适用。AI 不读取语音状态，语音不影响 AI 规划、行动顺序或 PRNG。

## 配音稿与生产流程

- `[DD]` **配音稿与显示文本分开存放。** 配音稿逐片段记录以下内容，规范化规则见评估第 7 节：
  - 片段键与说话人；
  - 显示文本的哈希；
  - 实际送去合成的文字；
  - 平台、模型、音色、生成参数。

  规范化包括：
  - 去掉「」；
  - `．` 串改为省略号；
  - 繁转简；
  - 专名读音词典；
  - 咒语逐字分读；
  - 错别字按本意读。
- `[DD]` **完全不配音的文字**：调试残留的“SOUND CARD BREAK”。这些页面在配音稿里记为“不配音”并写明原因，
  不能静默缺片段。“得經驗值00000 點”原也列在这里，`REMAKE-202` 起改为只读「獲得經驗值」。
- `[DD]` **合成参数**：
  - ElevenLabs：`eleven_v4`，`language_code: "zh"`；
  - MiniMax：`speech-2.8-hd`，国内站 `api.minimaxi.com`，`language_boost: "Chinese"`。

  每句可多次生成、人工挑一条；入选片段做响度归一。
- `[DD]` **语速**：用户 2026-11-17 在游戏中试听后，认为角色说话太从容、与战斗气氛不合，定为 ElevenLabs 角色片段一律
  1.15 倍速；旁白与亡灵拼接段保持原速。`eleven_v4` 不理会 `voice_settings.speed`，所以在成品处理时用保持音高的变速实现，
  倍率写在 `scripts/lib/voice-cast.mjs`，配音稿与清单逐片段记录，生成器拒绝倍率不符的片段。
- `[DD]` **工作区不进仓库。** 生成稿、候选版本和工具都放在 git 忽略的 `tmp/voice-over/`，与 Suno 工作流相同。
  入选成品必须归档：库音色可能被作者下架，不能依赖“需要时再生成”（评估第 6 节）。
- `[DD]` **资产**：
  - 成品放在私有素材包 `WispSnow/angel2-assets` 的 `voice/` 目录，编码与现有音乐同为 OGG 单声道；
  - 同目录的 `voice-manifest.json` 记录片段键、文件、时长、哈希、`startGlyph`、说话人、音色和显示文本哈希；
  - 生成器 `scripts/generate-voice-catalog.mjs` 产出 `src/game/content/voice-catalog.generated.ts`，
    命令为 `pnpm content:voice`，之后再跑 `pnpm content:resource-manifest`。素材包由用户自己推送。
- `[DD]` **生成器必须逐项校验**：
  - 每个片段键都对应一个现存的 SAY 对白页；
  - 显示文本哈希与当前对白页一致，不一致时拒绝生成；
  - 89 条记录的每个 `KY` 页要么有片段，要么在配音稿里写明不配音的原因；
  - 每个片段的音色与上表选角一致，语速倍率与“语速”一条一致；
  - 片段实际合成所用的音色（生成记录）也与选角一致，改选后旧音色的版本不会混进成品（`REMAKE-199`）。

  对白文字日后被修正时，这道校验会强制重配受影响的片段。
- `[DD]` **加载**：
  - 语音文件不进各关基础资源包；
  - 语音开启时，进关资源门额外预载本关用到的片段，与 `REMAKE-181` 的改编曲相同；
  - 载入画面收起前，资源门还要把进关后马上要开的页面解码好：每段剧情的第一个有语音页，以及当前停在的剧情页
    与其后几页（调试场景、读档可能直接停在剧情中段）。不这样做的话，第一页要等播放层的前瞻解码，慢的时候
    就成了无语音页（用户 2026-11-19 回报）；
  - 关卡中途开启时按需下载；
  - 下载或解码失败都不阻止进关，只让对应页面成为无语音页。
- `[DD]` **调试入口**：调试场景不经过开场方框，没有那一次手势。从 `/debug.html` 点连结进入时，浏览器已允许出声，
  调试入口探测到这一点就照已解锁挂上，第一页就有语音；直接贴网址开新分页时仍要先点一下画面。这一条只影响
  调试入口，正式流程不变。
- `[DD]` **体积**：全部片段约 20–27 MB（评估第 8 节估计），按关分散加载。

## 表现与可访问性

- 语音是文字的补充，不替代文字。画面文字、分页与逐字节奏保持原样，所以关闭语音或听不清时不会丢失任何内容。
- 语音有独立音量，与音乐、音效分开调节；「關」即完全关闭，连同下载一起停止。
- `[DD]` **口型**：原先口型照原版规则由逐字驱动，文字打完后语音还在继续，嘴已经闭上。用户 2026-11-17 决定原版与高清两种肖像都
  改为跟随语音（`REMAKE-192`），规则见“逐字与口型”。
- `[H]` **SAY/0164 的换脸**：换脸由逐字驱动，每字 80 ms，比语音每个词约 0.5 秒快得多，所以脸会先换完。
  是否改由语音的词边界驱动换脸，留待试玩后决定。
- 「複刻說明」需新增一条，写明剧情语音由 AI 语音合成服务（ElevenLabs、MiniMax）生成、旁白与角色声线的来源，
  以及与本作其他素材相同的非商业使用范围。

## 验收场景

1. Given 首次启动（偏好为默认），When 播放任意剧情，Then：
   - 不发出任何语音请求；
   - 逐字声、按键次数和截图都与未接入本系统时一致。
2. Given 语音为「最大」且第 0 关关前剧情的片段已就绪，When 一页开始逐字，Then：
   - 该页片段开始播放；
   - 本页没有「說話」逐字声请求；
   - 逐字仍为每字 80 ms。
3. Given 第 2 条的页面正在逐字，When 按一次主操作，Then 文字补完、语音继续；When 再按一次，Then：
   - 页面推进；
   - 旧片段在约 0.1 秒内淡出；
   - 新页的片段随新页逐字开始。
4. Given 「自動翻頁」开启，When 有语音页的片段播完，Then 约 0.6 秒后恰好推进一页；When 先按主操作，
   Then 按现有规则处理，并取消本页的自动翻页；When 遇到无语音页，Then 停下等待输入。
5. Given 有语音页正在播放，When 右键并确认跳过，Then 语音淡出、整段对话结束；When 跳过确认框打开但未确认，
   Then 语音继续，且不自动翻页。
6. Given 语音与自动翻页计时都在进行，When 全局暂停，Then 片段位置与计时都不前进；When 恢复，Then 从原位置继续。
7. Given 某页片段下载失败或被删除，When 播放该页，Then：
   - 按无语音页处理，播放逐字声，不自动翻页；
   - 没有未处理异常；
   - 状态列只提示一次。
8. Given 语音关闭，When 进关，Then 资源门不请求语音文件；Given 语音开启，Then 资源门预载本关片段；
   When 关卡中途从「關」调到其他档，Then 后台下载、不阻塞当前页。
9. Given 「開場準備完成」方框，When 切换「劇情語音」，Then 偏好写入且不进入游戏；「音效開關」面板显示同一状态。
10. Given 同一存档与同一语义操作序列，When 分别在语音关、语音开、语音开且自动翻页开时运行，Then 模拟状态、
    PRNG、存档内容与战果完全一致。自动翻页只改变推进的时刻，不改变推进的次数与顺序。
11. Given 生成的语音目录，When 运行内容测试，Then：
    - 每个片段键都对应现存对白页，且显示文本哈希一致；
    - 89 条记录的每个 `KY` 页都有片段或写明不配音的原因；
    - 片段音色与选角表一致；
    - SAY/0164 `KY` 20–23 是拼接片段，且 `KY` 20 的 `startGlyph` 指向第一个说话人的词。
12. Given 语音开启且击杀者声线的台词已下载，When 击杀后「得經驗值 N 點」窗打开（任意 N），Then（`REMAKE-202`）：
    - 播放击杀者声线的「獲得經驗值」片段，本窗不放逐字声；
    - 文字不是原文数字栏写入后的样子（如被 Mod 改过）时为无语音页。
