## 玩家目的

工兵用一次完整行动移动到附近空格，并把落点四周可修改的地面铺成该关铁板。铁板不是
一次性特效，而是持续改变移动代价与地形防御的战场状态；落点本身不会变成铁板。

## 证据边界

- `[OF]` 工兵职业记录 `5A/34` 的三个等级都显示 `1K/鐵板` 与 `2K/障礙`；本切片只开放
  已逐项闭合的 `1K`，`2K` 在自己的序号到达前仍不可提交，不能用 `1K` 兜底。
- `[OF]` 玩家 `1K/2K` 分支建立 seed `5`、mode `M` 的范围；路径传播读取行动者移动表，
  规则 `98/99` 不可进入，可穿过空格与同阵营占格，但最终目标必须为空。
- `[OF]` 确认后行动者使用普通移动流程到目标格；成功分支消费行动，但没有技术经验、
  伤害、治疗、状态或随机调用。
- `[OF]` 到达后按下、上、右、左的线性顺序检查邻格；逻辑地形槽 `0` 跳过，其他邻格都
  写同一个关卡构筑源 token。邻格是否占有单位不参与检查，中心格不改。
- `[OF]` 已开放的原版关卡 `0..4` 构筑源 token 分别为 `50/64/4/28/27`；第 1 关 token
  `64` 映射逻辑槽 `3`。视觉 tile 来自相应 `B/0,2,4,6,8` 图形记录中的同 token。
- `[OF]` 玩家入口在 `0000:761A..762F` 直接进入构筑分支，绕过动作分发表；分发表的
  `1K/2K` 包装器虽可横向写五个连续 token，却没有正常玩家或 AI 生产者，属于休眠路径。
- `[OF]` 工兵是 ordinary AI 类别，原版技术池不会生成 `1K/2K`；敌我自动单位只执行
  普通移动、攻击、休息等既有行为。
- `[OF]` 构筑没有专用图形、声音、描述符或固定等待；可见顺序只有普通逐格移动，随后
  地图重绘显示新 tile。
- `[SR]` `REMAKE-025` 以几何边界跳过地图外方向，拒绝 DOS 线性跨行／内存越界；动态
  地形成为模拟和存档状态，所有规则消费者读取同一覆盖表。

## 触发与输入

- 进入条件：工兵任意等级、未行动、未冰封且未被禁咒；初始动作菜单显示“技術”，二级
  菜单当前只列已经完成的“鐵板”。
- 选择范围使用固定 seed `5`，不是职业正常移动力；源格值为 5，每进入一格扣该格对工兵
  的移动代价，只有结果仍大于 0 的格可继续／可选。因此全为代价 1 时最远四步。
- 同阵营单位可以被路径穿过但不能作为最终落点；敌军格既不能穿过也不能选；目标必须
  在地图内、范围值非零且当前为空。
- 取消目标选择回工兵技术菜单，再取消回动作菜单；取消不移动、不写地形、不消费行动或
  PRNG，也不建立临时覆盖。
- 确认时准备并冻结 `{actorBefore, target, path, four neighbor results}`；准备阶段不改单位或
  地形。表现先播放冻结路径，完成后原子提交行动者位置、地形覆盖与行动位。

## 有序规则

1. 验证职业、任意等级、状态、行动位和 `iron-plate` 关卡内容映射；
2. 以动态地形快照、单位占格和 seed `5` 建立 mode `M` 代价图与确定路径；
3. 验证目标为空；复制从行动者到目标的逐格路径，准备阶段不写当前位置；
4. 以目标为中心按下、上、右、左枚举几何邻格；越界或当前逻辑槽 `0` 的方向记录为跳过；
5. 其余方向准备为语义覆盖 `kind=iron-plate`，即使邻格有单位或已是铁板也合法；重复覆盖
   结果幂等，不产生额外经验、等待或随机调用；
6. 播放现有普通移动表现；移动墙钟内模拟仍保持准备前状态，不能保存中间格；
7. 原子验证准备未陈旧，写行动者目标格、覆盖表和 `acted=true`，再刷新地图、地形检查、
   范围与单位投影；战役 roster 只记录工兵原有成长／生命，不把地形写进 roster。

## 动态地形与存档

动态覆盖以稳定语义记录 `{position, kind: "iron-plate"}`，按线性格升序序列化。关卡内容
负责把 `iron-plate` 映射到本关的原始 token、逻辑槽和 40×44 tile；模拟状态、存档与
领域 API 不暴露 `B/*` 路径。覆盖后的 `terrainSlotAt` 是移动、范围、地形防御、普通攻击、
AI 与 UI 检视的唯一入口，静态底图只负责未覆盖格。

当前 v18 战中档以 `terrainOverrides` 保存鐵板与障礙动态地形；v17 鐵板覆盖无损迁移，
v16 及更早版本迁移为空覆盖。恢复
时拒绝越界、重复位置、未知 kind、位于关卡槽 `0` 上的铁板覆盖，以及内容未声明该 kind
的档案。保存只允许在提交前或提交后，不能捕获移动演出中间态。

## 表现与可访问性

- 使用既有普通移动路径、方向、逐格时序和音效边界；构筑本身不请求音频，不增加停顿。
- 提交后在静态地图上方、网格与单位下方绘制该关原始铁板 tile，像素缩放关闭；有单位的
  邻格仍先显示 tile，再显示单位。
- 范围预览沿用原版抖动遮罩；状态文字明确“選擇工兵移動並鋪設鐵板的空格”，不能称为
  敌方／我方目标。完成文字报告实际改变格数；重复铁板可计为覆盖格但另显示新增格数。
- technique-lab 采用第 1 关 token `64`：初态显示工兵、目标与四邻格；播放／seek 的唯一
  语义节点是“移动前”与“构筑完成”，完成帧显示精确 tile。读数说明无专用动画、无伤害、
  无经验、无声音；它仍不写战役存档。
- 减少动态或加速可立即完成移动墙钟，但提交顺序、路径、覆盖格和行动位不变。

## AI 使用

原版工兵没有构筑技术池，因此 `stableRemake` 与当前 `legacyStrict` 规划器都不选择 `1K`；
它继续使用 ordinary AI。竞技场必须证明敌方工兵不会因存在可铺格而自动构筑，同时玩家
控制的工兵可在所有三个等级使用同一 `1K`。未来 Mod 若新增构筑 AI，必须单独声明目标
评分、路径、边界与 deterministic tie-break，不能混入原版策略。

## 验收场景

1. Given 全为代价 1 的可通行区域，When 工兵打开 `1K`，Then 最远合法空格为四步；同阵营
   占格可穿过但不能落脚，敌军格阻断，代价 `98/99` 不可进入；
2. Given 合法目标四邻格分别为普通地形、槽 `0`、已有铁板和有单位的普通地形，When 提交，
   Then 中心不变、槽 `0` 跳过、其余三格成为铁板，单位保持且立即读取新地形；
3. Given 目标在地图边缘，When 提交，Then 只处理几何合法邻格，不跨行；路径与地形写入前
   PRNG state/calls 不变，经验、生命和状态不变；
4. Given 移动表现尚未完成，Then 行动者与覆盖表仍是准备前值；When 完成，Then 位置、覆盖
   和行动位同一次提交，地图显示关卡原始 tile 且地形检查返回新逻辑槽；
5. Given 构筑后保存，When 读取新版本战中档，Then 覆盖、单位、镜头与后续路径一致；v16
   档迁移为空覆盖，非法／重复／未知覆盖安全拒绝并给出既有可见坏档反馈；
6. technique-lab 的完成节点显示第 1 关 token `64` tile 四邻格结果，自动断言零专用音频／
   零构筑动画；人工截图确认像素、层级与落点；
7. 竞技场中三个等级的我方工兵都只显示已完成的 `1K` 并能提交；敌方工兵的自动回合不会
   选择构筑。正式玩家流程通过技术菜单、空格目标、普通移动与即时铺板闭环。
