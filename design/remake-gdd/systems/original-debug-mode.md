## 玩家目的

原版《天使帝國 II》带有一套玩家社区熟知的调试模式，包括：

- 即时胜利与直达结局；
- 双方全体生命设定；
- 经验与生命微调、全员再行动；
- 台词预览与格号读数；
- 第 37 关首领数值显形；
- 音乐盒，其中可以听到正常流程听不到的 `T04.RIX`。

复刻版把它作为可选的玩家功能提供：想重温、测试或练习的玩家可以开启；不开启的玩家完全看不到它的影响。

## 触发与输入

- 开关：宿主工具列「原版Debug」，`aria-pressed` 反映状态，按浏览器保存。关闭立即生效；进行中的音乐盒覆盖曲不受影响。
- 调试热键：开关开启、Caps Lock **处于开启状态**、战场处于我方阶段的待机光标，且没有选单、对白、表现或转职等待时，以下按键生效：

| 按键 | 效果 | 批次 |
| --- | --- | --- |
| F3 | 原版选单 `敵全滿 `／`敵全滅 `／`敵  1 ` | 一 |
| F4 | 原版选单 `我全滿 `／`我全滅 `／`我  1 ` | 一 |
| F10 | 我方全员解除已行动 | 一 |
| U／D | 光标下单位累计经验 +50／−50 | 一 |
| 数字键盘 `-` 或 `-` | 光标下单位生命 −10 | 一 |
| S | 光标下单位以自己的肖像说台词 `22h`「我．．．我好難過．．．｜頭好痛啊！」 | 一 |
| 2 | 在战场左上显示光标格号与难度值（原版五位数） | 一 |
| J | 即时胜利 | 一 |
| 数字键盘 `*` 或 `*` | 直达主线结局的战绩卡 | 一 |
| M | 音乐盒 | 一 |
| F1 | 光标下单位的 AI 行为面板（原版 13 个行为名，0..11 可选） | 二 |
| F2 | 原版选单 `我  EDIT`／`敵  EDIT`／`兵    種`／`地    型`；前两项第二批、后两项第三批 | 二、三 |
| F5／F6 | 光标下任一方单位施放任一技术（原版一级、二级选单） | 二 |
| 1（按住） | 视口每格的原版范围值；我方阶段的选格中同样有效 | 二 |

- 浏览器无法可靠侦测“按住” Caps Lock（macOS 只在切换时发出事件），所以复刻以“开启状态”代替“按住”。
- 选格、转职等子状态不接受调试热键。这比原版收紧，避免调试操作打断一个半提交的动作。
  例外是按住 Caps Lock+1 的范围读数：它只显示、不改状态，所以选格中也有效。
- Caps Lock 开启时，上表按键不再执行其平常的含义：S、D 不移动光标，M 不打开音量面板。方向键与 W／A 照常移动。

## 有序规则

1. 校验：开关开启，热键条件成立；需要目标的功能要求光标格有单位，空格只在信息栏提示，不沿用上一个单位。
2. 第一批结算（全部不消耗战斗 PRNG）：

   | 功能 | 结算 |
   | --- | --- |
   | 全滿 | 该方每个单位生命 = 当前生命上限 |
   | 全滅 | 该方全部单位从棋盘移除；不播死亡表现，不触发击杀替补或形态转换，与原版只清棋盘一致 |
   | 1 | 该方每个单位生命 = 1 |
   | 经验 +50 | 累计经验加 50；生命若高于新上限则压到上限 |
   | 经验 −50 | 只在结果大于 0 时写入；生命压到新上限 |
   | 生命 −10 | 只在生命大于 10 时扣 10（`[SR]`：原版在生命恰为 10 时会留下 0 生命单位） |
   | 全员再行动 | 只清我方已行动状态，不解除冰封 |
   | 即时胜利 | 本场战斗结果强制为胜利 |
   | 直达结局 | 以本关进场时的战役名册与战绩建立主线结局，从战绩卡开始 |

3. 后续消费者：
   - 生命与移除变化后立即做一次胜负判定；经验变化后跑一次转职扫描（原版待机循环每一轮都会扫描）；
   - 即时胜利走本关正常的胜利事件、胜利回馈与存档询问；
   - 直达结局之后走战绩卡 → 结局 → 隐藏关；
   - 台词与读数只是表现，不进模拟。

### 第二批

1. F1 行为：
   - 校验光标格有单位、单位未锁定（固定路线／护送／剧情台阵、第 0 关路线敌军、女帝／龍／頭／手）；
   - 写入 0..11：存到单位（水战士整组）的 `debugAiBehavior`，先于关卡自己的行为值；
   - 我方单位以它决定指挥权：0 归玩家，非 0 交给自动阶段并显示 `N`；
   - 面板保持开着，关闭时跑一次转职扫描与胜负判定，我方若已没有可指挥的未行动单位就照常进入自动阶段。
2. EDIT：
   - 名字框：在场 → 整组移出棋盘（无死亡表现、无击杀替补／形态转换、不算击杀），记入离场名单；离场 → 关闭画面，
     下一次点格放回到空着、该职业可站的格，生命回满，冰封与已行动清除；未出战成员与未登场敌人不能放置；
   - 棋子框：在原版职业记录 0..34 中按方向走、不回绕，跳过本场资源门未备妥棋子／全景图／技术演出的职业；
     生命压到新上限，通用单位名字与肖像跟随职业，第 0／1 槽士兵经验补到 299，标记 `debugClassEdit`；
   - 行为框：0..11 不回绕，写本方行为；
   - 锁定：分身中的水战士、第 30 关维絲塔不能改职业；
   - 关闭时跑一次转职扫描与胜负判定。
3. F5／F6 技术测试：
   - 施法者为光标下任一方单位；不看职业、禁咒、已行动、冰封与行为；
   - 选格用原版种子；伤害类只能选 side 2、辅助类只能选 side 1；施法者不能用伤害技选自己；
   - 落雷与回復作用于所选目标那一方（施法者除外），冰雪冻住施法者的对方，祈禱扫我方；
   - 真实结算：消耗 PRNG，照常给经验（含击倒自己人的奖励）并写已行动；选格中取消回到战场；
   - VIRT 与本关未预载演出的技术不可选。
4. Caps Lock+1：
   - 按住时显示，放开即消失；只在我方阶段；
   - 数值：待机 1；移动为含本格剩余移动力（敌方邻接 1、可穿越友军格非零、不可达 0）；攻击为可攻击格 1；射击与技术为原版选格范围。

### 第三批

1. 覆写的范围与寿命：
   - 改动存在当前战斗物件上，不序列化；所有读职业资料行、移动消耗与地形防御的查表都先经过它，所以属性、等级、
     经验门槛、敌方成长、移动范围、地形防御、AI 与右栏都立刻按新值计算（原版每次载入单位情境都重选资料行）；
   - 换掉战斗物件（撤退、重开、下一关、回标题）或读取记录时覆写消失；
   - 存档与读取校验一律按原版数值进行。写出时生命高于原版上限的单位，连同在场我方的名册条目，压回原版上限。
2. 兵種（`0000:1294`）：
   - 画面照原版：13×3 职业格（side 2 棋子）、红框、`(100,160)` 面板、五行 × 七列五位数、行底与括线／刻线；不清画面，格外看得到战场；
   - 指针：悬停移动红框与行底；在行区之外按左键，面板换成红框职业；指到某一位时左键 +1、右键 −1，该位 0..9 不进位，按 16 位重组；
   - 全部 39 条记录、五行七列都能改。第 4、5 行与「魔防」列原版战斗本来就不读；第 7 列（等级）复刻的战斗规则也不读（等级按资料行序数计）；
   - `[SR]` 推导出的攻防不低于 0、生命上限不低于 1；`linear` 成长遇到门槛相等或倒序时不再延续；
     资料行照原版顺序选择，第一个没达到的门槛就停；
   - 退出（Esc、返回钮，或被胜负、重开、系统选单收起）时，双方生命高于新上限的压到新上限，只降不升；之后跑一次转职扫描与胜负判定。

   - 同一场战斗再打开时沿用上次选定的地形；
   - 退出后跑一次转职扫描与胜负判定。
4. `[SR]` 原版会选到表外或留下残值的边缘不复刻：
   - 兵種网格 x = 624、y = 150；
   - 列内第 6 个 8 px；
   - 地型条 x = 576；
   - 空的职业格 37..39；
   - 第 24 格「障礙」（profile 之间的重叠字）可以框选，但不能选定。
5. 复刻补充：
   - 键盘：方向键移动、Enter 换面板或选定地形、Tab 切换区域、＋／－ 改游标那一位、Esc 返回；

## 音乐盒

- 入口：「音樂開關」面板的「音樂盒」按钮（常驻），以及除错模式下的 Caps Lock+M。
- 名单：
  - 原版 31 首按原顺序列出，每项显示原版格式「`MUSIC-   NN-名稱.RIX`」与复刻撰写的用途说明；
  - 「原版未收錄」列出：
    - `TALK.RIX`：原版表内第 32 项，序号回绕后选不到；
    - 第 37 关敌方阶段专属曲；
    - 结局战绩卡曲、衰亡结局曲与制作人员表曲。
- 播放：
  - 原版单曲名单中的记录单曲循环；
  - 其余战场记录按“奇数入场 → 偶数循环”曲对播放；
  - 关闭音乐盒后所选曲继续，直到游戏下一次自己选曲（换阶段、剧情或换关）；
  - 「恢復原曲」立即交回游戏自己的选曲。
- 键盘：上下选择，Enter／Space 播放，Esc／Backspace 返回。

## AI 使用

AI 不使用调试功能。调试操作只改变棋盘状态，之后 AI 照常从公开棋盘规划。F1／EDIT 的行为覆写是 AI 的输入：
敌方与自动友军按覆写值规划（1 为原地，其余照各自规则），我方单位的覆写还决定它是否进入自动阶段。
兵種／地型的覆写同样是 AI 的输入：AI 读的属性、移动范围与地形防御都是改过的值，规划快取以覆写版本区分。

## 验收场景

1. Given 开关关闭，When 按 Caps Lock+J，Then 没有任何调试效果。S 键照常移动光标。
2. Given 开关开启、Caps Lock 开启、我方待机，When 按 F3 并选「敵全滅」，Then 敌方全部从棋盘移除，
   「全滅敵軍」类关卡进入正常胜利流程。
3. Given 光标在生命 10 的单位上，When 按数字键盘 `-`，Then 生命仍为 10。生命 25 时变为 15。
4. Given 光标在经验差 30 到达转职门槛的我方单位上，When 按 U，Then 经验 +50，并立即出现转职选择。
5. Given 任意关卡，When 按 J，Then 进入该关正常胜利流程。
6. Given 「音樂開關」面板，When 选第 26 首并播放，Then 播放 `T04.RIX`；关闭面板后音乐继续；
   进入敌方阶段时换回敌方曲。
7. Given 第 37 关、开关关闭，Then side 2 的单位详情显示 `?????`，地图上没有 side 2 生命数字；
   开关开启后两者都显示。
8. 保存／读取：开关本身不改变存档内容；除技术测试外，同一操作序列在开关前后得到相同的战斗 PRNG 状态。
