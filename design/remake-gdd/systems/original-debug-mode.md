依赖：语义输入、宿主工具列、战场控制器、音乐传输、单位详情 HUD、第 37 关表现、主线结局链

## 玩家目的

原版《天使帝國 II》带有一套玩家社区熟知的调试模式，包括：

- 即时胜利与直达结局；
- 双方全体生命设定；
- 经验与生命微调、全员再行动；
- 台词预览与格号读数；
- 第 37 关首领数值显形；
- 音乐盒，其中可以听到正常流程听不到的 `T04.RIX`。

复刻版把它作为可选的玩家功能提供：想重温、测试或练习的玩家可以开启；不开启的玩家完全看不到它的影响。

## 触发与输入

- 开关：宿主工具列「原版除錯」，`aria-pressed` 反映状态，按浏览器保存。关闭立即生效；进行中的音乐盒覆盖曲不受影响。
- 调试热键：开关开启、Caps Lock **处于开启状态**、战场处于我方阶段的待机光标，且没有选单、对白、表现或转职等待时，以下按键生效：

| 按键 | 效果 | 批次 |
| --- | --- | --- |
| F3 | 原版选单 `敵全滿 `／`敵全滅 `／`敵  1 ` | 一 |
| F4 | 原版选单 `我全滿 `／`我全滅 `／`我  1 ` | 一 |
| F10 | 我方全员解除已行动 | 一 |
| U／D | 光标下单位累计经验 +50／−50 | 一 |
| 数字键盘 `-` 或 `-` | 光标下单位生命 −10 | 一 |
| S | 光标下单位以自己的肖像说台词 `22h`「我．．．我好難過．．．｜頭好痛啊！」 | 一 |
| 2 | 在战场左上显示光标格号与难度值（原版五位数） | 一 |
| J | 即时胜利 | 一 |
| 数字键盘 `*` 或 `*` | 直达主线结局的战绩卡 | 一 |
| M | 音乐盒 | 一 |
| F1／F2／F5／F6／1 | 第二批；第一批只在信息栏提示尚未复刻 | 二 |

- 浏览器无法可靠侦测“按住” Caps Lock（macOS 只在切换时发出事件），所以复刻以“开启状态”代替“按住”。
- 选格、转职等子状态不接受调试热键。这比原版收紧，避免调试操作打断一个半提交的动作。
- Caps Lock 开启时，上表按键不再执行其平常的含义：S、D 不移动光标，M 不打开音量面板。方向键与 W／A 照常移动。

## 有序规则

1. 校验：开关开启，热键条件成立；需要目标的功能要求光标格有单位，空格只在信息栏提示，不沿用上一个单位。
2. 结算（全部不消耗战斗 PRNG）：

   | 功能 | 结算 |
   | --- | --- |
   | 全滿 | 该方每个单位生命 = 当前生命上限 |
   | 全滅 | 该方全部单位从棋盘移除；不播死亡表现，不触发击杀替补或形态转换，与原版只清棋盘一致 |
   | 1 | 该方每个单位生命 = 1 |
   | 经验 +50 | 累计经验加 50；生命若高于新上限则压到上限 |
   | 经验 −50 | 只在结果大于 0 时写入；生命压到新上限 |
   | 生命 −10 | 只在生命大于 10 时扣 10（`[SR]`：原版在生命恰为 10 时会留下 0 生命单位） |
   | 全员再行动 | 只清我方已行动状态，不解除冰封 |
   | 即时胜利 | 本场战斗结果强制为胜利 |
   | 直达结局 | 以本关进场时的战役名册与战绩建立主线结局，从战绩卡开始 |

3. 后续消费者：
   - 生命与移除变化后立即做一次胜负判定；经验变化后跑一次转职扫描（原版待机循环每一轮都会扫描）；
   - 即时胜利走本关正常的胜利事件、胜利回馈与存档询问；
   - 直达结局之后走战绩卡 → 结局 → 隐藏关；
   - 台词与读数只是表现，不进模拟。

## 状态变化与边界

| 情况 | 结果 | UI 反馈 |
| --- | --- | --- |
| 正常 | 按上表结算 | 信息栏说明本次调试操作 |
| 空格 | 不做任何事 | 信息栏「游標下沒有單位。」 |
| 全滅后胜负成立 | 直接进入正常胜利／失败流程 | 原有流程 |
| 即时胜利 | 不检查任何目标条件 | 原有胜利流程 |
| 保存／读取 | 开关与读数不入存档；调试改动过的单位状态与普通状态一样保存 | 无额外标记 |

## 音乐盒

- 入口：「音樂開關」面板的「音樂盒」按钮（常驻），以及除错模式下的 Caps Lock+M。
- 名单：
  - 原版 31 首按原顺序列出，每项显示原版格式「`MUSIC-   NN-名稱.RIX`」与复刻撰写的用途说明；
  - 「原版未收錄」列出：
    - `TALK.RIX`：原版表内第 32 项，序号回绕后选不到；
    - 第 37 关敌方阶段专属曲；
    - 结局战绩卡曲、衰亡结局曲与制作人员表曲。
- 播放：
  - 原版单曲名单中的记录单曲循环；
  - 其余战场记录按“奇数入场 → 偶数循环”曲对播放；
  - 关闭音乐盒后所选曲继续，直到游戏下一次自己选曲（换阶段、剧情或换关）；
  - 「恢復原曲」立即交回游戏自己的选曲。
- 键盘：上下选择，Enter／Space 播放，Esc／Backspace 返回。

## AI 使用

AI 不使用调试功能。调试操作只改变棋盘状态，之后 AI 照常从公开棋盘规划。

## 表现与可访问性

- 第 37 关：
  - 非调试状态下，side 2 的单位详情数值以 `?????` 隐藏（原有），地图生命数字也不画（本次补上）；
  - 调试状态下两者都显示。

- 开关、音乐盒和信息栏提示都是复刻自撰内容，使用现代字体；调试选单的原文使用原版点阵字。

## 验收场景

1. Given 开关关闭，When 按 Caps Lock+J，Then 没有任何调试效果。S 键照常移动光标。
2. Given 开关开启、Caps Lock 开启、我方待机，When 按 F3 并选「敵全滅」，Then 敌方全部从棋盘移除，
   「全滅敵軍」类关卡进入正常胜利流程。
3. Given 光标在生命 10 的单位上，When 按数字键盘 `-`，Then 生命仍为 10。生命 25 时变为 15。
4. Given 光标在经验差 30 到达转职门槛的我方单位上，When 按 U，Then 经验 +50，并立即出现转职选择。
5. Given 任意关卡，When 按 J，Then 进入该关正常胜利流程。
6. Given 「音樂開關」面板，When 选第 26 首并播放，Then 播放 `T04.RIX`；关闭面板后音乐继续；
   进入敌方阶段时换回敌方曲。
7. Given 第 37 关、开关关闭，Then side 2 的单位详情显示 `?????`，地图上没有 side 2 生命数字；
   开关开启后两者都显示。
8. 保存／读取：开关不改变存档格式；同一操作序列在开关前后得到相同的战斗 PRNG 状态。
