## 玩家目的

原版《天使帝國 II》带有一套玩家社区熟知的调试模式，包括：

- 即时胜利与直达结局；
- 双方全体生命设定；
- 经验与生命微调、全员再行动；
- 台词预览与格号读数；
- 第 37 关首领数值显形；
- 音乐盒，其中可以听到正常流程听不到的 `T04.RIX`。

复刻版把它作为可选的玩家功能提供：想重温、测试或练习的玩家可以开启；不开启的玩家完全看不到它的影响。

## 触发与输入

- 开关：宿主工具列「原版Debug」，`aria-pressed` 反映状态，按浏览器保存。关闭立即生效；进行中的音乐盒覆盖曲不受影响。
- 调试热键：开关开启、Caps Lock **处于开启状态**、我方阶段、没有对白或表现进行中，并且战场处于下列状态之一时，以下按键生效：
  - 待机光标；查看敌方或友军自动单位范围的预览也算待机，先收起预览再执行；
  - 移动、攻击、射击、传送、技术、建造的选格，包括技术测试自己的选格；
  - 转职的职业选择（授职对白中不收）。

  指令、技术、集体、系统等选单，魔弓箭道切换，冰雪施放确认，除错画面与放回单位等待中都不接受。
  原版的通用选单只在指针停在拖曳把手上时接收，复刻不做。

- 浏览器无法可靠侦测“按住” Caps Lock（macOS 只在切换时发出事件），所以复刻以“开启状态”代替“按住”。
- 选格与转职选择中：
  - 数字键盘 `-`、J、`*` 只在信息栏提示“这个热键只在我方待机时有效”（原版这三个键只在待机循环检查）；
  - 转职选择中，以及技术测试自己的选格中，F5／F6 只提示，不做技术测试。
- Caps Lock 开启时，上表按键不再执行其平常的含义：S、D 不移动光标，M 不打开音量面板。选格与转职选择中同样如此。
  方向键与 W／A 照常移动。
- 热键不生效的状态（开着选单、除错画面或授职对白）里，字母与数字键照常走平常的意思；F1–F6、F10 只在信息栏提示
  “热键在我方待机、选格与转职选择时有效”，不落回 F1–F4 的集体命令（全军休息、跟随、自由行动、撤退），也不让 F5
  触发浏览器重新整理。按住不放的自动重复同样不落回。提示会暂时盖过选中单位的摘要。
- 开关开着时，「原版Debug」按钮外缘显示游戏实际读到的 Caps Lock 状态（亮绿为开）；不另放标签，避免工具列
  一行放不下时按钮折成两行，操作说明放在鼠标悬停提示里。macOS 的拼音等中文输入法默认
  短按 Caps Lock 只切换中英文、不开启 Caps Lock，这时外缘不亮、热键不生效；长按到键盘指示灯亮起，或先切换到 ABC
  输入法即可。

## 有序规则

1. 校验：开关开启，热键条件成立；需要目标的功能要求光标格有单位，空格只在信息栏提示，不沿用上一个单位。
2. 第一批结算（全部不消耗战斗 PRNG）：

   | 功能 | 结算 |
   | --- | --- |
   | 全滿 | 该方每个单位生命 = 当前生命上限 |
   | 全滅 | 该方全部单位从棋盘移除；不播死亡表现，不触发击杀替补或形态转换，与原版只清棋盘一致 |
   | 1 | 该方每个单位生命 = 1 |
   | 经验 +50 | 累计经验加 50；生命若高于新上限则压到上限 |
   | 经验 −50 | 只在结果大于 0 时写入；生命压到新上限 |
   | 生命 −10 | 只在生命大于 10 时扣 10（`[SR]`：原版在生命恰为 10 时会留下 0 生命单位） |
   | 全员再行动 | 只清我方已行动状态，不解除冰封 |
   | 即时胜利 | 本场战斗结果强制为胜利 |
   | 直达结局 | 以本关进场时的战役名册与战绩建立主线结局，从战绩卡开始 |

3. 后续消费者：
   - 生命与移除变化后立即做一次胜负判定；经验变化后跑一次转职扫描（原版待机循环每一轮都会扫描）。
     选格与转职选择中的时机见下文；
   - 即时胜利走本关正常的胜利事件、胜利回馈与存档询问；
   - 直达结局之后走战绩卡 → 结局 → 隐藏关；
   - 台词与读数只是表现，不进模拟。

### 选格与转职选择中

1. 选格中（原版七个选格循环共用的步进 `54BC`）：
   - 调试操作与待机时相同，作用于游标下的单位；操作完成或除错画面关闭后回到同一个选格；
   - `[SR]` 范围与目标按当前状态重算。原版沿用进入选格时的旧范围图，已移除的敌人格上仍有攻击标记；
   - 胜负照常立即判定；
   - `[SR]` 转职扫描延到这次行动结束，或一路取消退回待机时再做（原版只在待机循环扫描）；
   - `[SR]` 行动做不成时的退出：

     | 情况 | 结果 |
     | --- | --- |
     | 行动者离场 | 取消这次行动，回到待机 |
     | 行动者不能再由玩家指挥（改成自动行为、被冰封、已行动）或被推离原格 | 还没移动：取消，回到待机；已经移动：落点保留，照「結束」收尾 |
     | 职业不再有这项行动（含被禁咒的技术），或范围内已没有合法目标 | 回到行动选单 |
     | 技术测试自己的选格：施法者离场或没有目标 | 结束技术测试 |

   - F5／F6：先记住原来的选格；技术测试施放完毕、取消或没有目标时回到它，游标回到按键时的位置，再照上表检查。
     技术测试的转职扫描与自动阶段都留给原来的选格收尾。
2. 转职选择中（原版 `0744` 循环）：
   - 除错选单与画面叠在转职选单上，按键先给它们；台词预览期间不能选择职业；
   - 复刻在转职时把游标移到转职单位上，转职选择中不能移动游标，所以经验、台词、行为等调试都作用于它；
   - `[SR]` 每次调试操作后按当前状态重整转职队列：
     - 已离场或不再符合条件的单位移出，新符合条件的排到最后；
     - 正在选的单位被移出时换下一位，重新开始授职对白；
     - 队列空了就结束转职等待，战斗照常继续；
   - 胜负判定延到转职全部结束后，与一般行动结束时的顺序相同。
3. `[DD]` 复刻的取舍（用户 2026-10-03 确认）：
   - 选格与转职选择中仍要求 Caps Lock 开着（原版不必）：那里的 S、D 会移动游标；
   - 转职选择中不做技术测试：技术测试要在战场选格，转职选择挡着战场；
   - EDIT 放置单位只从待机开始（原版下一次待机点格才放上场）；选格与转职选择中点可以放置的单位只提示；
   - 技术测试的选格中不能再开一次技术测试（原版可以递回）。

## AI 使用

AI 不使用调试功能。调试操作只改变棋盘状态，之后 AI 照常从公开棋盘规划。F1／EDIT 的行为覆写是 AI 的输入：
敌方与自动友军按覆写值规划（1 为原地，其余照各自规则），我方单位的覆写还决定它是否进入自动阶段。
兵種／地型的覆写同样是 AI 的输入：AI 读的属性、移动范围与地形防御都是改过的值，规划快取以覆写版本区分。
