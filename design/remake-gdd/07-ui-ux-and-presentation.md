# UI、交互与表现方向

## 视觉基线

- `[OF]` 原版战斗输出为 `640×350`；主战场占左侧，右侧为肖像、HP/EXP 竖条、属性和状态，底部显示地点与回合。
- `[OF]` 战场视口为 `10×7` 个 `40×44` 图块；逻辑地图为 `50×50`，小地图用于定位全图和当前视口。
- `[DD]` 默认主题复现原版构图、边框、字体、肖像、色彩和像素比例；所有位图使用已修正位平面顺序与原生调色板。
- `[DD]` 像素素材默认使用最近邻缩放，不做平滑、重绘或自动色彩增强。

## 浏览器画面策略

- `[DD]` 以原版 `640:350` 逻辑画布为构图基准，保持宽高比并使用留边适配窗口。
- `[DD]` 优先提供整数倍缩放；窗口不足时允许等比非整数缩小，但仍保持像素清晰选项。
- `[DD]` 游戏规则不依赖 CSS 尺寸、设备像素比、帧率或浏览器缩放。
- `[DD]` 宽屏额外空间默认只用于留边；可选资料面板不得挤压或遮挡 `10×7` 主战场。

## 主要 UI 表面

| 表面 | 原版身份 | 复刻版必须增加/澄清 |
| --- | --- | --- |
| Logo / 开场 / 标题 | 原版素材、音乐、双标题、两项主菜单 | 规则集/Mod 入口不破坏主菜单层级 |
| 难度选择 | 四个原版名称 | 显示已确认的规则影响 |
| 五槽继续 | 原版五项元数据与槽导航 | 显示规则集、Mod、兼容状态 |
| 剧情 | 上下窗、肖像、名字、背景、逐字节奏 | 文本速度、已看快进、字幕可读性 |
| 部署 | 名单、固定单位、部署格、底部错误条 | 固定/可选状态、上限、目标常驻入口 |
| 战场 | `10×7` 地图、右 HUD、小地图、底栏、菜单 | 清晰的选择/预览/提交状态与无效原因 |
| 目标 | 原版目标文字 | 与机器条件一致的准确说明和触发反馈 |
| 胜负/退出 | 原版窗口与确认流程 | 明确触发原因、下一步与规则影响 |
| 战后保存 | 五槽选择与保存次数 | 规则身份、覆盖确认、错误恢复 |

## 战场信息层级

### 常驻

- 当前聚焦单位肖像、姓名、职业；
- 当前/最大生命、攻击、防御、等级、经验；
- HP/EXP 视觉条、状态图标、当前回合；
- 当前关卡地点；
- 敌我阵营与已行动状态。

### 选择动作后

- 移动/攻击/射击/技术的合法范围；
- 当前目标和行动会否提交；
- 地形与必要的免疫/无效说明；
- 取消会返回哪一层。

### 按需详情

- 完整状态说明、地形规则、职业行动、转职图；
- 胜利/失败条件；
- 可选伤害区间或公式说明；
- 当前规则集与 Mod 来源。

## 输入原则

- `[OF]` 原版支持语义化的主操作、副操作、方向、菜单与系统动作，并通过 Joymouse 配置连接键盘/鼠标。
- `[DD]` 复刻版以语义动作而非物理按键定义交互，使键盘、鼠标和手柄共享相同规则。
- `[DD]` 主操作负责选择/确认，副操作负责取消/返回；已提交的模拟动作不能被普通副操作撤销。
- `[DD]` 所有关键流程可仅用键盘完成，也可仅用鼠标完成；手柄支持不改变菜单拓扑。
- `[DD]` 输入重映射是设备偏好，不进入规则集。

## 表现与规则同步

- `[DD]` 模拟先产生规范化结果，表现按事件播放；表现完成不是决定伤害的时钟来源。
- `[DD]` 原版地图/全屏攻击、射击、技术、死亡和逐关脚本的顺序按专项证据复现。
- `[DD]` 动画速度只缩放等待，跳过会抵达相同最终状态；关键选择和未读剧情默认不自动跳过。
- `[DD]` UI 在动画中可锁定冲突输入，但锁定不能改变 AI 或随机流。

## 可访问性与原貌的分层

- `[DD]` 色觉辅助使用轮廓、图案或标签补充阵营色，不重染原始素材作为唯一方案。
- `[DD]` 减少闪烁、降低屏幕震动、字幕背景和音量独立控制默认可用。
- `[DD]` 原版字体模式与高可读字体/放大文本可切换；文本内容和分页事件必须保持一致。
- `[H]` 战场 UI 的最小可读尺寸需在笔记本与高 DPI 屏幕上实测后确定。

## UI 验收

- 在标准 `640×350` 基准截图上，主战场、右 HUD、小地图和底栏区域与原版构图对应；
- 调色板、肖像和战场图块与已验证渲染无系统性色偏；
- 200%、300% 整数缩放不出现插值模糊；
- 键盘与鼠标能完成标题 → 第 0 关 → 胜利 → 保存的同一流程；
- 关闭战斗动画或提高速度不会改变任何战斗状态；
- 只依靠颜色之外的视觉线索也能区分阵营、范围和已行动状态。
