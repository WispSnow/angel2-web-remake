# UI、交互与表现方向

## 视觉基线

- `[OF]` 原版战斗输出为 `640×350`；主战场占左侧，右侧为肖像、HP/EXP 竖条、属性和状态，底部显示地点与回合。
- `[OF]` 战场视口为 `10×7` 个 `40×44` 图块；逻辑地图为 `50×50`，小地图用于定位全图和当前视口。
- `[OF]` 战场焦点不在单位上时，右栏显示 `A/0006/19` 战术桌与实时小地图；焦点进入单位格后，单位详情叠加在同一右栏上，小地图变暗且隐藏当前视口与双方单位标记，而不是在画布外常驻另一块战术面板。
- `[OF]` `A/0000` 的八个原生组件组成完整左侧战场框：`00` 为 `480×23` 顶栏，`01/02` 为左右角饰，`03` 是两侧共用的 `40×80` 彩色玻璃，`04/05` 是左右雕像，`06/07` 是底座；组合后中央开口精确对应 `(40,23)`、`400×308` 战场视口。
- `[OF]` 地图棋子下方常驻显示当前生命数字，数字以白色像素字配合敌我红/蓝底色；行动完毕的单位不依赖变灰表达，而是在棋子左下侧显示原版灰底红字 `E` 标识。该标识为 `16×14` 像素，相对棋子逻辑底部中心的左上偏移为 `(-22,-15)`；三位数生命标签会与其右边缘轻微重叠。
- `[OF]` 每条原版 `D/<角色>` 肖像记录不是单张静态图：frame 0 为 `112×112` 主肖像，frame 1–3 是“睁眼／半闭／闭眼”覆盖片，frame 4–6 是口型覆盖片；肖像元数据的四个布局字节依次给出眼部与口部覆盖片在主肖像内的 X/Y 原点。
- `[OF]` 原版剧情肖像和战斗右栏肖像都会间歇眨眼。眨眼等待受原生 PIT 计时值影响，眼部按“睁眼 → 半闭 → 闭眼 → 半闭 → 睁眼”覆盖，不替换或缩放整张肖像。
- `[OF]` 单位职业行动使用原版通用菜单的紧凑三行布局、金色多层边框、深褐点阵底与蓝/红顶角饰；菜单在战场内靠近所选单位放置并避开右侧详情栏。键盘上下循环选择，主操作确认，次操作返回上一层。
- `[DD]` 敌军移动范围预览使用半透明红色格与浅红轮廓，和我方移动的蓝色范围、攻击目标的高亮红框保持可辨；预览期间继续显示该敌军详情，但不出现职业行动菜单。
- `[DD]` 默认主题复现原版构图、边框、字体、肖像、色彩和像素比例；所有位图使用已修正位平面顺序与原生调色板。
- `[DD]` 像素素材默认使用最近邻缩放，不做平滑、重绘或自动色彩增强。

## 浏览器画面策略

- `[DD]` 以原版 `640:350` 逻辑画布为构图基准，保持宽高比并使用留边适配窗口。
- `[DD]` 优先提供整数倍缩放；窗口不足时允许等比非整数缩小，但仍保持像素清晰选项。
- `[DD]` 游戏规则不依赖 CSS 尺寸、设备像素比、帧率或浏览器缩放。
- `[DD]` 宽屏额外空间默认只用于留边；可选资料面板不得挤压或遮挡 `10×7` 主战场。
- `[DD]` 正常战斗默认不显示独立的画布外辅助区块；额外规则、键位与 Mod 资料只能从按需系统/暂停表面打开。

## 主要 UI 表面

| 表面 | 原版身份 | 复刻版必须增加/澄清 |
| --- | --- | --- |
| Logo / 开场 / 标题 | 原版素材、音乐、双标题、两项主菜单 | 规则集/Mod 入口不破坏主菜单层级 |
| 难度选择 | 四个原版名称 | 显示已确认的规则影响 |
| 五槽继续 | 原版五项元数据与槽导航 | 显示规则集、Mod、兼容状态 |
| 剧情 | 上下窗、肖像、名字、背景、逐字节奏 | 文本速度、已看快进、字幕可读性 |
| 部署 | 名单、固定单位、部署格、底部错误条 | 固定/可选状态、上限、目标常驻入口 |
| 战场 | `10×7` 地图、右 HUD、小地图、底栏、菜单 | 清晰的选择/预览/提交状态与无效原因 |
| 目标 | 原版目标文字 | 与机器条件一致的准确说明和触发反馈 |
| 胜负/退出 | 原版窗口与确认流程 | 明确触发原因、下一步与规则影响 |
| 战后保存 | 五槽选择与保存次数 | 规则身份、覆盖确认、错误恢复 |

## 战场信息层级

### 常驻

- 无单位焦点时显示原版战术桌、实时小地图、当前视口与单位标记；
- 有单位焦点时在变暗且无棋子标记的小地图上叠加其肖像、姓名、职业、当前/最大生命、攻击、防御、等级、经验、HP/EXP 视觉条与状态图标；
- 当前回合；
- 当前关卡地点；
- 敌我阵营、棋子当前生命数字与 `E` 已行动状态；
- “胜利条件”“回合终了”与表现/声音设置不作为右栏底部常驻按钮，只在玩家明确呼出的系统菜单中出现。

### 选择动作后

- 移动/攻击/射击/技术的合法范围；
- 当前目标和行动会否提交；
- 地形与必要的免疫/无效说明；
- 取消会返回哪一层。

### 按需详情

- 完整状态说明、地形规则、职业行动、转职图；
- 胜利/失败条件；
- 可选伤害区间或公式说明；
- 当前规则集与 Mod 来源。

## 输入原则

- `[OF]` 原版支持语义化的主操作、副操作、方向、菜单与系统动作，并通过 Joymouse 配置连接键盘/鼠标。
- `[DD]` 复刻版以语义动作而非物理按键定义交互，使键盘、鼠标和手柄共享相同规则。
- `[DD]` 主操作负责选择/确认，副操作负责取消/返回；已提交的模拟动作不能被普通副操作撤销。
- `[DD]` 所有关键流程可仅用键盘完成，也可仅用鼠标完成；手柄支持不改变菜单拓扑。
- `[DD]` 输入重映射是设备偏好，不进入规则集。
- `[DD]` 物理设备切换只能改变焦点来源；不得因鼠标移入、手柄唤醒或键盘导航本身提交模拟动作。
- `[OF]` 战场鼠标内区为 X=`40..432`、Y=`26..325`；指针进入上 `<26`、下 `>=326`、左 `<40`、右 `>=433` 的战场框边缘区时，视口按对应方向逐格滚动并夹取到地图边界。
- `[DD]` 复刻版默认启用边缘驻留滚屏：进入边缘立即滚动一格，继续停留则按固定节拍重复，移回内区、右栏或画布外立即停止。该操作只改变视口原点，不移动逻辑光标、不改变选中或行动状态；方向键导航与手柄导航继续保留。

## 关卡标题、目标与现代提示

- `[OF]` 原版战场地点名位于底栏，胜利条件可从右栏热点或系统菜单按需打开。
- `[DD]` 默认不在每关开战前新增阻断式标题/目标卡；关卡若有原生专用过场，则按其剧情规格处理。
- `[DD]` 新手提示必须非阻断、不夺焦点、不覆盖普通战场合法目标，并能按规则集或用户偏好关闭。
- `[DD]` AI 内部目标格、行为编号和搜索预算不因“意图辅助”自动公开；每关规格只定义玩家应知道的高层意图。

## 表现与规则同步

- `[DD]` 模拟先产生规范化结果，表现按事件播放；表现完成不是决定伤害的时钟来源。
- `[DD]` Web 眨眼间隔使用独立的表现随机源，不读取或推进战斗 PRNG；切换焦点、镜头滚动或 DOM 重绘不得重置正在进行的眨眼周期。眨眼是局部、低幅度的角色生命感表现，即使启用系统“减少动态效果”也继续播放；该设置只压缩或停用大幅位移、闪烁与震动。
- `[DD]` 原版地图/全屏攻击、射击、技术、死亡和逐关脚本的顺序按专项证据复现。
- `[DD]` 动画速度只缩放等待，跳过会抵达相同最终状态；关键选择和未读剧情默认不自动跳过。
- `[DD]` UI 在动画中可锁定冲突输入，但锁定不能改变 AI 或随机流。

## 可访问性与原貌的分层

- `[DD]` 色觉辅助使用轮廓、图案或标签补充阵营色，不重染原始素材作为唯一方案。
- `[DD]` 减少闪烁、降低屏幕震动、字幕背景和音量独立控制默认可用。
- `[DD]` 原版字体模式与高可读字体/放大文本可切换；文本内容和分页事件必须保持一致。
- `[H]` 战场 UI 的最小可读尺寸需在笔记本与高 DPI 屏幕上实测后确定。

## UI 验收

- 在标准 `640×350` 基准截图上，主战场、右 HUD、小地图和底栏区域与原版构图对应；
- 空地焦点显示明亮小地图、视口框和单位标记；悬浮或激活单位时显示详情覆盖层，小地图变暗且不再绘制视口框和单位标记；
- 肖像右侧同时存在 HP 与 EXP 两条独立竖条，填充高度分别来自当前生命/最大生命与当前经验/下一阈值；
- 正常战斗右栏不常驻功能按钮；系统入口呼出独立菜单，关闭后恢复原先焦点与右栏状态；
- 顶栏、彩色玻璃、左右雕像和底座使用 `A/0000` 原生像素，不以 CSS 渐变或通用边框近似；
- 每个地图棋子下方显示与模拟同步的当前生命；已行动单位显示 `E` 标识，未行动单位不显示，且不以降低棋子透明度替代；
- 剧情与战斗右栏肖像均使用对应角色自己的三张原生眼部覆盖片，并按元数据原点无缝叠加；一次眨眼完整经过半闭、闭眼、半闭后回到睁眼；
- 调色板、肖像和战场图块与已验证渲染无系统性色偏；
- 200%、300% 整数缩放不出现插值模糊；
- 键盘与鼠标能完成标题 → 第 0 关 → 胜利 → 保存的同一流程；
- 鼠标停在战场四边可连续逐格滚动，离开边缘立即停止；滚屏期间逻辑光标、单位坐标、选择与行动态均保持不变；
- 关闭战斗动画或提高速度不会改变任何战斗状态；
- 只依靠颜色之外的视觉线索也能区分阵营、范围和已行动状态。
