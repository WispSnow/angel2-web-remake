## 目标

从第 0 关完成战役状态真实进入“騎士城堡前”，完成关前剧情、交互部署、玩家与敌方
技术、首领胜利、传令兵事件、v7 存档与 `stage-02` 未实现边界，同时保持第 0 关规则、
截图、旧存档迁移和普通入口通关零回归。

2. 建立与 DOM/Phaser 无关的部署纯模拟和三输入投影；
3. 从逆向机器产物生成第 1 关地图、阵容、目标、剧情、音乐和事件内容；
4. 复用 `fire-1/heal-1`，新增 `lightning-1/ice-1` 与敌方修女调度；
5. 建立 v7、v2–v6 确定性迁移、严格拒绝矩阵和第 1 关战中恢复；
6. 开放第 0 关到第 1 关的普通路由，并在 `stage-02` 未实现边界终止；
7. 增加内容、模拟、浏览器、真实流程和代表性视觉验收。

## 实施顺序

### P1：关卡与事件边界

- 扩展关卡目标、部署、剧情、音乐、事件和内容身份的稳定接口；
- 让第 0 关先消费扩展接口并建立零差异测试；
- 禁止在控制器中加入第 1 关正文、坐标或槽号条件分支。

### P2：部署纯模拟

- 建立 `simulation/deployment/`；
- 覆盖固定/可选/空位、5–8 人完成、三条原文错误、焦点和 PRNG 不变；
- 模拟通过后再接 DOM 名单与 Phaser 地图投影。

### P3：第 1 关生成内容

- 生成地图、地形、阵容、目标、剧情、事件、音乐和表现引用；
- 保存源记录、哈希、稳定 ID、内容身份和资源存在性；
- 浏览器运行时不得读取 `reverse/`。

### P4：技术扩展

- 复用 M00.6 的动作准备/表现/原子提交边界；
- 新增 `lightning-1/ice-1` 和敌方修女 `fire-1/heal-1` 调度；
- 应用 `REMAKE-009`：敌方修女与玩家共用 action definition，`fire-1/heal-1` 范围均为
  `5`，不读取原版 AI `fire-1=4` 的专属参数；
- 正常/加速、地图/全景和静音必须得到同一模拟结果与 PRNG 后态。

### P5：v7 与战役路由

- 先写迁移/拒绝矩阵，再开放第 1 关记录入口；
- 战中单位是已提交部署结果的唯一真值；
- `999` 不可记录，`1000` 写为 `campaign-route/stage-02`。

### P6：完整验收

- 按 `S01-A–K` 完成单元、内容、Playwright、普通入口和人工视觉门禁；
- 运行 `pnpm check`、`node reverse/tools/angel2-phase1-verify.mjs` 和 `git diff --check`；
- 人工查看部署、落雷、冰雪、敌方施法、首领胜利和窄屏截图。

## 体积与加载基线

授权时生产构建的 `game` chunk 为约 `1491.66 kB`（gzip `389.69 kB`），已经触发
`1400 kB` 警告。第 1 关生成内容和专用表现必须成为按关加载边界；每次注册新内容时
记录构建前后体积，不能把全部后续关卡静态导入首屏。该预算不允许通过单纯抬高警告阈值
“解决”。

首批关卡/事件边界与部署纯模拟完成后的构建为 `1493.96 kB`（gzip `390.28 kB`），
相对授权基线增加约 `2.30 kB`（gzip `0.59 kB`）；尚未加入第 1 关正文与素材。

P1 收尾及 P3 证据生成模块完成后的主 `game` chunk 为 `1497.96 kB`（gzip
`391.36 kB`）。第 1 关生成 TS、地图、肖像和约 25 MB 音频源没有静态导入主入口；
可玩路由接入时必须通过动态 `import()` 保持这一边界。

P2 投影完成后新增独立多页入口 `deployment-lab`：其 JS 为 `27.86 kB`（gzip
`9.10 kB`），CSS 为 `5.69 kB`（gzip `1.90 kB`）。生产构建继续把该入口与第 1 关
生成内容隔离于普通 `index.html`；原版地图、肖像和音频仍只作为 URL 资源按需请求。

P4–P5、调试入口与统一肖像目录收尾后，普通入口的 `game` chunk 为 `137.11 kB`（gzip `37.88 kB`）；
全战役肖像索引位于共享 `portrait-catalog.generated` chunk（`35.97 kB`，gzip `3.33 kB`），第 1 关
生成内容与动作表现位于独立 `stage1` chunk（`36.75 kB`，gzip `9.04 kB`），战斗工厂
位于独立 `stage1-battle` chunk（`1.88 kB`，gzip `0.96 kB`），部署会话、DOM、Phaser
场景和 CSS 也保持独立。调试注册表与运行时分别是独立 chunk；普通 `index.html` 不预载
调试或第 1 关模块，浏览器门禁也确认第 0 关启动期间不会请求它们。
