# M00：第 0 关人工接受

状态：`verified`

更新日期：2026-07-25

## 目标

让第 0 关“瓦爾克麗宮”从自动验证完成推进到用户接受，形成后续系统扩展可以信赖的体验基线。

## 输入

- 玩家合同：[`design/remake-gdd/vertical-slices/stage-00.md`](../../design/remake-gdd/vertical-slices/stage-00.md)；
- UI 状态：[`design/remake-gdd/ui/stage-00-ui-flow.md`](../../design/remake-gdd/ui/stage-00-ui-flow.md)；
- 设计门槛：[`design/remake-gdd/09-design-acceptance.md`](../../design/remake-gdd/09-design-acceptance.md)；
- 运行和操作说明：[`README.md`](../../README.md)。

## 范围

- 从普通 `/` 经开场、标题和难度选择进入战斗；
- 用玩家可见输入完成移动、攻击、休息、目标查看、系统菜单和镜头操作；
- 体验剧情节奏、音画反馈、失败重试、战中存读档、胜利保存和下一关占位；
- 检查桌面和至少一种窄屏布局；
- 登记阻塞接受的缺陷和非阻塞改进。

## 不在范围

- 第 1 关、部署、技术、射击、状态或转职实现；
- 为了方便后续开发而进行无玩家收益的大规模重构；
- 将主观偏好直接写成原版事实或默认规则。

## 已完成的技术门槛

- 单元测试、覆盖率门槛、类型检查和生产构建通过；
- 固定版本 Chromium 的完整端到端流程通过；
- 普通入口真实通关场景不依赖测试查询参数或调试 API；
- 动态肖像、终局截图和菜单输入已具有稳定回归保护；
- 存档读取验证完整 schema 和关键语义边界；
- 逆向证据基线校验通过。

## 手动试玩清单

- [ ] 开场、标题、难度选择和第一段剧情节奏可接受；
- [ ] 鼠标与键盘的选择、确认、取消和菜单焦点符合直觉；
- [ ] 战场镜头、小地图、单位详情和合法范围容易理解；
- [ ] 普通攻击、AI、剧情事件和胜负反馈清楚；
- [ ] 音乐、音效、逐字音和表现速度切换符合预期；
- [ ] 战中保存、读取、覆盖确认与坏档反馈可理解；
- [ ] 失败重试、胜利保存和下一关占位没有死路；
- [ ] 桌面与窄屏没有阻塞操作的问题。

## 问题分类

试玩发现的问题按以下三类处理：

1. **阻塞接受**：死路、错误规则、存档损坏、关键输入不可用、严重视觉或音频缺失；
2. **后续改进**：不改变合同也不阻塞通关的手感、提示和性能优化；
3. **非目标**：被冻结系统、尚未授权的玩法变化或与原版证据冲突的偏好。

每个阻塞项必须链接复现步骤、相关合同和回归测试。后续改进可登记到未来里程碑，但不能静默扩大 M00。

## 退出条件

- 手动试玩清单完成；
- 阻塞接受的问题全部关闭，或由用户明确带已知问题接受；
- 相关自动检查保持通过；
- [`design/remake-gdd/09-design-acceptance.md`](../../design/remake-gdd/09-design-acceptance.md) 的第 0 关人工试玩项同步更新；
- 本里程碑状态改为 `accepted`。

## 下一动作

用户从普通入口完成一次手动试玩，并将观察到的问题或接受结论反馈到本里程碑。
