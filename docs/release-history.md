# 发布记录

本文件记录面向玩家的发行版本。Windows 安装包版本由
`pnpm release:version [x.y.z]` 统一更新；未指定版本时默认递增次版本。

## 0.3.0 — 2026-09-02

- 包含截至源码基线 `7150323` 的全部已验收内容，并同步第 13–24、26–37 关的最新技能规则证据身份。
- 修正弓兵／弩兵与魔弓箭士的射击经验，恢复水战士原版移动模式并补齐共享本体击杀奖励。
- 调整跟随主将的护卫半径与第 9 关护卫路线，允许敌方施放的魔法守护延续至下一玩家阶段。
- Windows 产物仍为未签名的 x64 NSIS 当前用户安装包，并配套发布 SHA-256 校验文件。

## 0.2.0 — 2026-09-01

- 首次启用明确的安装包版本递增规则，替代长期固定使用 `0.1.0` 的做法。
- 包含截至源码基线 `92f1f74` 的全部已验收内容，以及第 36 关证据身份重新生成修复。
- Windows 产物为未签名的 x64 NSIS 当前用户安装包，继续配套发布 SHA-256 校验文件。
