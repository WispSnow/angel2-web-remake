# 发布记录

本文件记录面向玩家的发行版本。Windows 安装包版本由
`pnpm release:version [x.y.z]` 统一更新；未指定版本时默认递增次版本。

## 0.6.0 — 2026-09-15

- 包含截至源码基线 `c19cede` 的全部内容；存档身份升级至 v115／`guard-magic-archer-kins-entry-1`，v109 起逐级无损迁移。
- 水戰士的射击改读弓兵的射击地形表：崖壁、深水与天空不再挡住射击，第 23 关死亡之谷里隔着崖壁的崖顶弩兵、停在崖壁格上的飛龍騎士都能射中。
- 守卫或被围得无处可退的魔弓兵按原版原地射击：第 23 关第一层两名守卫魔弓兵被我方贴身后不再只休息或待命。
- 琴斯按原版带着 299 经验入队（第 20／22 关剧情棋子与第 23 关起各关名单）；读档时低于 299 的魔祭師琴斯补到 299，已损生命按原量保留。
- 本次计划同时更新 Cloudflare Pages 网页版与 Windows NSIS 安装包；产物仍为未签名的 x64 当前用户安装包，配套发布 SHA-256 校验文件。

## 0.5.0 — 2026-09-10

- 包含截至源码基线 `26d5dc9` 的全部已验收内容；存档身份升级至 v113／`enemy-phase-action-bits-1`，v109 起逐级无损迁移。
- 敌方阶段入口按原版 `1000:14A6` 先清 side 2 行动位再跑敌方 AI：第 20 关带着已行動徽章登场的妖龍不再整个第 1 个敌方阶段不动。
- 战场场景按「在场单位 ∪ 剧情增援 ∪ 形态转换」预载我方棋子图：第 21 关四名斥候不再画成缺图方块；顺带补上场景 42 維絲塔（女帝）从未进过资源包的棋子图。
- 第 22 关的地图动作图集补上 `WD`，特殊行动失败时一并清演出状态并报出原因：妖龍念完「看我的雷電魔法」不再卡死整个敌方阶段。
- 本次同时更新 Cloudflare Pages 网页版与 Windows NSIS 安装包；产物仍为未签名的 x64 当前用户安装包，配套发布 SHA-256 校验文件。

## 0.4.0 — 2026-09-04

- 包含截至源码基线 `e1cd021` 的全部已验收内容；存档身份升级至 v112／`boss-poison-and-life-band-1`，v109 起逐级无损迁移。
- 修正龍系首領的中毒方向：每回合的三分之一是扣除量而非剩余量；剧情首領的難度状态修正改为与其余敌方共用同一条顺序。
- 剧情首領低于四成生命继续行动、低于两成才休息；守衛打不到人、法師被禁咒、追擊被堵死或混亂动不了时，未满血单位改为原地休息。
- 多格共用本体的水戰士在范围效果下只扣一次生命池，只有清空生命池的那一格计为击杀；第 20 关的全面徹退与战败重试回到部署面。
- 本次仅更新 Cloudflare Pages 网页版；0.4.0 的 Windows NSIS 安装包尚未构建，玩家侧仍为 0.3.0。

## 0.3.0 — 2026-09-02

- 包含截至源码基线 `7150323` 的全部已验收内容，并同步第 13–24、26–37 关的最新技能规则证据身份。
- 修正弓兵／弩兵与魔弓箭士的射击经验，恢复水战士原版移动模式并补齐共享本体击杀奖励。
- 调整跟随主将的护卫半径与第 9 关护卫路线，允许敌方施放的魔法守护延续至下一玩家阶段。
- Windows 产物仍为未签名的 x64 NSIS 当前用户安装包，并配套发布 SHA-256 校验文件。
