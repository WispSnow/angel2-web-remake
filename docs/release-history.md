# 发布记录

本文件记录面向玩家的发行版本。Windows 安装包版本由
`pnpm release:version [x.y.z]` 统一更新；未指定版本时默认递增次版本。

## 0.9.0 — 2026-09-22

- 包含截至源码基线 `c028bce` 的全部内容；存档身份升级至 v120／`original-stage-titles-1`，v109 起逐级无损迁移。
- 第 36 关「究極女神」敌方阶段按原版改放本关专属曲 `UN/48`（单曲循环），不再错放通用的 `MUSIC/5→4`。
- 关卡名按原版底条记录更正（`REMAKE-158`）：第 6／7／8 关依次为「來到異世界」「營地遭到偷襲」「營地遭到偷襲 ２」，第 37 关由「異世界」改回「瑪姬的墓園」，异世界之门过场的底条按原版留空；旧存档读取时一并更正关卡名。
- 小地图在移動、攻擊与技術选格期间同样可以点击定位视口，并支持按住拖曳滑动视口（触控同样适用），只改变视口与游标位置、不影响战果；「復刻說明」功能增強分页新增本条。
- 资源清单身份随第 36 关音乐包调整更新（`ea821d55ff6e → 3cf9771f9756`，无新增素材文件，仅清单变化），素材仓库已同步；本次同时更新 Cloudflare Pages 网页版与 Windows NSIS 安装包，产物仍为未签名的 x64 当前用户安装包，配套发布 SHA-256 校验文件。
